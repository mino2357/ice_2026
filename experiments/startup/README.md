# 始動の数値実験（クランキング → 直噴 → 完爆 → アイドル）

実験用ブランチの記録．`src/core.js` と成果物は変えていない．スクリプト `startup.js` が，読み込むときに 1 か所を書き換え，定数 `K` を上書きする．

```
node experiments/startup/startup.js [T=20]   # 結果は result.json（約 35 s）
```

## 1. 問題設定（利用者と合わせたもの，2026-11-24）

| 項目 | 設定 |
| :--- | :--- |
| 試験の形 | エンジンダイナモメーター，スロットル制御（モード A）．動力計はモータリングしない．負荷の吸収と慣性 $I_{\text{dyno}}$ だけ |
| 負荷 | 一定のトルク $T_{\text{load}}$ を動力計が吸収する．**クランキング中から入れる**（core.js は完爆前の指令を 0 にしている．そこを書き換える）．補機の負荷 $T_{\text{aux}} = 2\ \text{N·m}$ は既定のまま |
| スターター | 直流モータの直線特性（ワンウェイクラッチ）．$T_{\text{st}} = T_{\text{stall}}\max(0, 1 - \omega/\omega_{nl})$ |
| 噴射 | START では燃料 OFF．$\bar N \ge N_{\text{crank}} = 250\ \text{rpm}$ に達したら燃料 ON．直噴，SOI は吸気上死点後 80°，$\phi = 1$ |
| 完爆 | $\bar N > N_{\text{fire}} = 500\ \text{rpm}$（既定 550 から下げた）かつ $W_g > 20\ \text{J}$．スターターを切る |
| アイドル | 既定の ECU（スロットルの PI，$N_{\text{target}} = 800\ \text{rpm}$，点火の自動最適化 ON） |
| 温度 | 壁温は設定の一定値（暖機後の再始動に当たる） |
| そのほか | 熱物性は化学平衡，サイクル変動 OFF，始動の角度は下死点 180°（既定） |

## 2. スターターの定数の決め方

1. $T_{\text{stall}} = 60\ \text{N·m}$（既定）のまま $\omega_{nl}$ を下げて，クランキングを 250 rpm 付近にすると，最初の圧縮を越えられない．$I = 0.12$，$I_{\text{dyno}} = 0.05$，$T_{\text{load}} = 3\ \text{N·m}$ では，最初の圧縮の上死点の手前で止まり，3〜6 s の回転は 0 だった（20 s まで計算すると，熱損失で圧力が下がった 19 s ごろにようやく越えた）．9 通りのうち越えたのは $I = 0.12$，$T_{\text{load}} = 0$ だけだった．
   * 見積もり（**推定**）：圧縮の最大トルクは $(p - p_{\text{atm}})\,dV/d\theta \approx 10^6 \times 1.4\times10^{-4} \approx 130\ \text{N·m}$ で，$T_{\text{stall}}$ を上回る．上死点までの圧縮の仕事は $\frac{p_1V_1}{n-1}(\varepsilon^{n-1} - 1) \approx 180\ \text{J}$（$n = 1.3$，$\varepsilon = 10$）．ここで $p_1$，$V_1$ は圧縮の始まりの圧力と容積，$\varepsilon$ は圧縮比である．
   * 単気筒なので，ほかの気筒の膨張に助けてもらえない．越えられるかどうかは，フライホイールの運動エネルギーと，スターターのトルクで決まる．
2. $T_{\text{stall}} = 100,\ 150,\ 200\ \text{N·m}$ を調べた．$\omega_{nl}$ は，燃料 OFF，$I = 0.12$，$I_{\text{dyno}} = 0.05$，$T_{\text{load}} = 6\ \text{N·m}$ でクランキングの時間平均が 300 rpm になる値にした．100 N·m では，$I = 0.03$ でクランキングの最小回転数が $0$〜$33\ \text{rpm}$ まで落ちた（止まりかけ）．150 N·m 以上では，どの条件でも最小が 113 rpm 以上で，0.17〜0.29 s で $\bar N \ge 250$ に達した．
3. 採った値：$T_{\text{stall}} = 150\ \text{N·m}$，$\omega_{nl} = 33.705\ \text{rad/s}$（321.9 rpm）．燃料 OFF のクランキングは平均 300.0 rpm で，瞬時の回転数の最大と最小の差は 148 rpm．低い慣性では，平均が $\omega_{nl}$ を超えることがある（膨張の行程で機関がスターターを追い越し，ワンウェイクラッチが切れるため）．

## 4. 分かったこと

1. **クランキングから完爆までは，どの条件でも成り立つ**：噴射を始めてから 2 サイクル目に完爆する．
2. **完爆からアイドルへの移行が成り立たない**．仕組み（$I = 0.05$，$T_{\text{load}} = 3$ の経過）：
   1. 完爆の時点で，開度は始動開度の $\alpha_{\text{crank}} = 6^\circ$ で，アイドルの開度（約 $4^\circ$）より大きい．このため，完爆（0.55 s）から約 0.5 s で 1700 rpm まで吹け上がる．
   2. PI が開度を下限 $\alpha_{\min} = 2.52^\circ$ まで閉じる．回転が落ち始めても，$\bar N$ は時定数 0.15 s の遅れを持ち，比例の項もこの $\bar N$ で作るので，開き始めが遅れる（2.0 s で $N = 877$ なのに開度は $2.52^\circ$ のまま）．
   3. 慣性が小さいと落ち方が速く，開き始めたとき（2.2〜2.8 s で $3.5 \to 8.5^\circ$）には間に合わず，3.0 s までに止まる．
3. 既定の ECU の PI のゲイン，開度の下限，feedforward（$T_{\text{aux}}$ しか知らない）は，$I_{\text{tot}} = 0.17$，$T_{\text{load}} = 0$ に合わせてある（SPEC-12）．慣性を下げるか負荷を入れると成り立たない．既定の慣性・無負荷でも，$\bar N$ が 50 rpm の幅で振れ続ける（SPEC-12 の限界に書いてある振れと同じ種類と思われる．**未確認**）．

## 5. 未決（次に決めること）

* 完爆からアイドルへの移行の制御：始動開度，完爆直後の開度のスケジュール（flare 制御），PI の比例を瞬時の回転数で作る（動力計制御と同じ形．SPEC-11 の 3），$T_{\text{load}}$ の feedforward，慣性に応じたゲイン．
* 最終の目的は，始動からアイドルまでの最適な VVT の過渡的な変化を見ること（利用者の方針）．そのためには，バルブタイミングを時間（またはサイクル）の関数として与えられるようにする必要がある．
