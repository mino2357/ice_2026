## 経緯

2. 第25版のモデルを実行して，全開の軸トルクが $\phi = 1.0$ で最大になり，$\phi$ を $0.1$ 増やすごとに約 $4\%$ 下がることを確かめた（$4000\ \text{rpm}$ で $\phi = 1.0$：$35.04\ \text{N·m}$，$1.1$：$33.65\ \text{N·m}$）．理由は，酸素が尽きた後の余分な燃料が空気あたりの発熱を減らすことと，リッチが出力を増やす機構（解離，組成による比熱比の変化，吸気の冷却）がモデルに無いことである．

## 自分で決めたこと（理由は仕様書の SPEC-29，SPEC-30 と `docs/report_richburn.md` 7 節）
第25版の熱物性を設定で残す．既定は「化学平衡」と「直噴」にする．平衡は起動時ではなく，当量比の節点ごとに初めて必要になったときに表にする．既燃ガスの当量比は筒内では状態として連続に追う．噴射率はクランク角で一定にする．噴射量は前のサイクルで閉じ込めた空気量から決める．凍結温度は $1700\ \text{K}$．壁への付着，液滴の加熱，成層は扱わない．量論空燃比は，燃料と空気の組成から決まる $14.503$ とする（第25版の $14.7$ は $\gamma$ のモデルでだけ使う）．
