# 単気筒4ストロークSI機関シミュレータ 要件定義書（第26版）

## 1. 目的と範囲

### 1.1 目的
単気筒4ストローク火花点火機関を，連立常微分方程式

$$\frac{d\mathbf{y}}{dt} = \mathbf{f}(\mathbf{y}; \mathbf{u}), \qquad \mathbf{y} \in \mathbb{R}^{21}$$

として数値積分し，ブラウザ上で実時間に可視化・解析する（$\mathbf{y}$：機関の状態，$\mathbf{u}$：ECU と動力計が決める入力．成分は用語の定義集 2.2）．利用者は，設定を変えたときの筒内圧・トルク・効率・音の変化を，保存則が閉じた計算の結果として確かめられる．

### 1.2 対象
* 0 次元・単一ゾーンの開いた系の熱力学（未燃ガスと既燃ガスの比熱を分ける）
* 等エントロピーのオリフィス流れによるガス交換（弁，スロットル，排気の出口）
* スロットル，吸気マニホールド，吸気ランナ，排気系の充填と慣性．吸気側へ吹き返した既燃ガスと熱の追跡
* 火炎伝播の速さに連動する Wiebe 関数の燃焼，壁面熱伝達と壁温
* スライダ・クランク機構とフライホイールの回転運動，摩擦，スターター
* 電動式動力計（吸収と駆動），ECU（始動，スロットル開度の PI 制御，点火時期の自動最適化）
* 線図・性能曲線・機関断面図・エンジン音による可視化，設定の変更，アプリ内の検証

### 1.3 対象外
モデルに含めない事項：三元触媒，消音器（排気管の出口は大気に開いている），排気の熱管理，ノッキング，燃料の壁面付着と始動増量，1 次元の圧力波，多気筒．

実装しない機能：スマートフォンの横持ち（高さ $500\ \text{px}$ 未満），グラフのピンチズーム・パン，フレーム落ち時の描画の簡略化，Screen Wake Lock，`prefers-reduced-motion`，キーボード操作．

### 1.4 利用者と利用環境
* 利用者：数学・物理・内燃機関の知識を持ち，モデルの式と数値解法の中身を確かめたい人．
* 主対象の環境：Samsung Galaxy S26+，Android 版 Google Chrome，タッチ操作，幅 $360\ \text{px}$ 以上の縦持ち．タブレットと PC（マウス）にも対応する（REQ-15）．

## 3. 状態と記号

状態ベクトルは次の 21 成分である（単位と式は用語の定義集 2.2，仕様書 2 節）．後ろの 5 成分は，熱物性が「化学平衡」（REQ-29）のときだけ使う．

$$\mathbf{y} = \left(\theta,\ \omega,\ p,\ m,\ m_u,\ T_w,\ p_{\text{in}},\ m_{b,\text{in}},\ \dot m_r,\ p_p,\ m_{b,p},\ \dot m_e,\ p_{pe},\ p_{te},\ E_{\text{in}},\ E_p,\ m_f,\ m_{bf},\ m_l,\ m_{f,\text{in}},\ m_{f,p}\right)$$

$\theta$：クランク角，$\omega$：角速度，$p$：筒内圧，$m$，$m_u$：筒内ガスの全質量と未燃ガスの質量，$T_w$：壁温，$p_{\text{in}}$：吸気マニホールド圧，$m_{b,\text{in}}$，$m_{b,p}$：マニホールドとポートの既燃ガスの質量，$\dot m_r$，$p_p$：吸気ランナの流量と吸気ポート圧，$\dot m_e$，$p_{pe}$，$p_{te}$：排気管の流量，排気ポート圧（排気管の弁側の半分の圧力），排気管の出口側の圧力（排気管は大気に開いているので使わない．時間微分は $0$．仕様書 SPEC-27 の 8 の内部の値で出口側に容積を置いたときだけ使う），$E_{\text{in}}$，$E_p$：マニホールドとポートの余剰エンタルピー，$m_f$，$m_{bf}$：筒内の未燃の燃料蒸気と，既燃ガスのうち燃料に由来する質量，$m_l$：筒内の液体の燃料，$m_{f,\text{in}}$，$m_{f,p}$：マニホールドとポートの燃料蒸気．

受入基準で使う増分 $\Delta$ は，指定した区間（サイクル）での補助積分（用語の定義集 2.3）または状態の増分を表す．

## 4. 要件

### REQ-01：スライダ・クランク運動学

**要求**：ボア $B$，ストローク $S$，クランク半径 $r = S/2$，連桿長 $l$，連桿比 $\lambda = r/l$，圧縮比 $\varepsilon$ から，行程容積 $V_d$，隙間容積 $V_c$，上死点からのピストン変位 $x(\theta)$，筒内容積 $V(\theta)$，$\frac{dV}{d\theta}$，伝熱面積 $A_w(\theta)$ を求めること．

**受入基準**：

1. $V(0) = V_c$，$V(\pi) = V_c + V_d$，$\dfrac{V(\pi)}{V(0)} = \varepsilon$（相対誤差 $10^{-12}$．TEST-01 項目 1）．
2. 解析式の $\dfrac{dV}{d\theta}$ が，$V(\theta)$ の中心差分と相対誤差 $10^{-9}$ 未満で一致する（項目 2）．
3. 設定できる諸元の全範囲（$\lambda \le 0.5$）で $V(\theta) > 0$，$0 \le x(\theta) \le S$（項目 3）．

**仕様**：仕様書 SPEC-01　**検証**：TEST-01

---

### REQ-02：作動流体の熱物性（未燃・既燃の比熱）

**要求**：筒内ガスを理想気体（$pV = mRT$）とし，比熱を**未燃ガス（新気の混合気）と既燃ガスで分け**，未燃分率で補間すること．内部エネルギーとエンタルピーは比熱の積分で与え，REQ-09 のエネルギーの式と整合させること．比較用に定比熱比のモデルへ切り替えられること．

**受入基準**：

1. 全ての温度（$300 \le T \le 3000\ \text{K}$）と未燃分率 $Y$ で $c_p - c_v = R$，$\gamma = c_p/c_v$（相対誤差 $10^{-12}$．TEST-02 項目 2）．
2. 内部エネルギーが比熱の積分である：$\dfrac{de_k}{dT} = c_{v,k}(T)$（$k = u, b$．数値微分との相対誤差 $10^{-6}$），$e_k(T_0) = 0$，$e_k$ は連続（項目 3）．
3. 比熱比が文献の当てはめを再現する：$\gamma_u(300\ \text{K}) = 1.3488$，$\gamma_u(700\ \text{K}) = 1.2968$，$\gamma_b(2000\ \text{K}) = 1.2080$，$\gamma_b(2700\ \text{K}) = 1.1422$（絶対誤差 $10^{-12}$．項目 1）．
4. 定比熱比モデル（$\gamma = 1.35$）に切り替えられる（項目 5）．

**仕様**：仕様書 SPEC-02　**検証**：TEST-02

### REQ-03：カムプロファイルと弁の有効開口面積

**要求**：吸気弁と排気弁の開閉時期，最大リフト，弁径から，クランク角ごとのリフトと有効開口面積を求めること．機関は 4 弁（吸気 2 個，排気 2 個）とし，弁径（1 個の径）は吸気と排気を別々に設定できること（実機では吸気弁のほうが大きい）．カムプロファイルを 3 種類から選べること．カムの位相を運転中に変えられること（VVT）．弁とピストンの干渉を警告すること．

**受入基準**：

1. 3 種のカムとも，開閉点でリフトが $0$，作用角の中央で $L_{\max}$（TEST-03 項目 1〜3）．
2. 位相 $\varphi$ はリフト曲線を平行移動するだけである：$L_v(\theta; \varphi) = L_v(\theta - \varphi; 0)$（相対誤差 $10^{-12}$．項目 5）．
3. $L_v(\theta) \ge h_c + x(\theta)$ となるクランク角があるとき，かつそのときに限り `VALVE HIT` を表示する（項目 6）．
4. 運転中に位相を変えても状態量が有限のままで，体積効率が $1\%$ 以上変わる（項目 7）．
5. 吸気弁径と排気弁径を別々に設定でき，既定では排気弁が吸気弁より小さい（項目 4）．
6. 弁の有効開口面積が，吸気・排気とも弁 2 個の分である．4 弁であることが設定画面と全体図で読める（項目 8）．

**仕様**：仕様書 SPEC-03　**検証**：TEST-03

### REQ-04：オリフィスの圧縮性流れ（順流・逆流・チョーク）

**要求**：弁，スロットル，排気管の出口を通る質量流量を，等エントロピー流れのオリフィスの式で求めること．チョークと逆流を扱うこと．

**受入基準**：

1. $p_1 = p_2$ で $\dot m = 0$（厳密）．上流の温度と比熱比が同じなら $\dot m(p_1, p_2) = -\dot m(p_2, p_1)$（TEST-04 項目 1）．
2. 圧力比 $r_p$ が臨界圧力比 $r_{\text{crit}} = \left(\dfrac{2}{\gamma_0 + 1}\right)^{\gamma_0/(\gamma_0 - 1)}$ 以下では流量が $r_p$ によらない．$\gamma_0 = 1.4$ で $r_{\text{crit}} = 0.5282817877$，$\Psi = 0.68473145$（項目 2）．
3. 流量関数 $\Psi(r_p)$ は $r_{\text{crit}} < r_p \le 1$ で連続かつ単調減少で，$\Psi(1) = 0$（項目 3）．

**仕様**：仕様書 SPEC-04　**検証**：TEST-04

### REQ-05：スロットルと吸気マニホールド

**要求**：スロットル開度 $\alpha$ から，スロットルの質量流量 $\dot m_{\text{th}}$ と吸気マニホールド圧 $p_{\text{in}}$ の変化を求めること．大気圧を設定で変えられること．吸気側へ吹き返した筒内ガスの**既燃分**と**熱**を追跡し，次の吸気で筒内へ戻すこと．

**受入基準**：

1. **質量**：吸気弁を閉じたとき $\displaystyle\int\dot m_{\text{th}}\,dt = \frac{V_{\text{in}}}{RT_{\text{in}}}\,\Delta p_{\text{in}}$（相対誤差 $10^{-6}$）．周期定常で $\Delta M_{\text{th}} = \Delta M_{\text{in}}$（$0.2\%$．TEST-05 項目 2，4）．
2. **既燃ガス**：$\Delta\left(m_{b,\text{in}} + m_{b,p}\right) = \Delta B_o - \Delta B_i$（差が $10^{-3}\,\Delta B_o$ 以下）．周期定常で $\Delta B_o = \Delta B_i$（$2\%$．項目 7）．
3. **熱**：$\Delta\left(E_{\text{in}} + E_p\right) = \Delta X_o - \Delta X_i - \Delta X_t$（差が $10^{-6}\,\Delta X_o$ 以下）．周期定常で $\Delta X_o = \Delta X_i$（$2\%$．項目 8）．
4. アイドルで，吸気弁の順流の上流温度の流量加重平均が $T_{\text{in}} + 15\ \text{K}$ 以上（吹き返しが吸気を温める．項目 9）．
5. 全時刻で $0 \le Y_{b,\text{in}} \le 1$，$0 \le Y_{b,p} \le 1$，$E_{\text{in}} \ge 0$，$E_p \ge 0$（項目 6）．
6. チョークしたスロットルの流量が大気圧 $p_{\text{atm}}$ に比例する（相対誤差 $10^{-12}$．項目 3）．

**仕様**：仕様書 SPEC-05　**検証**：TEST-05

### REQ-07：燃焼（乱流火炎伝播に連動する単一 Wiebe モデル）

**要求**：点火時期，当量比 $\phi$，残留ガス率 $x_r$，回転数に応じて，着火遅れと燃焼期間が変わること．着火遅れと熱発生の速さを利用者が係数で調整できること．リッチ側の不完全燃焼を扱うこと．燃焼をサイクルごとにばらつかせられること（既定ではばらつかせない）．

**受入基準**：

1. $\displaystyle\int_0^1\frac{dx_b}{d\zeta}\,d\zeta = 1 - e^{-a}$（相対誤差 $10^{-5}$．TEST-07 項目 1）．
2. 層流燃焼速度が文献の値を再現する：$S_{L,0}(\phi = 1.13) = 0.2758\ \text{m/s}$．残留ガス率 $x_r = 0.2$ で $x_r = 0$ の $0.58$ 倍（項目 2）．
3. 残留ガスが増えると $S_L$ が下がり，点火を遅らせると燃焼期間が延びる（項目 3）．調整係数 $c_d = 2$ で着火遅れが 2 倍，$c_b = 2$ で燃焼期間が半分（項目 4）．
4. 開度固定で，IMEP が当量比 $\phi = 0.8 < 0.9 < 1.0$ の順に増える．既定（化学平衡・直噴）では $\phi = 1.1$ が $1.0$ より大きく（REQ-29 の 8），熱物性 $\gamma(T)$ では $\phi = 1$ で最大になる（$1.0 > 1.1 > 1.2$．項目 6）．
5. リッチ側の生成物が元素の保存と水性ガスシフト平衡 $K_w = 3.5$ を満たし，$\phi\,\epsilon(\phi)$ が $\phi \ge 1$ で単調に減る（$\phi = 1.1$ で $0.969 \pm 0.002$．項目 5）．
6. サイクル変動 ON で，IMEP の変動係数が $0.5$〜$5\%$，平均 IMEP が OFF と $2\%$ 以内で，同じ初期状態から同じ結果になる（項目 8，9）．
7. 設定「サイクル変動」の既定は OFF である（項目 10）．

**仕様**：仕様書 SPEC-07　**検証**：TEST-07

### REQ-08：壁面熱伝達と壁温

**要求**：筒内ガスからシリンダ壁への熱流量を Woschni の式で求め，壁温の変化を連立して解くこと．

**受入基準**：

1. $C_w = 0$ で $\dot Q_{\text{wall}} = 0$（TEST-08 項目 1）．
2. 燃焼による増圧（$p > p_{\text{mot}}$）で熱伝達率 $h_c$ が増える（項目 2）．
3. $\dot Q_{\text{wall}} = 0$，$T_w = 300\ \text{K}$ で $\dfrac{dT_w}{dt} = \dfrac{G_{\text{cool}}\,(T_{\text{cool}} - T_w)}{C_{w,\text{th}}} = 0.6\ \text{K/s}$（相対誤差 $10^{-12}$．項目 3）．

**仕様**：仕様書 SPEC-08　**検証**：TEST-08

### REQ-09：筒内圧の式（開いた系の熱力学第一法則）

**要求**：質量の出入りと燃焼を伴う筒内ガスのエネルギー保存と状態方程式から，筒内圧の時間微分を導いて解くこと．比熱が温度と組成で変わっても，第一法則が閉じること．

**受入基準**：

1. 定比熱比・断熱・閉じた系で $pV^{\gamma_0}$ が一定：$p(2\pi) = p(\pi)\,\varepsilon^{\gamma_0}$（相対誤差 $10^{-5}$），1 往復の図示仕事が $0$（TEST-09 項目 1）．
2. 温度依存比熱・断熱・閉じた系で $m\left[e_k(T_{\text{end}}) - e_k(T_{\text{start}})\right] = -\displaystyle\int p\,dV$（相対誤差 $10^{-6}$．未燃ガスだけ，既燃ガスだけのそれぞれ．項目 2）．

### REQ-11：電動式動力計と運転モード

**要求**：機関に負荷を与え，軸トルク・軸出力・BMEP を評価するための電動式動力計を持つこと．動力計はトルクの指令に速く従い，吸収（機関から仕事を取る）と駆動（モータリング．機関を回す）の両方ができ，定格トルクと定格出力の範囲で働く．回転数を制御する方法を 2 つのモードから選べること．既定は動力計制御とする．

2 つの制御が同時に回転数を操作しないよう，モードは排他とする．完爆前はどちらのモードも動力計のトルクの指令は $0$，$\alpha = \alpha_{\text{crank}}$．画面では「スロットル制御」「動力計制御」と呼び，設定の項目名は「回転数の制御」，選択肢は「スロットル」「動力計」とする．動力計のトルクは「吸収 12.3 N·m」「駆動 4.1 N·m」のように向きを言葉で示し，出力（kW）を添える．

**受入基準**：

### REQ-27：排気系（排気管の脈動と背圧）

**要求**：排気弁の下流に排気管（長さ $L_e$，内径 $d_e$）を置き，その出口を大気に開くこと（消音器も触媒も無い）．排気の脈動と，流量に応じて変わる背圧を扱うこと．背圧は，管の摩擦と出口の動圧から決まり，目標の値を持たないこと．

**受入基準**：

1. 排気弁が閉じているとき，排気管の流量が角振動数 $\omega_E = \sqrt{\dfrac{A_e}{L_e}\dfrac{\gamma_0 RT_X}{V_{pe}}}$ で振動する（周期の相対誤差 $1\%$．TEST-27 項目 1）．

3. 出口が大気に開いている：排気管の運動量の式の出口の圧力が大気圧で，損失係数に出口の動圧 1 つ分が入る（$p_{pe} - p_{\text{atm}} = (\zeta_x + 1)\dfrac{\dot m_e^2}{2\rho_e A_e^2}$ のとき $\dfrac{d\dot m_e}{dt} = 0$．項目 2）．周期定常で，背圧（1 サイクル平均の排気ポート圧と大気圧の差）が，損失の項の 1 サイクル平均に一致する（運動量の式の 1 サイクル平均．相対 $1\%$）．全開の $1000$〜$7000\ \text{rpm}$ で背圧が $10\ \text{kPa}$ 以下，アイドルで $0.5\ \text{kPa}$ 以下（項目 5）．
4. 全開・$3000\ \text{rpm}$ で排気ポート圧の脈動の幅が $20\ \text{kPa}$ 以上（項目 6）．

### 7.2 未決事項と既知の限界
1. **スターターが実機より速い**：燃料 OFF のクランキングが約 $1700\ \text{rpm}$ に達し，始動直後に回転が吹け上がる．アイドルへの整定に約 $12\ \text{s}$ かかる（SPEC-10）．
2. **高い補機負荷での整定**：$T_{\text{aux}} \ge 10\ \text{N·m}$ では整定が遅い．低い目標回転数（$600\ \text{rpm}$）では回転が数十 rpm の幅で振れ続ける（SPEC-12）．
3. **アイドルの吸気管圧**：サイクルの終端の値で，始動から $20\ \text{s}$（S2）で $26.6\ \text{kPa}$，$30\ \text{s}$ で $29.1\ \text{kPa}$（実測．壁温が上がるにつれて上がる）．実機の推定（$30$〜$35\ \text{kPa}$）より低めである．吹き返しによる吸気の加熱を入れて，第24版（S2 で $23.5\ \text{kPa}$）からは上がった．ポート壁による吸気の加熱を扱っていないことが一因と考えられる（推定）．
4. **既燃ガスの比熱**：線形の当てはめで，$1\%$ 弱の誤差がある．より正確な Krieger–Borman の多項式は，係数を原典で確認できていないため採用していない（SPEC-02）．
5. **文献で確認できていない値**：Barnes–Moss の相関の係数（SPEC-28），Martyr と Plint の版とページ（SPEC-11）．
6. **吸気ポートの壁との熱のやりとり**：扱っていない（断熱）．吹き返しによる吸気の加熱は上限の見積もりである（SPEC-05）．
7. **排気の温度**：$800\ \text{K}$ 一定．排気弁が開く時点の筒内の温度はこれより高い（SPEC-27）．
8. **単気筒であること**：実機と比べる値は多気筒機関からの 1 気筒あたりの換算で，排気量あたりの摩擦や熱損失が同じとは限らない（SPEC-28）．
9. **画面と音の仕様**（REQ-15〜23，26）は，第25版で文書を書き直した．第25版で変えたのは解説タブの文書の閲覧（REQ-16）だけである．第26版で，設定のページ「噴射」，性能曲線の回転数の点と印の間引き，$p$-$V$ 線図の印，線図タブのバルブタイミングの画面を加えた（7.4 節）．音は，演出の音の音量の基準の値を既定のモデルに合わせて改めたほかは，第24版から変えていない．
10. **ノッキング**：扱わない．点火は常に MBT が取れるので，実機でリッチにする主な理由（ノックを避けて点火を進められること，排気温の保護）による利得は現れない（7.4 節，`docs/report_richburn.md`）．
11. **単一ゾーンでの解離**（第26版）：既燃ガスの平衡組成を筒内の平均温度で評価するので，解離を小さく見積もる（SPEC-29）．
12. **気化潜熱の値**：$h_{fg} = 350\ \text{kJ/kg}$ は，米国石油協会の資料に基づく燃料の物性の表の値（約 $150\ \text{Btu/lb} = 349\ \text{kJ/kg}$，$60\ ^\circ\text{F}$）に当たる．文献によって $305$〜$380\ \text{kJ/kg}$ の幅がある（Heywood の表は $305$）．$305$ にすると，全開・$3000\ \text{rpm}$ の直噴の軸トルクは $1.4\%$ 下がり，リッチでの出力増の比（$\phi = 1.1$ と $1.0$）は変わらない（SPEC-30，`docs/review_v26.md` の 4 節）．
13. **仕様書の「実測」の値**：第26版で測り直したのは TEST-29，TEST-30 と，判定値を改めた項目だけである．ほかは第25版（$\gamma(T)$ が既定）での値のままである．第26版の成果物での全検査の実測値は `docs/measured_v26.md` にまとめてある（仕様書 8 節の冒頭）．
14. **性能曲線の収束の判定と吸気側の組成**：収束の判定（SPEC-26 A の 6）は，軸トルク・点火時期・流量・吸気管圧を見て，吸気側の燃料蒸気の割合は見ない．ポート噴射では，計測の機関は吸気側が空気だけの状態から始まり，燃料蒸気の割合は，設定の値との差が 1 サイクルごとに約 $0.64$ 倍になる速さ（全開・$3000\ \text{rpm}$ の実測．時定数にして約 $2.2$ サイクル）で設定の値に近づく．軸トルクが当量比に対してほぼ平らな $\phi \approx 1.1$ 付近では，割合が $1\%$ 残った状態で判定を満たすことがある（そのときの軸トルクの差は $0.05\%$．`docs/review_v26.md` の 5 節）．手順が「上り」のときは最初の点だけ，「独立」のときは各点に当たる．
15. **エンストの点の表示**：性能曲線の計測でエンストと記録した点（$150\ \text{rpm}$ 未満）はグラフに描かないだけで，点の数や回転数を画面に書き出していない（SPEC-26 A の 4）．
16. **4 弁のモデル**：弁の数は有効開口面積に 2 を掛ける形でだけ入る．流量係数 $C_d = 0.6$ は 2 弁のときと同じとし，弁どうし・弁と壁の間の干渉による流量の低下は入れていない．4 弁の実機の利点のうち，点火プラグを中央に置けることとタンブル流による燃焼の速さは，燃焼の速さのモデル（SPEC-07）に入らない．このため，4 弁にした効果は高回転の吸排気の流れだけに現れる（`docs/review_v26.md` の 11.2 節）．
17. **動力計制御・全開での回転数の振れ**（解決済み．7.4 の 22）：充水率に対する吸収トルクの感度 $k_w\omega^2$ が定格トルクと回転数の 2 乗に比例するのに，PI のゲインが一定だったため，定格を大きくするか目標回転数を上げると制御が不安定になり，振幅数百 rpm のリミットサイクルになっていた．ゲインを感度で規格化した（SPEC-11 の 3）．
18. **音の「出口の反射率」**（解決済み．7.4 の 22）：設定の項目を廃止し，反射は管内の損失と開口端の放射だけで決めるようにした（SPEC-21 B）．

#### 自分で決めたこと（理由は仕様書の SPEC-29，SPEC-30 と `docs/report_richburn.md` 7 節）
