# 単気筒4ストロークSI機関シミュレータ 要件定義書（第26版）

## 1. 目的と範囲

### 1.1 目的
単気筒4ストローク火花点火機関を，連立常微分方程式

$$\frac{d\mathbf{y}}{dt} = \mathbf{f}(\mathbf{y}; \mathbf{u}), \qquad \mathbf{y} \in \mathbb{R}^{22}$$

として数値積分し，ブラウザ上で実時間に可視化・解析する（$\mathbf{y}$：機関の状態，$\mathbf{u}$：ECU と動力計が決める入力．成分は用語の定義集 2.2）．利用者は，設定を変えたときの筒内圧・トルク・効率・音の変化を，保存則が閉じた計算の結果として確かめられる．

### 1.2 対象
* 0 次元・単一ゾーンの開いた系の熱力学（未燃ガスと既燃ガスの比熱を分ける）
* 等エントロピーのオリフィス流れによるガス交換（弁，スロットル，排気の出口）
* スロットル，吸気マニホールド，吸気ランナ，排気系の充填と慣性．吸気側へ吹き返した既燃ガスと熱の追跡．排気ポートのガスの温度（質量とエネルギーの式）
* 火炎伝播の速さに連動する Wiebe 関数の燃焼，壁面熱伝達と壁温
* スライダ・クランク機構とフライホイールの回転運動，摩擦，スターター
* 電動式動力計（吸収と駆動），ECU（始動，スロットル開度の PI 制御，点火時期の自動最適化）
* 線図・性能曲線・機関断面図・エンジン音による可視化，振動による体感，設定の変更，アプリ内の検証

### 1.2a 試験の種類（大きな枠組み）
シミュレータの使い方を，次の 2 つの**試験の種類**に分ける．設定「試験の種類」で選ぶ（既定はエンジンダイナモメーター）．

| 試験の種類 | 構成 | 機関の回転数の決まり方 | 調べること | 要件 |
| :--- | :--- | :--- | :--- | :--- |
| **エンジンダイナモメーター**（機関単体） | 機関 ＋ 電動式動力計 | スロットル制御（ECU が開度で合わせる）か，動力計制御（動力計がトルクで合わせる．駆動もできる） | 軸トルク，出力，燃費，損失，性能曲線，最適化 | REQ-11，REQ-12 ほか |
| **シャシーダイナモメーター**（車両あり） | 機関 ＋ 理想の無段変速機 ＋ 車両（車重，空気抵抗，転がり抵抗）．ローラが走行抵抗と車両の慣性を与える | 変速機が機関を目標回転数に保つ．スロットル開度はアクセル | 車速，駆動力，$0 \to 100\ \text{km/h}$ の時間，最高速度 | REQ-35 |

機関のモデルはどちらでも同じである．

### 1.3 対象外
モデルに含めない事項：三元触媒，消音器（排気管の出口は大気に開いている），排気の熱管理，冷却水・油・ピストンの温度（壁温は 1 つの設定値），ノッキング，燃料の壁面付着と始動増量，1 次元の圧力波，多気筒．車両では，段付きの変速機と変速の時間，タイヤのすべり，荷重移動，勾配，車輪の慣性．

実装しない機能：スマートフォンの横持ち（高さ $500\ \text{px}$ 未満），グラフのピンチズーム・パン，フレーム落ち時の描画の簡略化，Screen Wake Lock，`prefers-reduced-motion`，キーボード操作．

### 1.4 利用者と利用環境
* 利用者：数学・物理・内燃機関の知識を持ち，モデルの式と数値解法の中身を確かめたい人．
* 主対象の環境：Samsung Galaxy S26+，Android 版 Google Chrome，タッチ操作，幅 $360\ \text{px}$ 以上の縦持ち．タブレットと PC（マウス）にも対応する（REQ-15）．

## 3. 状態と記号

状態ベクトルは次の 22 成分である（単位と式は用語の定義集 2.2，仕様書 2 節）．後ろの 6 成分は，熱物性が「化学平衡」（REQ-29）のときだけ使う．

$$\mathbf{y} = \left(\theta,\ \omega,\ p,\ m,\ m_u,\ T_w,\ p_{\text{in}},\ m_{b,\text{in}},\ \dot m_r,\ p_p,\ m_{b,p},\ \dot m_e,\ p_{pe},\ p_{te},\ E_{\text{in}},\ E_p,\ m_f,\ m_{bf},\ m_l,\ m_{f,\text{in}},\ m_{f,p},\ T_X\right)$$

$\theta$：クランク角，$\omega$：角速度，$p$：筒内圧，$m$，$m_u$：筒内ガスの全質量と未燃ガスの質量，$T_w$：壁温，$p_{\text{in}}$：吸気マニホールド圧，$m_{b,\text{in}}$，$m_{b,p}$：マニホールドとポートの既燃ガスの質量，$\dot m_r$，$p_p$：吸気ランナの流量と吸気ポート圧，$\dot m_e$，$p_{pe}$，$p_{te}$：排気管の流量，排気ポート圧（排気管の弁側の半分の圧力），排気管の出口側の圧力（排気管は大気に開いているので使わない．時間微分は $0$．仕様書 SPEC-27 の 8 の内部の値で出口側に容積を置いたときだけ使う），$E_{\text{in}}$，$E_p$：マニホールドとポートの余剰エンタルピー，$m_f$，$m_{bf}$：筒内の未燃の燃料蒸気と，既燃ガスのうち燃料に由来する質量，$m_l$：筒内の液体の燃料，$m_{f,\text{in}}$，$m_{f,p}$：マニホールドとポートの燃料蒸気．$T_X$：排気ポートのガスの温度（排気温度）．熱物性が「化学平衡」のとき，壁温 $T_w$ は設定の一定値で，時間変化しない（REQ-08）．

受入基準で使う増分 $\Delta$ は，指定した区間（サイクル）での補助積分（用語の定義集 2.3）または状態の増分を表す．

## 4. 要件

### REQ-01：スライダ・クランク運動学

**要求**：ボア $B$，ストローク $S$，クランク半径 $r = S/2$，連桿長 $l$，連桿比 $\lambda = r/l$，圧縮比 $\varepsilon$ から，行程容積 $V_d$，隙間容積 $V_c$，上死点からのピストン変位 $x(\theta)$，筒内容積 $V(\theta)$，$\frac{dV}{d\theta}$，伝熱面積 $A_w(\theta)$ を求めること．

**受入基準**：

1. $V(0) = V_c$，$V(\pi) = V_c + V_d$，$\dfrac{V(\pi)}{V(0)} = \varepsilon$（相対誤差 $10^{-12}$．TEST-01 項目 1）．
2. 解析式の $\dfrac{dV}{d\theta}$ が，$V(\theta)$ の中心差分と相対誤差 $10^{-9}$ 未満で一致する（項目 2）．
3. 設定できる諸元の全範囲（$\lambda \le 0.5$）で $V(\theta) > 0$，$0 \le x(\theta) \le S$（項目 3）．

**仕様**：仕様書 SPEC-01　**検証**：TEST-01

---

### REQ-02：作動流体の熱物性（未燃・既燃の比熱）

**要求**：筒内ガスを理想気体（$pV = mRT$）とし，比熱を**未燃ガス（新気の混合気）と既燃ガスで分け**，未燃分率で補間すること．内部エネルギーとエンタルピーは比熱の積分で与え，REQ-09 のエネルギーの式と整合させること．比較用に定比熱比のモデルへ切り替えられること．

**受入基準**：

1. 全ての温度（$300 \le T \le 3000\ \text{K}$）と未燃分率 $Y$ で $c_p - c_v = R$，$\gamma = c_p/c_v$（相対誤差 $10^{-12}$．TEST-02 項目 2）．
2. 内部エネルギーが比熱の積分である：$\dfrac{de_k}{dT} = c_{v,k}(T)$（$k = u, b$．数値微分との相対誤差 $10^{-6}$），$e_k(T_0) = 0$，$e_k$ は連続（項目 3）．
3. 比熱比が文献の当てはめを再現する：$\gamma_u(300\ \text{K}) = 1.3488$，$\gamma_u(700\ \text{K}) = 1.2968$，$\gamma_b(2000\ \text{K}) = 1.2080$，$\gamma_b(2700\ \text{K}) = 1.1422$（絶対誤差 $10^{-12}$．項目 1）．
4. 定比熱比モデル（$\gamma = 1.35$）に切り替えられる（項目 5）．

**仕様**：仕様書 SPEC-02　**検証**：TEST-02

### REQ-03：カムプロファイルと弁の有効開口面積

**要求**：吸気弁と排気弁の開閉時期，最大リフト，弁径から，クランク角ごとのリフトと有効開口面積を求めること．機関は 4 弁（吸気 2 個，排気 2 個）とし，弁径（1 個の径）は吸気と排気を別々に設定できること（実機では吸気弁のほうが大きい）．カムプロファイルを 3 種類から選べること．カムの位相を運転中に変えられること（VVT）．弁とピストンの干渉を警告すること．

**受入基準**：

1. 3 種のカムとも，開閉点でリフトが $0$，作用角の中央で $L_{\max}$（TEST-03 項目 1〜3）．
2. 位相 $\varphi$ はリフト曲線を平行移動するだけである：$L_v(\theta; \varphi) = L_v(\theta - \varphi; 0)$（相対誤差 $10^{-12}$．項目 5）．
3. $L_v(\theta) \ge h_c + x(\theta)$ となるクランク角があるとき，かつそのときに限り `VALVE HIT` を表示する（項目 6）．
4. 運転中に位相を変えても状態量が有限のままで，体積効率が $1\%$ 以上変わる（項目 7）．
5. 吸気弁径と排気弁径を別々に設定でき，既定では排気弁が吸気弁より小さい（項目 4）．
6. 弁の有効開口面積が，吸気・排気とも弁 2 個の分である．4 弁であることが設定画面と全体図で読める（項目 8）．

**仕様**：仕様書 SPEC-03　**検証**：TEST-03

### REQ-04：オリフィスの圧縮性流れ（順流・逆流・チョーク）

**要求**：弁，スロットル，排気管の出口を通る質量流量を，等エントロピー流れのオリフィスの式で求めること．チョークと逆流を扱うこと．

**受入基準**：

1. $p_1 = p_2$ で $\dot m = 0$（厳密）．上流の温度と比熱比が同じなら $\dot m(p_1, p_2) = -\dot m(p_2, p_1)$（TEST-04 項目 1）．
2. 圧力比 $r_p$ が臨界圧力比 $r_{\text{crit}} = \left(\dfrac{2}{\gamma_0 + 1}\right)^{\gamma_0/(\gamma_0 - 1)}$ 以下では流量が $r_p$ によらない．$\gamma_0 = 1.4$ で $r_{\text{crit}} = 0.5282817877$，$\Psi = 0.68473145$（項目 2）．
3. 流量関数 $\Psi(r_p)$ は $r_{\text{crit}} < r_p \le 1$ で連続かつ単調減少で，$\Psi(1) = 0$（項目 3）．

**仕様**：仕様書 SPEC-04　**検証**：TEST-04

### REQ-05：スロットルと吸気マニホールド

**要求**：スロットル開度 $\alpha$ から，スロットルの質量流量 $\dot m_{\text{th}}$ と吸気マニホールド圧 $p_{\text{in}}$ の変化を求めること．大気圧を設定で変えられること．吸気側へ吹き返した筒内ガスの**既燃分**と**熱**を追跡し，次の吸気で筒内へ戻すこと．

**受入基準**：

1. **質量**：吸気弁を閉じたとき $\displaystyle\int\dot m_{\text{th}}\,dt = \frac{V_{\text{in}}}{RT_{\text{in}}}\,\Delta p_{\text{in}}$（相対誤差 $10^{-6}$）．周期定常で $\Delta M_{\text{th}} = \Delta M_{\text{in}}$（$0.2\%$．TEST-05 項目 2，4）．
2. **既燃ガス**：$\Delta\left(m_{b,\text{in}} + m_{b,p}\right) = \Delta B_o - \Delta B_i$（差が $10^{-3}\,\Delta B_o$ 以下）．周期定常で $\Delta B_o = \Delta B_i$（$2\%$．項目 7）．
3. **熱**：$\Delta\left(E_{\text{in}} + E_p\right) = \Delta X_o - \Delta X_i - \Delta X_t$（差が $10^{-6}\,\Delta X_o$ 以下）．周期定常で $\Delta X_o = \Delta X_i$（$2\%$．項目 8）．
4. アイドルで，吸気弁の順流の上流温度の流量加重平均が $T_{\text{in}} + 15\ \text{K}$ 以上（吹き返しが吸気を温める．項目 9）．
5. 全時刻で $0 \le Y_{b,\text{in}} \le 1$，$0 \le Y_{b,p} \le 1$，$E_{\text{in}} \ge 0$，$E_p \ge 0$（項目 6）．
6. チョークしたスロットルの流量が大気圧 $p_{\text{atm}}$ に比例する（相対誤差 $10^{-12}$．項目 3）．

**仕様**：仕様書 SPEC-05　**検証**：TEST-05

### REQ-07：燃焼（乱流火炎伝播に連動する単一 Wiebe モデル）

**要求**：点火時期，当量比 $\phi$，残留ガス率 $x_r$，回転数に応じて，着火遅れと燃焼期間が変わること．着火遅れと熱発生の速さを利用者が係数で調整できること．リッチ側の不完全燃焼を扱うこと．燃焼をサイクルごとにばらつかせられること（既定ではばらつかせない）．

**受入基準**：

1. $\displaystyle\int_0^1\frac{dx_b}{d\zeta}\,d\zeta = 1 - e^{-a}$（相対誤差 $10^{-5}$．TEST-07 項目 1）．
2. 層流燃焼速度が文献の値を再現する：$S_{L,0}(\phi = 1.13) = 0.2758\ \text{m/s}$．残留ガス率 $x_r = 0.2$ で $x_r = 0$ の $0.58$ 倍（項目 2）．
3. 残留ガスが増えると $S_L$ が下がり，点火を遅らせると燃焼期間が延びる（項目 3）．調整係数 $c_d = 2$ で着火遅れが 2 倍，$c_b = 2$ で燃焼期間が半分（項目 4）．
4. 開度固定で，IMEP が当量比 $\phi = 0.8 < 0.9 < 1.0$ の順に増える．既定（化学平衡・直噴）では $\phi = 1.1$ が $1.0$ より大きく（REQ-29 の 8），熱物性 $\gamma(T)$ では $\phi = 1$ で最大になる（$1.0 > 1.1 > 1.2$．項目 6）．

### REQ-11：電動式動力計と運転モード

**要求**：機関に負荷を与え，軸トルク・軸出力・BMEP を評価するための電動式動力計を持つこと．動力計はトルクの指令に速く従い，吸収（機関から仕事を取る）と駆動（モータリング．機関を回す）の両方ができ，定格トルクと定格出力の範囲で働く．回転数を制御する方法を 2 つのモードから選べること．既定は動力計制御とする．

* **スロットル制御**（モード A）：ECU がスロットル開度 $\alpha$ を PI 制御して目標回転数 $N_{\text{target}}$ に合わせる（REQ-12）．動力計のトルクの指令は設定の一定値（負荷トルク $T_{\text{load}}$，既定 $0$，吸収だけ）．
* **動力計制御**（モード B．既定）：スロットル開度は設定の一定値 $\alpha_{\text{manual}}$（既定 $15^\circ$）とし，動力計のトルクを PI 制御して $N_{\text{target}}$ に保つ．機関の出力が足りないときは駆動して回転数を保つ（燃料を止めても回転数を保ち，摩擦とポンピングの損失を負のトルクとして見られる）．定常点のトルク・出力・燃費の取得に使う．

2 つの制御が同時に回転数を操作しないよう，モードは排他とする．スロットル制御の完爆前（スターターで回している間）は，動力計のトルクの指令は $0$，$\alpha = \alpha_{\text{crank}}$．画面では「スロットル制御」「動力計制御」と呼び，設定の項目名は「回転数の制御」，選択肢は「スロットル」「動力計」とする．動力計のトルクは「吸収 12.3 N·m」「駆動 4.1 N·m」のように向きを言葉で示し，出力（kW）を添える．

**受入基準**：

1. 設定「回転数の制御」の既定が動力計制御である（TEST-11 項目 10）．
2. トルクの指令を $0 \to T_c$ にすると，$t = \tau_d$ で動力計のトルクが $(1 - e^{-1})T_c$（相対誤差 $10^{-9}$．積分の刻みによらない．項目 2）．指令は $\pm\min(T_{\text{rated}},\ P_{\text{rated}}/\omega)$ で頭打ちになる（項目 1）．
3. スロットル制御の定常で $\overline{T_b} = \overline{T_{\text{dyno}}}$（相対差 $2\%$．項目 3）．
4. 動力計制御で $\bar N$ の平均が目標の $\pm 10\ \text{rpm}$，瞬時値が $\pm 25\ \text{rpm}$（$1500\ \text{rpm}$，開度 $15^\circ$．項目 4）．
5. 動力計制御で燃料を止めると，動力計が機関を駆動して $\bar N$ を目標の $\pm 25\ \text{rpm}$ に保ち，動力計のトルクが負（駆動）になる（項目 5）．
6. 動力計の吸収の容量が足りないとき `OVERLOAD`，駆動の容量が足りないとき `UNDERPOWER` を表示し，張り付いている間は積分の状態が増え続けない．目標を届く値にすると制御に戻る（項目 6，7）．
7. 制御方式を切り替えた直後に指令が跳ばない：トルクの指令の変化 $\le 10^{-3}\ \text{N·m}$，$|\Delta\alpha| \le 0.01^\circ$（項目 8）．

9. 画面（制御状態の表示，設定の行，全体図）で，動力計のトルクを「吸収」「駆動」の言葉と N·m の値で示す（TEST-22 項目 5，TEST-18 項目 16，TEST-31 項目 3）．

### REQ-27：排気系（排気管の脈動と背圧）

**要求**：排気弁の下流に排気管（長さ $L_e$，内径 $d_e$）を置き，その出口を大気に開くこと（消音器も触媒も無い）．排気の脈動と，流量に応じて変わる背圧を扱うこと．背圧は，管の摩擦と出口の動圧から決まり，目標の値を持たないこと．熱物性が「化学平衡」（既定）のときは，排気ポートのガスの温度（排気温度）を，質量とエネルギーの式で求めること：排気弁から入るガスの顕熱，排気管へ出るガスの顕熱，ポートの壁への熱伝達で決まり，一定の値を仮定しない．排気管の密度と，排気弁の逆流の温度はこの温度による．

**受入基準**：

1. 排気弁が閉じているとき，排気管の流量が角振動数 $\omega_E = \sqrt{\dfrac{A_e}{L_e}\dfrac{\gamma_X R_X T_X}{V_{pe}}}$ で振動する（$\gamma_X$，$R_X$，$T_X$ は排気ポートのガスの比熱比，気体定数，温度．熱物性 $\gamma(T)$ では $\gamma_X = \gamma_0$，$T_X = 800\ \text{K}$ 一定．周期の相対誤差 $1\%$．TEST-27 項目 1）．
2. 周期定常で $\Delta M_{\text{ex}}$，$\Delta M_e$，$\Delta M_t$ が互いに $1\%$ 以内（項目 4）．
3. 出口が大気に開いている：排気管の運動量の式の出口の圧力が大気圧で，損失係数に出口の動圧 1 つ分が入る（$p_{pe} - p_{\text{atm}} = (\zeta_x + 1)\dfrac{\dot m_e^2}{2\rho_e A_e^2}$ のとき $\dfrac{d\dot m_e}{dt} = 0$．項目 2）．周期定常で，背圧（1 サイクル平均の排気ポート圧と大気圧の差）が，損失の項の 1 サイクル平均に一致する（運動量の式の 1 サイクル平均．相対 $1\%$）．全開の $1000$〜$7000\ \text{rpm}$ で背圧が $10\ \text{kPa}$ 以下，アイドルで $0.5\ \text{kPa}$ 以下（項目 5）．
4. 全開・$3000\ \text{rpm}$ で排気ポート圧の脈動の幅が $20\ \text{kPa}$ 以上（項目 6）．
5. 排気ポートの質量とエネルギーが保存する：周期定常の 5 サイクルで，ポートのガスの質量と（顕熱の）内部エネルギーの増分が，補助積分で求めた出入り（排気弁から入る顕熱，排気管へ出る顕熱，壁への熱）に一致する（出入りの絶対値の和に対して $10^{-6}$．項目 9）．
6. ポートの壁への熱伝達を $0$ にし，流れの無い状態の右辺で $\dfrac{dT_X}{dt} = \dfrac{dp_{pe}}{dt} = 0$．壁への熱伝達率が管内乱流の熱伝達の式（Dittus–Boelter）に一致する（相対誤差 $10^{-12}$．項目 10）．
7. 排気温度が妥当：全開・$3000\ \text{rpm}$ の周期定常で，排気管へ出るガスの質量で重みをつけた 1 サイクルの平均温度が，排気弁が開く時点の筒内の温度より低く，$900$〜$1400\ \text{K}$．アイドル（S2）ではそれより低い（項目 11）．

### REQ-33：熱効率の損失の内訳

**要求**：運転中の機関の正味の図示熱効率 $\eta_i$ が，オットーサイクルの理論熱効率から，どの損失でどれだけ下がっているかを，損失ごとの段（滝の図）で示すこと．置き場所は上のタブ「熱効率」とする．

* **正味熱効率まで**：正味の図示熱効率から機械損失（摩擦と補機の仕事）を引いた正味熱効率 $\eta_b$ も，同じ図の続きに示す．
* **圧縮比の定義**：幾何の圧縮比 $\varepsilon$（設定値．理論熱効率の基準）と，弁時期で決まる有効圧縮比（吸気弁が閉じた時点の容積と隙間容積の比），有効膨張比（排気弁が開く時点の容積と隙間容積の比）を区別し，後の 2 つを段の名前に値で示す．膨張比が圧縮比より大きい運転（ミラーサイクル，アトキンソンサイクル）であることが，膨張比と圧縮比の比で分かること．
* **損失**：有効圧縮比（吸気弁の閉じる時期），燃え残り（燃焼効率と，気化が間に合わず燃えなかった燃料），比熱比の低下（比熱の温度変化と組成），熱解離，燃焼の遅れ（等容度），冷却損失，有効膨張比（排気弁の開く時期．排気の吹き出し），ポンピング．
* **求め方**：直前のサイクルの吸気弁が閉じた時点の筒内の状態から，条件を 1 つずつ実際に近づけた閉じた系の再計算をして，段ごとの熱効率の差を損失とする．
* **値の表示**：等容度と，燃焼割合 $50\%$ の時期（CA50）も示す．
* **熱物性**：「化学平衡」（既定）のときに示す．ほかの熱物性ではその旨を表示する．

**受入基準**：

1. 理論熱効率 $1 - \varepsilon^{1 - \gamma}$（$\gamma = 1.4$）から損失を順に引いた値が，運転中の機関の正味の図示熱効率 $\dfrac{W}{m_f H_u}$ に一致する（相対 $10^{-9}$．TEST-33 項目 1）．さらに機械損失を引いた値が，正味熱効率 $\dfrac{W - W_f - W_a}{m_f H_u}$ に一致する（相対 $10^{-12}$．項目 1）．
2. 熱伝達ありで実際の燃焼の再計算は，排気弁が開くまで実際の筒内圧と一致する（相対 $10^{-6}$．項目 2）．
3. 壁面の熱伝達を $0$ にした機関では冷却損失が $0$，排気弁が下死点で開く機関では排気の吹き出しの損失が $0$（どちらも $10^{-6}$ 以下．項目 3）．
4. 1 回の計算（再計算 4 回と実際のサイクル）が運転を妨げない：描画のフレームの間隔が $250\ \text{ms}$ 以下（項目 4）．
5. 作動ガスの物性による損失を，燃え残り，比熱比の低下，熱解離の 3 つに分けて示す．解離の無い既燃ガスの内部エネルギーは，高温（$2800\ \text{K}$）で平衡の値より低く，低温（$1000\ \text{K}$）で一致する．燃え残りの損失は，燃えた燃料の割合 $\xi$ から求める（項目 5）．
6. 有効圧縮比が $\dfrac{V(\text{IVC})}{V_c}$，有効膨張比が $\dfrac{V(\text{EVO})}{V_c}$ に一致し，どちらも $1$ より大きく $\varepsilon$ 以下．吸気弁を下死点に近づけて閉じ，排気弁を下死点に近づけて開くと，膨張比と圧縮比の比が変わる（TEST-33 項目 6）．

**仕様**：仕様書 SPEC-33　**検証**：TEST-33

### REQ-34：VVT マップ

### REQ-35：シャシーダイナモメーター

**要求**：試験の種類（1.2a）にシャシーダイナモメーターを設け，車重と空気抵抗係数 $C_d$ を与えると，$0 \to 100\ \text{km/h}$ の時間と最高速度がすぐに分かること．前面投影面積，転がり抵抗係数，駆動系の効率も設定できること．変速機は理想の無段変速機とする（機関を目標回転数に保ち，出力を効率 $\eta_d$ で車輪に伝える）．

* **予測**：今の設定の全開の最大軸出力 $P_{\max}$ を使った準定常の計算で，$0 \to 100\ \text{km/h}$ の時間と最高速度を示す（その機関で出せる最良の値）．車重や $C_d$ を変えたら，その場で値が変わる．
* **実時間の走行**：シャシーダイナモメーターでは，運転中の機関の出力で車速を時間積分し，車速，駆動力，走行抵抗，発進からの $0 \to 100\ \text{km/h}$ の計測値を示す．スロットル開度がアクセルで，全閉では制動する．

**受入基準**：

1. 設定「試験の種類」の既定はエンジンダイナモメーターで，そのとき車両の設定は機関の計算に影響しない（状態が完全に一致．TEST-35 項目 1）．
2. 走行抵抗が $F_{\text{res}} = \tfrac12\rho C_d A v^2 + C_{rr}\,m_v g$ である（相対 $10^{-12}$．項目 2）．
3. 予測の最高速度が $\eta_d P_{\max} = F_{\text{res}}(v_{\max})\,v_{\max}$ を満たす（相対 $10^{-9}$）．走行抵抗と駆動力の上限が無いとき，$0 \to v$ の時間が $\dfrac{m_v v^2}{2\eta_d P_{\max}}$ に一致する（相対 $10^{-9}$）．出力が足りず $100\ \text{km/h}$ に届かないときは，時間を示さず「届かない」と示す（項目 3）．
4. 車重を増やすと $0 \to 100\ \text{km/h}$ の時間が延び，$C_d$ を増やすと最高速度が下がる（項目 4）．
5. 実時間の走行で，全開・目標回転数を保った発進からの $0 \to 100\ \text{km/h}$ の計測値が，その運転点の軸出力から求めた予測と $5\%$ 以内で一致し，機関の回転数が目標の $\pm 25\ \text{rpm}$ に保たれる．全閉にすると停止する（項目 5）．
6. 設定ページ「車両」で，車重か $C_d$ を変えると，同じ操作の中で予測の値が変わる．駆動力と走行抵抗を車速に対して描いた図と，$0 \to 100\ \text{km/h}$ の時間と最高速度の文字が画面に収まる．運転タブの制御状態の表示に車速と $0 \to 100\ \text{km/h}$ の時間が出て，行が折り返さない（項目 6，7）．

**仕様**：仕様書 SPEC-35　**検証**：TEST-35

### REQ-36：振動による体感

**要求**：機関の燃焼を，スマートフォンの振動（ブラウザの Vibration API）で手に感じられること．シミュレーションで燃焼が起きるたびに，その時刻に合わせて，決まった短い長さの振動を 1 回与えること．燃焼しないサイクル（失火，燃料カット，モータリング，クランキング）と止まっているときは振動しないこと．端末やブラウザが振動できないときも，ほかの機能に影響しないこと．

* **体感の対象**：燃焼のガス圧によるトルクの脈動（機関を持つ手に，その反力として伝わる）．振動子は振動の長さしか変えられない（強さと波形を指定できない）．脈動の大きさ（負荷）は表さず，燃焼の有無と時刻だけを表す．往復質量の慣性力による振動（1 次，2 次）と，多気筒の振動は表さない．
* **時刻**：振動はシミュレーションの時間の燃焼に合わせる．再生速度 $0.1\times$ では断面図の燃焼に合わせてゆっくり振動し，$1\times$ では実時間の点火の周波数 $\bar N/120$ で振動する．
* **端末での確かめ**（2026-11-21，振動の試験台．Galaxy S26+）：$5\ \text{ms}$ の振動を感じ，$150\ \text{Hz}$（周期 $6.7\ \text{ms}$，振動 $3\ \text{ms}$）でも 1 回ずつ区別できた．1 回の抜けは分かった．Claude アプリ（WebView）でも Chrome でも，claude.ai の枠（iframe）の中で振動した．端末がサイレントモードのときは振動しなかった．

**受入基準**：

1. 運転タブに振動の ON/OFF があり，既定は OFF．OFF にしたとき，全テストの実行中，ページが非表示のときは，振動を止める命令を出す．振動の機能が無い環境では切替を無効にする（TEST-36 項目 5）．
2. 振動の回数が，その間にシミュレーションで起きた燃焼の回数と一致し，各振動が，その燃焼を含むフレームの次のフレームの間（1 フレームの遅れ）に始まる．再生速度によらない（項目 2）．
3. 振動の長さは一定である．続けて起きる燃焼の振動の間隔が決めた値より短いときは，振動をつなぐ（項目 1，3）．
4. 燃焼しないサイクル（燃料カット，モータリング，クランキング）では振動しない（項目 4）．
5. 振動の命令が API の制約（各要素が $0$ 以上の整数の ms，要素の数の上限）を満たし，1 フレームあたりの計算時間が決めた時間以下（項目 1，6）．
6. 振動の ON/OFF で，機関の計算の結果が変わらない（状態が完全に一致．項目 7）．

**仕様**：仕様書 SPEC-36（画面は画面の文書の SPEC-36 D）　**検証**：TEST-36

### 7.2 未決事項と既知の限界
1. **スターターが実機より速い**：燃料 OFF のクランキングが約 $1700\ \text{rpm}$ に達し，始動直後に回転が吹け上がる．アイドルへの整定に約 $12\ \text{s}$ かかる（SPEC-10）．
2. **高い補機負荷での整定**：$T_{\text{aux}} \ge 10\ \text{N·m}$ では整定が遅い．低い目標回転数（$600\ \text{rpm}$）では，スロットル制御の回転数が約 $530$〜$680\ \text{rpm}$ の間を周期約 $6\ \text{s}$ で振れ続ける（開度だけで合わせる制御では，この機関はこの回転数で安定に回らない．動力計制御では起きない．点火時期による補正などの ECU の改良は行っていない．SPEC-12，TEST-12 項目 11）．
3. **アイドルの吸気管圧**：サイクルの終端の値で，始動から $20\ \text{s}$（S2）で $26.6\ \text{kPa}$，$30\ \text{s}$ で $29.1\ \text{kPa}$（実測．壁温が上がるにつれて上がる）．実機の推定（$30$〜$35\ \text{kPa}$）より低めである．吹き返しによる吸気の加熱を入れて，第24版（S2 で $23.5\ \text{kPa}$）からは上がった．ポート壁による吸気の加熱を扱っていないことが一因と考えられる（推定）．
4. **既燃ガスの比熱**：線形の当てはめで，$1\%$ 弱の誤差がある．より正確な Krieger–Borman の多項式は，係数を原典で確認できていないため採用していない（SPEC-02）．
5. **文献で確認できていない値**：Barnes–Moss の相関の係数（SPEC-28），Martyr と Plint の版とページ（SPEC-11）．
6. **吸気ポートの壁との熱のやりとり**：扱っていない（断熱）．吹き返しによる吸気の加熱は上限の見積もりである（SPEC-05）．
7. **排気の温度**（化学平衡のモデルでは解決．第26版の経緯の 32）：熱物性が「化学平衡」のときは，排気ポートのガスの温度を質量とエネルギーの式で求める．熱物性 $\gamma(T)$，$\gamma$ 一定と，排気系モデルが OFF のときは，第26版までと同じく $800\ \text{K}$ 一定である（SPEC-27）．
8. **単気筒であること**：実機と比べる値は多気筒機関からの 1 気筒あたりの換算で，排気量あたりの摩擦や熱損失が同じとは限らない（SPEC-28）．
9. **画面と音の仕様**（REQ-15〜23，26）は，第25版で文書を書き直した．第25版で変えたのは解説タブの文書の閲覧（REQ-16）だけである．第26版で，設定のページ「噴射」，性能曲線の回転数の点と印の間引き，$p$-$V$ 線図の印，線図タブのバルブタイミングの画面を加えた（第26版の経緯）．音は，演出の音の音量の基準の値を既定のモデルに合わせて改めたほかは，第24版から変えていない．
10. **ノッキング**：扱わない．点火は常に MBT が取れるので，実機でリッチにする主な理由（ノックを避けて点火を進められること，排気温の保護）による利得は現れない（第26版の経緯，`docs/report_richburn.md`）．
11. **単一ゾーンでの解離**（第26版）：既燃ガスの平衡組成を筒内の平均温度で評価するので，解離を小さく見積もる（SPEC-29）．
12. **気化潜熱の値**：$h_{fg} = 350\ \text{kJ/kg}$ は，米国石油協会の資料に基づく燃料の物性の表の値（約 $150\ \text{Btu/lb} = 349\ \text{kJ/kg}$，$60\ ^\circ\text{F}$）に当たる．文献によって $305$〜$380\ \text{kJ/kg}$ の幅がある（Heywood の表は $305$）．$305$ にすると，全開・$3000\ \text{rpm}$ の直噴の軸トルクは $1.4\%$ 下がり，リッチでの出力増の比（$\phi = 1.1$ と $1.0$）は変わらない（SPEC-30，`docs/review_v26.md` の 4 節）．
13. **仕様書の「実測」の値**：第26版で測り直したのは TEST-29，TEST-30 と，判定値を改めた項目だけである．ほかは第25版（$\gamma(T)$ が既定）での値のままである．第26版の成果物での全検査の実測値は `docs/measured_v26.md` にまとめてある（仕様書 8 節の冒頭）．
14. **性能曲線の収束の判定と吸気側の組成**：収束の判定（SPEC-26 A の 6）は，軸トルク・点火時期・流量・吸気管圧を見て，吸気側の燃料蒸気の割合は見ない．ポート噴射では，計測の機関は吸気側が空気だけの状態から始まり，燃料蒸気の割合は，設定の値との差が 1 サイクルごとに約 $0.64$ 倍になる速さ（全開・$3000\ \text{rpm}$ の実測．時定数にして約 $2.2$ サイクル）で設定の値に近づく．軸トルクが当量比に対してほぼ平らな $\phi \approx 1.1$ 付近では，割合が $1\%$ 残った状態で判定を満たすことがある（そのときの軸トルクの差は $0.05\%$．`docs/review_v26.md` の 5 節）．手順が「上り」のときは最初の点だけ，「独立」のときは各点に当たる．
15. **エンストの点の表示**：性能曲線の計測でエンストと記録した点（$150\ \text{rpm}$ 未満）はグラフに描かないだけで，点の数や回転数を画面に書き出していない（SPEC-26 A の 4）．
16. **4 弁のモデル**：弁の数は有効開口面積に 2 を掛ける形でだけ入る．流量係数 $C_d = 0.6$ は 2 弁のときと同じとし，弁どうし・弁と壁の間の干渉による流量の低下は入れていない．4 弁の実機の利点のうち，点火プラグを中央に置けることとタンブル流による燃焼の速さは，燃焼の速さのモデル（SPEC-07）に入らない．このため，4 弁にした効果は高回転の吸排気の流れだけに現れる（`docs/review_v26.md` の 11.2 節）．
17. **動力計制御・全開での回転数の振れ**（解決済み．第26版の経緯の 22）：充水率に対する吸収トルクの感度 $k_w\omega^2$ が定格トルクと回転数の 2 乗に比例するのに，PI のゲインが一定だったため，定格を大きくするか目標回転数を上げると制御が不安定になり，振幅数百 rpm のリミットサイクルになっていた．ゲインを感度で規格化した（SPEC-11 の 3）．
18. **音の「出口の反射率」**（解決済み．第26版の経緯の 22）：設定の項目を廃止し，反射は管内の損失と開口端の放射だけで決めるようにした（SPEC-21 B）．
19. **壁温**：化学平衡のモデルでは，壁温は 1 つの設定値（既定 $360\ \text{K}$）で，ヘッド，ライナ，ピストンの温度の違い，暖機による変化，冷却水と油の温度は扱わない．実機の燃焼室の壁（暖機後で約 $400$〜$550\ \text{K}$．推定）に合わせるには設定を上げる．（SPEC-08）．
20. **排気ポートの熱伝達**：定常の管内乱流の式（Dittus–Boelter）で求める．実際の排気ポートでは，排気弁からの噴流のために吹き出しの間の熱伝達がこれより大きい（Caton と Heywood の実験）ので，ポートの壁への熱と排気温度の下がり方を小さく見積もる．排気管（出口側の半分）から外気への放熱は扱わない（SPEC-27）．
21. （欠番．冷却水と放熱器のモデルは採らなかった．第26版の経緯の 32）
22. **振動で表せること**（REQ-36）：振動子は ON と OFF しか指定できず，強さと波形を指定できない．振動は燃焼のたびに $3\ \text{ms}$ の一定で，負荷の違いは表さない（第26版の経緯の 34）．往復質量の慣性力による振動は表さない．振動は，端末のサイレントモードや本体の振動の設定で止まり，ページの側からは分からない（命令は受け付けられる）．振動子の応答（立ち上がりと止まるまでの時間）は端末で違い，確かめたのは Galaxy S26+ だけである．Chrome は振動のパターンを，ページの計算と同じスレッドのタイマーで 1 区間ずつ再生する．計算の負荷でタイマーが遅れると（端末で 1 フレームに $10\ \text{ms}$ の負荷のとき最大 $98\ \text{ms}$），振動の間隔が乱れ，ときどき途切れる．シミュレータは 1 フレームに最大 $9\ \text{ms}$（最速では $24\ \text{ms}$）計算するので，この影響はページの側では避けられない．
23. **性能曲線の計測の 1 回の計算時間**（TEST-26）：判定値 $30\ \text{ms}$ を，7 通りの検証の 2 回で 1 通りずつ超えた（$48.0$，$33.4\ \text{ms}$．ふだんは $8$〜$15\ \text{ms}$）．振動を入れる前の版でも同じ程度にばらつくが，$30\ \text{ms}$ を超えた回は見ていない．（解決．`docs/verification.md` の 30）．新しく開いたページでは毎回 $30\ \text{ms}$ を超えた．原因は，表の節点を初めて作る遅いステップ（$5$〜$27\ \text{ms}$）を，経過時間を 4 ステップごとにしか調べない計測の積分が続けて進めたこと．毎ステップ調べるように直し，それでも残った表を作る 1 ステップ（$33.5\ \text{ms}$ になった）は，計測の前に表を行ごとに作っておくことで直した（仕様書 SPEC-26 B の 1，TEST-26 項目 19，20）．
24. **性能曲線の計測の 1 回の計算時間と GC**（TEST-26．未決）：第26版の燃焼のときだけ $3\ \text{ms}$ の振動の版の 7 通りで，$412 \times 915$（画面のモード）の TEST-26 の「1 回の計算 $\le 30\ \text{ms}$」が 3〜4 回に 1 回ほど超えた（$30.3$，$43.1$，$43.5$，$60.3\ \text{ms}$）．GC の記録（`--js-flags=--trace-gc`）では，$30.3\ \text{ms}$ の回が，ページ全体の major GC（Mark-Compact，ヒープ $55.0 \to 19.7\ \text{MB}$）の停止 $26.4\ \text{ms}$ と重なった．計測だけを新しいページで $15\ \text{s}$ 回すと，major GC は 1 回（停止 $7.5\ \text{ms}$），1 回の計算の最大は $15.3\ \text{ms}$ だった．停止の長さは，それまでのテストで大きくなったヒープと実行の環境の速さで決まり，計測の計算の量ではない．右辺 `fS` は 1 回に約 $440$ バイト（1 ステップに約 $4\ \text{kB}$）の短命なオブジェクトを作る（インライン化されない関数の呼び出しの引数と戻り値の数値の箱と見られる．推定）が，これを減らしても停止は無くならないと見ている．判定の方法（GC の停止を除くか，2 番目に長い回で判定するか）と，右辺の割り当てを減らすかは，利用者が後で決める（`docs/review_v26.md` の 7.2 節の U-7）．
