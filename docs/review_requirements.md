## 1. 物理モデル

### 1.1 A1：比熱比 $\gamma(T)$ が高い

**現状**（REQ-02）：$\tilde\gamma(T) = 1.38 - 6.5 \times 10^{-5}(T - 300) + 1.0 \times 10^{-8}(T - 300)^2$ を，未燃・既燃の区別なく筒内ガス全体に使う．「NASA 熱力学多項式をフィッティング」とあるが，何の気体に当てはめたかが書かれていない．

**問題**：この式の値は空気に近い．火花点火機関の未燃混合気（燃料蒸気を含む）と既燃ガス（$\text{CO}_2$，$\text{H}_2\text{O}$ を含み，高温で解離する）は，同じ温度で $\gamma$ がもっと低い．Klein と Eriksson の整理（量論比，下の出典）と比べると次のとおり．

| $T$ [K] | 現行 | 未燃混合気 $1.3488 - 13.0 \times 10^{-5}(T - 300)$ | 既燃ガス $1.3678 - 9.4 \times 10^{-5}(T - 300)$ |
| ---: | ---: | ---: | ---: |
| $300$ | $1.380$ | $1.349$ | — |
| $700$ | $1.356$ | $1.297$ | $1.330$ |
| $1000$ | $1.339$ | $1.258$ | $1.302$ |
| $2000$ | $1.298$ | — | $1.208$ |
| $2500$ | $1.285$ | — | $1.161$ |

（未燃の当てはめは $300$〜$1000\ \text{K}$，既燃は $500$〜$2700\ \text{K}$ が有効範囲．）

$\gamma$ が高いと $c_v = R/(\gamma - 1)$ が小さく，同じ発熱で温度と圧力が上がりすぎる．膨張で取り出す仕事も増える．

**確かめたこと**：筒内の $\gamma$ だけを差し替えた 2 つの試作を回した（`tools/review/expF.js`，`expH.js`）．
* (i) 温度だけの 2 次式 $\gamma = 1.338 - 6.0 \times 10^{-5}\,T + 1.0 \times 10^{-8}\,T^2$（熱発生解析で使われる形．**係数は記憶によるもので，原典では確認していない**）
* (ii) 未燃分率 $Y_u$ で上の表の 2 本の直線を補間：$\gamma = Y_u\,\gamma_u(T) + (1 - Y_u)\,\gamma_b(T)$

| | 圧縮の指数（$290^\circ \to 340^\circ$） | $1.353$ | $1.302$ | $1.315$ |

* 現行の $T_{\max} = 2950\ \text{K}$（筒内平均温度）と $\eta_i = 0.417$ は高い（推定：単一ゾーンの平均温度の最高は実機の解析で $2400$〜$2600\ \text{K}$ 程度）．
* 未決事項 5（膨張の指数がアイドル $1.42$，部分負荷 $1.36$ で，目安の $1.3$ より高い）は，Woschni 係数ではなく $\gamma$ が原因である可能性が高い．(i) で $1.30$〜$1.36$ になる．
* (ii) の膨張の指数 $1.25$ は目安より低い．解離を含む平衡の $\gamma_b$ を，発熱を $Q_{\text{LHV}}$ で別に与える単一ゾーンにそのまま入れると，効きすぎている可能性がある（推定）．したがって (ii) をそのまま採ることは勧めない．

**提案**：
1. REQ-02 に，$\gamma$ の式が**何の気体のどの範囲の当てはめか**と，文献値との差を書く．
2. 比熱を未燃と既燃で分ける．Klein と Eriksson が勧めるのは $\gamma$ ではなく $c_p$，$c_v$ を燃焼割合で補間する方法（同論文のモデル D1）で，未燃は $c_{p,u} = 1051.9 + 0.387\,(T - 300)$，$c_{v,u} = 777.0 + 0.387\,(T - 300)\ \text{J/(kg·K)}$ の直線，既燃は Krieger–Borman の多項式である．
3. TEST-02 に物性の妥当性の項目を足す（例：未燃 $700\ \text{K}$ で $\gamma = 1.30 \pm 0.02$，既燃 $2000\ \text{K}$ で $1.21 \pm 0.03$）．現在の TEST-02 は $c_p - c_v = R$ と単調性だけで，値を見ていない．
4. 「モデルの結果を尊重する」方針（REQ-28）との関係：これは係数の合わせ込みではなく，物性値の出典を正す話なので，方針とは矛盾しないと考える．ただし全開トルクが約 $1$ 割下がり，TEST-24，26，28 の判定値の見直しが要る．

* **出典**：[M. Klein and L. Eriksson, "A specific heat ratio model for single-zone heat release models"（Linköping 大学，2004）](https://www.fs.isy.liu.se/Publications/Articles/CCSSE_04_MK.pdf)（表 1，表 2 の当てはめ係数．同論文は，線形の $\gamma$ モデルでも筒内圧の誤差が測定雑音の 4〜10 倍になると述べる）．

### 1.2 A2：吸気弁から吹き返した熱が消える

**現状**（REQ-05 4′ の「限界」，REQ-25 8）：吸気マニホールドとポートの温度は $T_{\text{in}} = 298.15\ \text{K}$ 一定．筒内から吹き返したガスは，組成（既燃分）は追跡するが，熱は追跡しない．吹き返したガスは次に $298\ \text{K}$ で戻ってくる．

**問題**：エネルギーの吸い込み口になっている．限界として書かれてはいるが，大きさの評価が無い．

**確かめたこと**（`expA.js`，`expB.js`）：

| 条件 | 吸気弁の逆流／順流 [mg/サイクル] | 逆流が運ぶ余剰エンタルピー [J/サイクル] | 順流の平均温度上昇の上限 |
| :--- | :--- | ---: | ---: |
| アイドル | $31.2$ ／ $123.0$ | $5.34$ | $42\ \text{K}$ |
| $2000\ \text{rpm}$，$f = 0.3$ | $37.5$ ／ $335.0$ | $2.90$ | $8\ \text{K}$ |
| 全開 $3000\ \text{rpm}$ | $55.9$ ／ $581.2$ | $6.51$ | $11\ \text{K}$ |

周期定常では，壁への放熱が無ければ，吹き返した余剰エンタルピーは混合する容積の大きさによらず全量が筒内へ戻る．そこで「逆流の余剰エンタルピーをポートにため，順流の温度に上乗せして返す」試作（断熱・完全混合，$c_p = 1040\ \text{J/(kg·K)}$ 一定．1.3 節の修正も含む）を回した．

| 条件 | 量 | 現行 | 試作 |
| :--- | :--- | ---: | ---: |
| アイドル | 吸気管圧（サイクル平均）[kPa] | $24.3$ | $27.0$ |
| | ポートの平均温度 [K] | $298$ | $333$ |
| 全開 $3000\ \text{rpm}$ | $\eta_v$ | $0.834$ | $0.798$ |
| | 軸トルク [N·m] | $39.6$ | $37.4$ |
| 全開 $5500\ \text{rpm}$ | $\eta_v$ | $0.771$ | $0.744$ |
| | 軸トルク [N·m] | $28.5$ | $26.9$ |

* これは**上限**である．実機ではポート壁への放熱で一部が失われる．
* 未決事項 4（アイドルの吸気管圧が $23.5\ \text{kPa}$ で，実機の推定 $30$〜$35\ \text{kPa}$ より低い）のうち，最大 $2.7\ \text{kPa}$ がこれで説明できる．第20版で「ずれは吸入側にある」とした見立てと整合する．
* 既定の IVC は $264^\circ$（下死点後 $84^\circ$）と遅く，低回転では吸った新気を押し戻す量が多い．逆流の多くはこの押し戻しで，温度はそれほど高くない（逆流の平均で $T_{\text{in}}$ より約 $165\ \text{K}$ 高い）．

**提案**：ポートの余剰エンタルピー $E_p$ $[\text{J}]$ を状態に加える（$h(T) = \int c_p\,dT$，$m_p$ はポートのガス質量）．
$$\frac{dE_p}{dt} = \max(0, -\dot m_{\text{in}})\left[h(T) - h(T_{\text{in}})\right] - \max(0, \dot m_{\text{in}})\left[h(T_p) - h(T_{\text{in}})\right] - G_p\,(T_p - T_{\text{in}}), \qquad T_p = T_{\text{in}} + \frac{E_p}{m_p c_p}$$
順流の上流温度とエンタルピーを $T_p$ で評価する．$G_p$（ポート壁への熱コンダクタンス）を $0$ にすれば上の試作になる．テストは「周期定常で，逆流の余剰エンタルピーの和 $=$ 順流で戻る和 $+$ 壁への放熱」（エネルギーの収支）で判定できる．

### 1.3 A3：流入エンタルピーが温度依存比熱と整合しない

**現状**（REQ-09）：流入エンタルピーを $\dot m\,c_p(T_{\text{up}})\,T_{\text{up}}$，内部エネルギーを $u(T) \approx c_v(T)\,T$ とし，注で「$u(T) = c_v(T) T$ の基準点の選び方によらず…$\frac{dm}{dt}$ の項はエンタルピー流束の中に完全に吸収される」と述べる．

**問題**：比熱が温度によるとき，$u(T) = \int c_v\,dT \ne c_v(T)\,T$ である．注の主張は**定比熱のときだけ**正しい．正しい導出は次のとおり．

比エンタルピーを $h(T) = \int_0^T c_p(T')\,dT'$，比内部エネルギーを $u = h - RT$ とする．流入 $j$（温度 $T_j$）と流出（筒内温度 $T$）に対し，エネルギーの式は
$$m\,c_v(T)\frac{dT}{dt} = -p\frac{dV}{dt} + \dot Q_{\text{comb}} - \dot Q_{\text{wall}} + \sum_j \dot m_j\left(h_j - u(T)\right)$$
（$h_j$ は流入なら $h(T_j)$，流出なら $h(T)$．$\dot m_j$ は流入を正）．状態方程式の微分 $V\frac{dp}{dt} = RT\frac{dm}{dt} + mR\frac{dT}{dt} - p\frac{dV}{dt}$ に代入し，$RT = (\gamma - 1)\,c_v T$ を使うと
$$\frac{dp}{dt} = -\gamma\frac{p}{V}\frac{dV}{dt} + \frac{\gamma - 1}{V}\left[\dot Q_{\text{comb}} - \dot Q_{\text{wall}} + \sum_j \dot m_j\left(h_j - u(T) + c_v(T)\,T\right)\right]$$
となる．流出では $h(T) - u(T) + c_v T = c_p(T)\,T$ で現行と同じ．**流入では $h(T_j) - h(T) + c_p(T)\,T$** であり，現行の $c_p(T_j)\,T_j$ とは単位質量あたり
$$c_p(T_j)\,T_j - \left[h(T_j) - h(T) + c_p(T)\,T\right] = \int_T^{T_j} T'\,\frac{dc_p}{dT'}\,dT'$$
だけ違う．$c_p$ が温度とともに増えるので，冷たい吸気（$T_j < T$）ではこれが負で，現行の式は流入エネルギーを過小に見積もる．

**確かめたこと**（`expA2.js`．真の $h(T)$，$u(T)$ で周期定常 5 サイクルの第一法則の収支を取った）：

| | アイドル | 全開 $3000\ \text{rpm}$ |
| :--- | ---: | ---: |
| 現行の残差（発熱に対する割合） | $0.91\%$（刻みを半分にしても $0.90\%$） | $0.16\%$ |
| 上の式に替えた場合 | $-0.008\%$（刻みを半分にすると $-0.004\%$） | $-0.008\%$ |

現行の残差は刻みを細かくしても減らず，式そのものの誤差である．替えた場合の残差は刻みに比例して減る積分誤差である．性能への影響は，全開 $3000\ \text{rpm}$ で $\eta_v$ $0.8338 \to 0.8256$（$-1.0\%$），軸トルク $39.59 \to 39.09\ \text{N·m}$（$-1.3\%$），アイドルの吸気管圧 $+0.1\ \text{kPa}$．

**提案**：REQ-09 を上の式に改め，注を「定比熱のときに限り…」と直す．$h(T)$ は $c_p = R + R/(\gamma(T) - 1)$ の積分で，$\gamma$ が 2 次式なら閉じた形にも表にもできる（A1 で $c_p$ を直接の多項式にすれば $h$ も多項式になる）．TEST-09 に「**燃焼・熱損失・弁流れを含む周期定常サイクルで第一法則の残差が発熱の $0.05\%$ 以下**」を加える．現在の TEST-09 は弁を閉じた断熱圧縮だけで，流入の項を検査していない．

### 1.4 A4：吸気は空気か，混合気か

* REQ-05 4 (d)：「燃料は当量比 $\phi$ で別途与え，管内質量収支に含めない」（＝吸気は空気）．
* REQ-07 4：「トラップ新気質量 $m_{u,\text{trapped}}$ に含まれる空気質量は $m_{\text{air}} = \frac{m_{u,\text{trapped}}}{1 + \phi/\text{AF}_{\text{stoich}}}$」（＝新気は空気と燃料の混合気）．

スロットルを通ったのが空気なら，その全量が空気で，燃料は $m_f = \phi\,m_u/\text{AF}$ として**加わる**はずである（筒内質量が $6.8\%$ 増える）．実装は REQ-07 の解釈で，スロットルを通った質量の $1/(1 + \phi/14.7) = 93.6\%$ だけを空気とみなす．$\eta_v$（REQ-14）もこの空気質量で定義されるので，スロットルの空気流量から求めた値より $6.4\%$ 小さい．

**提案**：「吸気系を流れるのは予混合気（気体定数は空気と同じ $R$）で，スロットル流量 $\dot m_{\text{th}}$ は混合気の流量である」と REQ-05 に明記し，(d) を直す（実装は変えない）．または，吸気を空気とし燃料質量を筒内に加える（実装が変わる）．前者を勧める．

## 2. 数値解法

### 2.1 B1：硬さの見積もりが過小で，RK4 の既定刻みはアイドルで安定限界を超える

**現状**（REQ-05 5，REQ-25 7，REQ-27 8）：「全開付近で固有値が $10^4\ \text{s}^{-1}$ オーダ」「$\omega_H \lesssim 5 \times 10^3$」「$\omega_E \lesssim 2 \times 10^3$」とし，RK4 の刻み上限 $10^{-4}\ \text{s}$ で安定とする．いずれもマニホールドやランナ単体の見積もりである．

**問題**：最も硬いのは，**弁が開いていて弁の前後の圧力がほぼ等しいとき**の，筒内とポートの間のやりとりである．オリフィスの正則化域（$1 - r_p < \delta_r = 10^{-3}$）では流量が圧力差に比例し，その傾きは $\Psi_{\text{sub}}(1 - \delta_r)/\delta_r \approx \sqrt{2/\delta_r} = 44.7$ と大きい．

**確かめたこと**（`expC.js`，`eig.py`：周期定常の 1 サイクルに沿って $1^\circ$ ごとにヤコビアン $\partial\mathbf f/\partial\mathbf y$ を差分で作り，固有値を求めた）：

| 条件 | $\max|\lambda|$ [1/s] | 場所 | RK4 既定刻みでの $|\lambda|\Delta t$ |
| :--- | ---: | :--- | ---: |
| アイドル | $6.65 \times 10^4$ | $600^\circ$（排気行程） | $6.65$（$\Delta t = 10^{-4}\ \text{s}$） |
| 全開 $3000\ \text{rpm}$ | $3.91 \times 10^4$ | $184^\circ$（吸気下死点付近） | $1.09$ |
| 全開 $6000\ \text{rpm}$ | $8.7 \times 10^3$ | $43^\circ$ | $0.12$ |

RK4 の実軸上の安定限界は $|\lambda|\Delta t \le 2.79$ で，アイドルの既定刻みはこれを超える．実際にアイドルで比べると（`expF.js`，`expI.js`）：

| ソルバ | IMEP [kPa] | $x_r$ | サイクル平均の $\dot m_{\text{in}}$／$\dot m_{\text{ex}}$ [g/s] |
| :--- | ---: | ---: | :--- |
| RK4 $0.02^\circ$，$0.05^\circ$（参照） | $106.81$ | $0.2234$ | $0.6116$ ／ $0.6116$ |
| RK4 $0.5^\circ$（RK4 の既定） | $108.49$（$+1.6\%$） | $0.2173$ | $0.7395$ ／ $0.9088$（$+21\%$，$+49\%$） |
| RK4 $0.25^\circ$ | $107.10$（$+0.27\%$） | $0.2224$ | — |
| DOPRI5（全体の既定） | $106.83$（$+0.01\%$） | $0.2236$ | $0.6084$ ／ $0.6156$（相互に $1.2\%$ の差） |

RK4 $0.5^\circ$ では排気行程の弁流量が振動し（増減の反転 6 回），集計した流量が大きく狂う．状態から求める量（IMEP など）の誤差は $1.6\%$ にとどまる．非線形性（正則化域の外では傾きが小さい）のおかげで発散はしない．DOPRI5 は刻みを自動で縮めて安定限界の内側にとどまるが，アイドルでは $16\%$ のステップが上限より小さく，これは精度ではなく安定性で決まっていると考えられる（推定：そのときの $|\lambda| h$ が DOPRI5 の安定限界の約 $3.3$ に近い）．

**提案**（いずれか）：
1. RK4 の刻み上限を $\Delta t \le 2.5/\max|\lambda|$ になるよう下げる（アイドルで $3.8 \times 10^{-5}\ \text{s}$．既定の $\Delta\theta$ を $0.25^\circ$ にし，上限を $4 \times 10^{-5}\ \text{s}$ にする）．
2. 正則化の幅 $\delta_r$ を広げる（$10^{-2}$ で傾きは $1/\sqrt{10}$ になる．等圧付近の流量が少し変わる）．
3. 要件定義書の「数値上の要件」を，上の表の値に書き換える．硬さを決めているのが弁とポートであることを書く．
4. TEST-13 に「RK4 の既定刻みで，アイドルの IMEP が参照解と $0.5\%$ 以内」を足す．現在の項目 3 は RK4 を $0.25^\circ$・部分負荷でしか試していない．

### 2.2 B2：DOPRI5 は実質的に固定刻み

**確かめたこと**（`expC.js`）：20 サイクルの統計で，刻みが上限 $0.5^\circ\text{CA}$ に張り付いたステップは，アイドルで $84\%$，全開 $3000\ \text{rpm}$ で $100\%$（棄却は $0.7\%$，$0.2\%$）．全開 $3000\ \text{rpm}$ で rtol を変えた結果は次のとおり．

| rtol | ステップ／サイクル | IMEP の誤差 | $p_{\max}$ の誤差 | $\eta_v$ の誤差 |
| ---: | ---: | ---: | ---: | ---: |
| $10^{-4}$ | $1440$ | $1.9 \times 10^{-5}$ | $4.0 \times 10^{-4}$ | $4.1 \times 10^{-6}$ |
| $10^{-5}$（既定） | $1441$ | $4.5 \times 10^{-5}$ | $2.4 \times 10^{-5}$ | $2.3 \times 10^{-5}$ |
| $10^{-6}$ | $1441$ | $1.6 \times 10^{-5}$ | $2.5 \times 10^{-4}$ | $7.3 \times 10^{-6}$ |
| $10^{-7}$ | $1444$ | $7.1 \times 10^{-5}$ | $2.1 \times 10^{-4}$ | $1.1 \times 10^{-5}$ |

（誤差は RK4 $1/64^\circ$ との相対差．）rtol を 3 桁変えても刻み数は変わらず，誤差も減らない．RK4 でも同じで，刻みを $1^\circ$ から $1/32^\circ$ まで半分ずつにしても，IMEP の誤差は $10^{-6}$〜$3 \times 10^{-4}$ の間を不規則に動き，次数が出ない（$p_{\max}$ はほぼ 1 次）．

**解釈**：誤差の床は積分公式ではなく，次の 2.3，2.4 で決まっている．誤差の大きさ（$\le 0.04\%$）は用途には十分で，実害は無い．ただし「rtol で精度を制御できる」「5 次の精度がある」という前提は，この系では成り立っていない．TEST-13 項目 1・2（調和振動子で次数を確認）は公式の実装の検査であって，機関モデルでの精度の検査ではない．

**提案**：REQ-13 に上の事実を書く．精度を上げたいなら 2.3，2.4 を先に直す．直さないなら，設定の rtol は効果がほぼ無いことを画面か解説に書く．

### 2.3 B3：イベントの時刻が刻みで量子化される

実装は，IVC・点火・サイクル終端を「ステップの前後で角度をまたいだか」で検出し，ステップ終端で処理する．
* IVC で記録する基準状態 $(p_{\text{IVC}}, V_{\text{IVC}}, T_{\text{IVC}})$ と $m_{u,\text{trapped}}$ は，真の IVC ではなく最大 $0.5^\circ$ 後の値である．さらに $p$，$V$ はステップ終端，$T$ はステップ始点の値で，**時刻が混ざっている**（`core.js` の `step`）．
* 点火も同様で，燃焼の計算に使う温度はステップ始点，圧力は終端の値である．
* $p_{\max}$，$T_{\max}$ はステップ点の最大値で，真の最大ではない（REQ-13 に記載あり）．
* 弁の開閉（有効面積の折れ点）と Wiebe の開始（$m_w = 0$ では熱発生率が不連続）もステップ内に入る．

**提案**：(a) IVC と点火の角度でステップを切る（次のステップ幅を「イベントまで」に制限する．実装は数行）．(b) 少なくとも基準状態の $T$ を終端の値にそろえる．(c) $p_{\max}$ は最大の前後 3 点の放物線補間にする．(a) を入れれば 2.2 の誤差の床が下がるはずである（未確認）．

### 2.4 B4：サイクルの集計が低次

**現状**（REQ-14）：「台形則積分で正確に更新」．

**実装**：図示仕事は $p$-$V$ の台形則（2 次）．摩擦・補機・動力計の仕事と，スロットル・弁・排気管の流量の積分は**ステップ始点の値 × 刻み（1 次の矩形則）**である．2.1 の表のとおり，既定の DOPRI5 でもアイドルの $\dot m_{\text{in}}$ と $\dot m_{\text{ex}}$ の集計に $1.2\%$ の食い違いがある（真値はどちらも $0.6116\ \text{g/s}$）．

第12版で，既燃ガスの吹き返し量 $B_o$，$B_i$ を「ソルバで同時に積分する補助積分」に替えて同じ問題を解決している（§2.2）．

**提案**：仕事（図示・摩擦・補機・動力計）と各流量も補助積分にする（状態を 10 個ほど足す．誤差判定には含めない）．集計がソルバと同じ次数になり，TEST-05 項目 4，TEST-25 項目 4，TEST-27 項目 4 の許容 $1\%$ を $10^{-4}$ 程度まで締められる．REQ-14 の「台形則」の記述は実装に合わせて直す．
