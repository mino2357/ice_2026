# 調査の記録：積分のヒープの割り当てと，流量関数の折れ目でのステップの棄却（2026-11-22〜23）

外部のレビュー（`docs/changes/2026-11-22-review-gemini-1.md`）の H-1（割り当て）と H-4 の 1（$\Psi$ を $C^1$ にする案）を判断するための実測．実装は変えていない．数値はすべてこの PC（WSL2，Core i5-8350U，Node.js 22.23.5）で実行して得た．

## 1. 割り当て

### 1.1 測り方

`tools/dev/alloc.js`（新設）．全開・$3000\ \text{rpm}$ 固定，サイクル変動 OFF，30 サイクル．

```
node --expose-gc --max-semi-space-size=64 tools/dev/alloc.js 30
```

* **内訳**：V8 の標本のヒーププロファイラ（`HeapProfiler.startSampling`，標本の間隔 64 バイト，GC で回収されたものも数える）で，割り当てた関数ごとのバイト数．
* **合計の照合**：GC の起きない 100 ステップの区間の `heapUsed` の増分も測ったが，構成によって値が大きく食い違い（$4.2$〜$64\ \text{kB}$/ステップ），使えなかった．以下はプロファイラの値だけを使う．
* **1 つ外したときの差**：読み込む前にソースを書き換えて（`alloc.js` の 3 つ目の引数），割り当てを 1 つ外したときの減り方を見た．成果物は変えていない．

### 1.3 分かったこと

1. `this.X`（36 項目のオブジェクトと，その中の `k`）が約 $1.0\ \text{kB}$ で，合計の $24$〜$31\ \%$．
2. `bs3c` の `y3` が約 $0.53\ \text{kB}$（$13$〜$16\ \%$），`step`（`vals` など）が約 $0.28\ \text{kB}$（$7$〜$9\ \%$）．
3. 残りの約 $1.5$〜$2.4\ \text{kB}$（$45$〜$57\ \%$）は，関数の引数・戻り値・オブジェクトの項目の数値の箱と見られる（推定．引き算で求めた）．
4. サイクルごとの割り当て（`cycleEnd` の `Float32Array` 3 本の写し $17.3\ \text{kB}$ など）は，1 サイクルの合計の約 $1\ \%$（計算．プロファイラの表には現れない）．
5. **要件定義書 7.2 節の 24 の推定は，おおむね合っていた**：合計の量（1 ステップに約 $4\ \text{kB}$）は同程度で，数値の箱と見られる分が半分前後を占める．ただし，明示的に作るオブジェクトと配列（`this.X`，`y3`，`vals`）も合わせて約 $1.8\ \text{kB}$（$43$〜$55\ \%$）ある．レビューの H-1 の「明示的な割り当てが直接の源」は半分だけ当たり，`cycleEnd` の写しが大きいという点は当たらない．
6. **GC の停止が減るかは測っていない**．
7. **はじめの記録の訂正**：はじめ，1 回ずつの測定で「`this.X` が約 $45\ \%$，数値の箱は約 $35\ \%$」と書いたが，`burned` の $890\ \text{B}$ が消えたのを `this.X` を外したためと取り違えていた．3 回測り直して上のとおり改めた．

## 2. 流量関数の折れ目とステップの棄却

### 2.1 測り方

`tools/dev/kink.js`（新設）．BS3 の 1 回の試行（`bs3c` の 1 回の呼び出し．2〜4 段目の 3 回の右辺）の中で，流量関数 $\Psi$ の評価が，直線の側（$r_p > 1 - \delta_r$，$\delta_r = 10^{-3}$）と，すぐ外側（$1 - 3\delta_r < r_p \le 1 - \delta_r$）の両方にあった試行を「折れ目をまたぐ」，どちらかがあった試行を「近く」，どちらも無い試行を「遠い」とし，棄却（誤差の見積もり $E > 1$）の率を比べた．どのオリフィスかは区別していない（別のオリフィスが片側ずつでも「またぐ」に数えるので，多めに数える側）．40 サイクル．

```
node tools/dev/kink.js 40
```

### 2.2 結果

### 2.3 分かったこと

1. **折れ目をまたぐ試行は，確かに棄却されやすい**（棄却率 $8$〜$40\ \%$．遠い試行は $1.5$〜$4.6\ \%$）．レビューの指摘（折れ目で誤差の次数が落ちる）と合う．
2. **しかし，全体への効きは小さい**．棄却は全試行の $1.6$〜$4.3\ \%$ で，そのうち折れ目をまたぐ試行は $19$〜$56\ \%$．折れ目による棄却をすべて無くせたとしても，減る試行は全体の $0.7$〜$1.2\ \%$（$4.27\ \% \times 20.65\ \% = 0.9\ \%$ など）にとどまる．棄却の後で刻みが小さくなる分の損は，この数え方には入っていない（測っていない）．
3. **見立て**：$\Psi$ を $C^1$ にしても，右辺の評価の回数は $1\ \%$ 前後しか減らない見込みである．一方で，`psiF`／`psiC` は $\gamma(T)$ の経路も使うので，変えると第25版とのビット一致が崩れる（化学平衡の経路だけ変えると，オリフィスの式が 2 通りになる）．**採らないことを勧める**．判断は利用者．
