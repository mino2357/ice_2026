# 力学系として見た単気筒 SI 機関モデル：サイクルの安定性の数値解析

第20版のモデル（`src/core.js`，状態 14 成分）を力学系として捉え，サイクル定常解の安定性を数値的に調べた報告である．数値はすべて本リポジトリのモデルを実行して得た（再現手順は 9 節）．実機についての記述と，計算で確かめていない解釈は「推定」と明記する．

## 0. 要約

1. 回転数と壁温を固定した系では，サイクル定常解は**漸近安定な周期軌道**である．サイクル写像の Jacobian の固有値（Floquet 乗数）は，調べた 6 条件すべてで単位円の内側にあり，絶対値の最大は $0.57$〜$0.84$ だった．
2. もっとも遅いモードは**吸気管に溜まった既燃ガス**（内部 EGR の貯蔵）で，乗数は混合槽の見積り $\exp(-m_{\text{cyc}}/m_{\text{in}})$ と同程度になる．スロットルがチョークする部分負荷では，吸気管圧の充填モードも同じ大きさの乗数を持つ．
3. MBT 点火制御は，乗数 $1 - K_s\,|\partial\,\mathrm{CA50}/\partial s| \approx 0.40$ のモードを 1 つ加えるだけで，ほかのモードとはほぼ分離している．
4. 回転数を自由にしたアイドル（スロットルの PI 制御）は，積分ゲイン $K_i$ を既定の $2$ 倍にすると周期 $0.57\ \text{s}$ の振動が現れ，$3$ 倍で大振幅のハンチングになる．比例ゲイン $K_p$ は小さすぎても大きすぎても振動する．サイクル写像の言葉では Neimark–Sacker 分岐（連続時間の Hopf 分岐）に当たる（分岐の型は推定）．
5. 「補機負荷 $6\ \text{N·m}$ でアイドルが成立しない」という未決の不具合候補は，**運転状態と停止状態の双安定**だった．運転中から負荷を上げれば $10\ \text{N·m}$ まで回り続けるが，冷間始動では $5\ \text{N·m}$ 以上で運転状態の吸引域に入れない．
6. 実機の希薄・高 EGR 域で知られる周期倍分岐（サイクルが 1 回おきに強弱する現象）は，残留ガス率を $0.72$ まで上げても現れなかった．このモデルには不完全燃焼・失火の機構が無いためである．

## 1. 定式化

### 1.1 状態方程式と位相空間

状態を $\mathbf{y} = (\theta, \omega, p, m, m_u, T_w, p_{\text{in}}, m_{b,\text{in}}, \dot m_r, p_p, m_{b,p}, \dot m_e, p_{pe}, p_m) \in \mathbb{R}^{14}$ とする（記号は要件定義書 2.2 節）．支配方程式は

$$\frac{d\mathbf{y}}{dt} = \mathbf{f}(\mathbf{y};\, \mathbf{u}), \qquad \frac{d\theta}{dt} = \omega$$

で，右辺は $\theta$ について周期 $4\pi$（弁リフト，容積 $V(\theta)$）である．$\mathbf{u}$ は ECU の操作量（スロットル開度 $\alpha$，動力計の充水率 $f$，点火時期 $s$）．したがって位相空間は $\theta$ を $\mathbb{S}^1 = \mathbb{R}/4\pi\mathbb{Z}$ とみた $\mathbb{S}^1 \times \mathbb{R}^{13}$ で，定常運転はこの上の**周期軌道**（リミットサイクル）である．

### 1.2 ハイブリッド系としての性質

このモデルは滑らかな常微分方程式だけではなく，次の離散事象を含む．

- **点火**：$\theta$ が点火角を横切った瞬間に，そのときの筒内状態から着火遅れ $\Delta\theta_d$ と燃焼期間 $\Delta\theta_b$ を決め，以後そのサイクルの熱発生率を固定する（REQ-07）．
- **サイクル終端**：MBT 制御が点火時期を $s_{k+1} = s_k + K_s(\mathrm{CA50}_k - 10^\circ)$，$K_s = 0.6$ と更新する（REQ-12）．$\mathrm{CA50}_k$ は第 $k$ サイクルの燃焼重心のクランク角 [°ATDC]．
- **流れの向きの切替**：弁・スロットルの流量は圧力差の符号で上流側が入れ替わり，右辺は連続だが微分が不連続になる（区分的に滑らかな系）．
- **始動・失火の判定**：完爆，回転数 $150\ \text{rpm}$ 未満での停止．停止状態 $\omega = 0$ は吸収状態である．

したがって全体は，連続状態 $\mathbf{y}$ と離散状態（$s$，燃焼パラメータ，運転モード）を持つハイブリッド力学系である．

### 1.3 サイクル写像

断面 $\Sigma = \{\theta \equiv 0 \pmod{4\pi}\}$（吸気上死点）をとり，$\Sigma$ から出て次に $\Sigma$ に戻るまでの写像を

$$\mathbf{x}_{k+1} = \mathbf{F}(\mathbf{x}_k), \qquad \mathbf{x} = (p, m, m_u, p_{\text{in}}, m_{b,\text{in}}, \dot m_r, p_p, m_{b,p}, \dot m_e, p_{pe}, p_m, s) \in \mathbb{R}^{12}$$

と書く（Poincaré 写像）．サイクル定常解は不動点 $\mathbf{x}^* = \mathbf{F}(\mathbf{x}^*)$，その安定性は Jacobian $J = D\mathbf{F}(\mathbf{x}^*)$ の固有値 $\lambda_i$（Floquet 乗数）で決まり，$\max_i |\lambda_i| < 1$ なら漸近安定である．$|\lambda|$ はその成分が 1 サイクルで何倍に縮むかを表す．

3 節では，性能曲線の計測（REQ-26）と同じく $\omega$ と $T_w$ を固定した系を調べる（$\dot\omega = 0$，$\dot T_w = 0$）．このとき周期は一定なので，$\mathbf{F}$ は「ちょうど 1 サイクル分の時間だけ進める」ストロボ写像に一致する．回転数を自由にした系は 4 節で扱う．

## 2. 時間スケールの分離

モードごとの時定数を見積もると，次のように $10^4$ 倍以上に広がっている．

| モード | 時定数の見積り | 値 |
| :--- | :--- | ---: |
| 壁温 $T_w$ | $C_w/G_w = 1500/15$ | $100\ \text{s}$ |
| 回転数（無負荷アイドル） | $I_{\text{tot}}\,\omega / T$ の程度 | $\sim 1\ \text{s}$ |
| 吸気管の充填・組成 | $m_{\text{in}}/\bar{\dot m}$（4 サイクル前後） | $0.1$〜$0.6\ \text{s}$ |
| サイクル | $120/N$ | $17$〜$150\ \text{ms}$ |
| 排気管の共鳴 | $2\pi/\omega_E$（REQ-27） | $7.3\ \text{ms}$ |
| 吸気ランナの共鳴 | $2\pi/\omega_H$（REQ-25） | $5.4\ \text{ms}$ |

遅い側（$T_w$，$\omega$）を固定して速い側のサイクル定常だけを解くのが性能曲線の計測であり，これは特異摂動の意味での「速い部分系の準定常解」を求めていることになる．逆に，サイクル平均した量だけで $\omega$ と $p_{\text{in}}$ を追うのが平均値モデル（mean value engine model [5]）である．

## 3. 回転数固定でのサイクル定常解の安定性

### 3.1 方法

- 積分は RK4，刻み $0.25^\circ\text{CA}$ 固定（適応刻みの状態を写像に持ち込まないため）．1 サイクル $= 2880$ ステップ．
- $400$ サイクル進めて不動点に落とす．残差 $\max_i |F_i(\mathbf{x}^*) - x^*_i| / |x^*_i|$ は全条件で $3.5 \times 10^{-9}$ 以下．
- $J$ は中心差分で求める：$J_{ij} \approx \dfrac{F_i(\mathbf{x}^* + \epsilon\,\sigma_j \mathbf{e}_j) - F_i(\mathbf{x}^* - \epsilon\,\sigma_j \mathbf{e}_j)}{2\epsilon\,\sigma_j}$．$\sigma_j$ は成分ごとの尺度（圧力・質量は値の $0.2\%$，流量は $2 \times 10^{-5}\ \text{kg/s}$，点火時期は $0.05^\circ$），$\epsilon = 1$ と $0.3$ の 2 通りで計算して差を見る．
- 固有値は numpy で求める．

### 3.2 結果

| 条件 | $\lvert\lambda\rvert$ の大きい順（偏角） | 支配的なモードの成分 |
| :--- | :--- | :--- |
| 全開，$3000\ \text{rpm}$ | $0.634$，$0.412$，$0.206\ (\pm130^\circ)$，$0.071$，$0.047\ (180^\circ)$ | $m_{b,\text{in}}$，$m_{b,p}$ |
| 全開，$3000\ \text{rpm}$，点火固定 | $0.634$，$0.206\ (\pm130^\circ)$，$0.079$，$0.047\ (180^\circ)$ | 同上 |
| 全開，$3000\ \text{rpm}$，ランナ長 $900\ \text{mm}$ | $0.572$，$0.410$，$0.192\ (\pm133^\circ)$，$0.103\ (\pm119^\circ)$ | 同上 |
| 開度 $10^\circ$，$1500\ \text{rpm}$ | $0.777$，$0.750$，$0.427$，$0.219$，$0.120\ (\pm133^\circ)$ | $m_{b,\text{in}}$ |
| 開度 $10^\circ$，$1500\ \text{rpm}$，オーバーラップ $80^\circ$ | $0.80$〜$0.84$，$0.70$〜$0.79$，$0.55$〜$0.70$，$0.21$ | $m_{b,\text{in}}$，$m_{b,p}$，$s$ |
| 開度 $5^\circ$，$800\ \text{rpm}$ | $0.798$（2 個），$0.46$〜$0.56$，$0.19$ | $m_{b,\text{in}}$ ほか |

偏角を書いていないものは正の実数．範囲で書いた値は，$\epsilon$ の 2 通りで結果が違ったもの（残留ガスが多い条件では，流れの向きの切替が増えて写像の滑らかさが落ち，差分が摂動の大きさに敏感になる）．それ以外は 2 通りが $0.002$ 以内で一致した．

**全条件で $\max|\lambda| < 1$** であり，サイクル定常解は漸近安定である．負の実軸に近い乗数は $-0.047$ が最大で，周期倍分岐（$\lambda = -1$）からは遠い．

### 3.3 各モードの解釈

**(a) 吸気管の既燃ガスの貯蔵（$\lambda \approx 0.57$〜$0.84$）．** 吸気管を完全混合の槽とみる．槽内のガス質量を $m_{\text{in}} = p_{\text{in}} V_{\text{in}}/(R T_{\text{in}})$，1 サイクルに筒内へ抜ける質量を $m_{\text{cyc}}$ とすると，槽内の既燃ガス分率 $Y_{b,\text{in}}$ の摂動は，流入が新気だけなら

$$\frac{d\,\delta Y_{b,\text{in}}}{dt} = -\frac{\bar{\dot m}}{m_{\text{in}}}\,\delta Y_{b,\text{in}} \quad\Longrightarrow\quad \lambda_{\text{mix}} = \exp\!\left(-\frac{m_{\text{cyc}}}{m_{\text{in}}}\right)$$

で減衰する．モデルの値を入れると次のとおり．

| 条件 | $m_{\text{in}}$ [g] | $m_{\text{cyc}}$ [g] | $\lambda_{\text{mix}}$ | 計算値 |
| :--- | ---: | ---: | ---: | ---: |
| 全開，$3000\ \text{rpm}$ | $1.760$ | $0.527$ | $0.741$ | $0.634$ |
| 開度 $10^\circ$，$1500\ \text{rpm}$ | $0.975$ | $0.283$ | $0.748$ | $0.777$ |
| 開度 $5^\circ$，$800\ \text{rpm}$ | $0.525$ | $0.136$ | $0.772$ | $0.798$ |

部分負荷では $4\%$ 以内で合う．全開で計算値のほうが小さいのは，ランナを通じた往復流がポートとプレナムの間の混合を強めるためと考えられる（推定）．$\lambda_{\text{mix}}$ が条件によらず $0.75$ 前後なのは，$m_{\text{cyc}}/m_{\text{in}}$ が $V_d \eta_{v,\text{man}} / V_{\text{in}}$（行程容積と吸気管容積の比に吸気管基準の体積効率を掛けたもの）でほぼ決まり，圧力に依らないからである．**吸気管容積 $V_{\text{in}}$ を大きくすると，このモードは 1 に近づく**（収束が遅くなる）．

**(b) 吸気管圧の充填（部分負荷の $\lambda \approx 0.75$）．** スロットルがチョークしていると流入 $\dot m_{\text{th}}$ は $p_{\text{in}}$ に依らず，流出は $\dot m_{\text{in}} \propto p_{\text{in}}$ なので，$p_{\text{in}}$ の摂動も同じ $\exp(-m_{\text{cyc}}/m_{\text{in}})$ で減衰する．開度 $10^\circ$ の $0.750$，開度 $5^\circ$ の $0.798$ の重複がこれに当たる．全開ではスロットルが圧力差を直ちに埋めるので，この遅いモードは現れない．

**(c) MBT 点火制御（$\lambda \approx 0.41$）．** 点火時期を $\delta s$ 進めると燃焼重心はほぼ同じだけ早まる（$\partial\,\mathrm{CA50}/\partial s \approx -1$）．更新則から

$$\delta s_{k+1} = \left(1 + K_s \frac{\partial\,\mathrm{CA50}}{\partial s}\right)\delta s_k$$

で，$J$ の $(s, s)$ 成分は計算値 $0.400$，すなわち $\partial\,\mathrm{CA50}/\partial s = -1.00$ だった．点火固定にするとこの乗数だけが消え，ほかは変わらない（表の 1・2 行目）．制御ループはほかのモードとほぼ分離している．高残留の条件では $(s,s)$ 成分が $0.53$ に増える．希釈で着火遅れが点火時の状態に敏感になるためである．$K_s > 2/|\partial\,\mathrm{CA50}/\partial s| \approx 2$ にすると $\lambda < -1$ となり，点火時期が 1 サイクルおきに振れる周期倍分岐が起きるはずである（未確認．8 節のテーマ 3）．

**(d) 複素共役の対（$|\lambda| \approx 0.2$，偏角 $\pm 130^\circ$）．** 吸気ランナと排気管の共鳴（周期 $5$〜$7\ \text{ms}$）の位相が，1 サイクルの間に整数回からずれた分だけ回転して見えるモードである．弁が開くたびに強く減衰するので $|\lambda|$ は小さい．ランナ長を $900\ \text{mm}$ にすると対が 2 組に分かれて現れる．

## 4. 回転数を自由にしたアイドル：制御ループの安定限界

回転数 $\omega$ と PI 制御器の積分状態 $I_\alpha$ を状態に戻す．スロットル制御は $\alpha = \alpha_b + K_p e + I_\alpha$，$\dot I_\alpha = K_i e$，$e = N_{\text{target}} - \bar N$ である（REQ-12）．既定のアイドル（$800\ \text{rpm}$）の定常から目標を $850\ \text{rpm}$ に上げ，$30\ \text{s}$ 後からの $10\ \text{s}$ 間の $\bar N$ の振れ幅（最大 − 最小）と周期を測った．

| $K_p$ [°/rpm] | $K_i$ [°/(rpm·s)] | 振れ幅 [rpm] | 周期 [s] | 状態 |
| ---: | ---: | ---: | ---: | :--- |
| $0.008$ | $0.002$〜$0.006$ | $7.4$〜$7.9$ | $0.14$ | 安定（振れは爆発ごとのトルク変動） |
| $0.008$ | $0.008$ | $30$ | $0.57$ | 持続振動 |
| $0.008$ | $0.012$〜$0.024$ | $980$〜$1230$ | — | 大振幅のハンチング |
| $0.001$ | $0.004$ | $74$ | $2.2$ | 持続振動 |
| $0.002$〜$0.016$ | $0.004$ | $7.5$〜$13$ | $0.14$ | 安定 |
| $0.03$ | $0.004$ | $285$ | $2.5$ | 持続振動 |

既定値は $K_p = 0.008$，$K_i = 0.004$．周期 $0.14\ \text{s}$ は $850\ \text{rpm}$ の爆発間隔 $120/850 = 0.141\ \text{s}$ で，定常解そのものの振れである．

読み取れること：

- 安定域は $K_i$ について上に，$K_p$ について上下に有界である．既定値から見た余裕は，$K_i$ が約 $2$ 倍，$K_p$ が上に約 $2$〜$4$ 倍，下に約 $1/4$〜$1/8$．
- 不安定化すると，爆発周期とは無関係な遅い周期（$0.6$〜$2.5\ \text{s}$）の振動が現れる．サイクル写像の不動点が複素共役の乗数の対を単位円の外へ出す Neimark–Sacker 分岐（連続時間の平均化系では Hopf 分岐）と解釈できる（推定．乗数は未計算）．
- 物理的な遅れの源は 3 つある．吸気管の充填（3.3 節 (b) の時定数），吸気から膨張までの約 $360^\circ\text{CA}$ の行程遅れ（$800\ \text{rpm}$ で $75\ \text{ms}$），回転数の平均化フィルタ $\tau_N = 0.15\ \text{s}$．積分器と慣性で位相が $180^\circ$ 遅れるところへこれらが加わるので，ゲインを上げると必ず不安定化する．$K_p$ が小さすぎても振動するのは，$K_p$ が与える位相進み（減衰）が足りなくなるためである．
- $K_i \ge 0.012$ の大振幅の状態では，平均回転数が目標より約 $200$〜$300\ \text{rpm}$ 高い．スロットルが全閉と開の間を往復する飽和つきのリミットサイクルで，線形の解析の範囲を出ている．

## 5. 運転状態と停止状態の双安定

補機負荷トルク $T_{\text{aux}}$ を変えて，(i) 既定のアイドル定常から切り替えた場合と，(ii) 冷間始動（スターター）した場合の $25\ \text{s}$ 後を比べた．

| $T_{\text{aux}}$ [N·m] | (i) 運転中から | (ii) 冷間始動 |
| ---: | :--- | :--- |
| $3$，$4$ | $797$，$805\ \text{rpm}$ | $809$，$788\ \text{rpm}$ |
| $5$，$6$ | $794$，$798\ \text{rpm}$（開度 $4.9^\circ$，$5.1^\circ$） | 停止 |
| $8$，$10$ | $830$，$870\ \text{rpm}$ | 停止 |
| $12$ | 停止 | 停止 |

$5 \le T_{\text{aux}} \le 10\ \text{N·m}$ では，**同じ設定に対して運転状態（周期軌道）と停止状態（$\omega = 0$）の 2 つのアトラクタが共存する**．要件定義書 7.2 節の未決事項 6「補機負荷 $6\ \text{N·m}$ でアイドルが成立しない」は，運転状態が存在しないのではなく，冷間始動の軌道が運転状態の吸引域に入れないことが原因だった．始動中のスロットルは固定開度 $6^\circ$ で，完爆（$550\ \text{rpm}$）と判定された瞬間にスターターが切れて PI 制御に移る．そのときの吸気管圧・壁温・積分状態では負荷に勝てず，$150\ \text{rpm}$ を割って停止状態に吸収される（機構は推定）．

$T_{\text{aux}} = 12\ \text{N·m}$ では運転中からでも止まる．平均トルクのつり合い $\bar T_{\text{ind}}(\omega, \alpha) = T_f(\omega) + T_{\text{aux}}$ を満たす安定な解が，制御の応答の範囲で維持できなくなる点で，つり合い解そのものが消えるサドルノード分岐なのか，制御の過渡で吸引域を出るだけなのかは切り分けていない（8 節のテーマ 2）．$8$，$10\ \text{N·m}$ で回転数が目標より $30$〜$70\ \text{rpm}$ 高いのは，回転変動が大きくなって平均が上がるためと考えられる（推定）．

## 6. 残留ガスの帰還と周期倍分岐：このモデルでは起きない

実機の SI 機関では，希薄限界や高 EGR 域で，強い燃焼と弱い燃焼が 1 サイクルおきに交代する現象が知られている．Kantor [1] は残留ガスの温度の帰還から，Daw ら [2] は残留ガスに残る未燃燃料の帰還から，サイクル写像の周期倍分岐としてこれを説明した．機構は，「弱い燃焼 → 残留ガスに未燃分が多い（または温度が低い）→ 次のサイクルの充填と燃焼が変わる → 強い燃焼」という負の帰還が強くなりすぎることである．

本モデルで，回転数 $1000\ \text{rpm}$ 固定，開度 $6^\circ$，点火固定 $25^\circ$ BTDC とし，カム位相でオーバーラップを $80^\circ$ から $160^\circ$ まで広げて残留ガス率を上げた．

| オーバーラップ | $x_r$ | 直近 16 サイクルの IMEP の最小／最大 [kPa] |
| ---: | ---: | :--- |
| $80^\circ$ | $0.366$ | $297.98$ ／ $298.14$ |
| $120^\circ$ | $0.594$ | $311.02$ ／ $311.17$ |
| $160^\circ$ | $0.719$ | $261.68$ ／ $261.80$ |

IMEP の変動は $0.06\%$ 以下で，交代は現れない．3 節の結果（負の乗数が最大 $-0.047$）とも整合する．理由は次の 2 点である．

- Wiebe 関数は残留ガス率に関係なく燃料の $1 - e^{-5} = 99.3\%$ を燃やす．不完全燃焼も失火も無いので，Daw らの機構の入口が無い．
- 残留ガスは層流燃焼速度を下げるが（$\max(0.15,\ 1 - 2.06\,x_r^{0.77})$），乱流項 $6u'$ が支配的なので燃焼期間はほとんど延びない．

このモデルの残留ガスの帰還は正で弱く（3.3 節 (a) の正の実乗数），単調に減衰する．

## 7. 雑音への応答

サイクル変動 ON では，点火のたびに着火時期と燃焼期間へ独立な乱数 $\boldsymbol{\xi}_k$ を加える（REQ-07）．不動点のまわりで線形化すると

$$\delta\mathbf{x}_{k+1} = J\,\delta\mathbf{x}_k + B\,\boldsymbol{\xi}_k$$

という線形の確率差分方程式（VAR(1) 過程）になり，定常な共分散 $\Sigma$ は Lyapunov 方程式 $\Sigma = J \Sigma J^{\mathsf T} + B B^{\mathsf T}$ の解である．$J$ の乗数が正の実数に偏っているので，出力の自己相関は正になるはずである．回転数を自由にした系で $400$ サイクルの IMEP を調べた．

| 条件 | 平均 IMEP [kPa] | 変動係数 | 自己相関 $r_1$，$r_2$，$r_3$ |
| :--- | ---: | ---: | :--- |
| アイドル（$800\ \text{rpm}$） | $106.8$ | $8.05\%$ | $0.22$，$0.32$，$0.16$ |
| $2000\ \text{rpm}$，$f = 0.3$ | $644.1$ | $1.19\%$ | $0.19$，$0.12$，$0.12$ |

自己相関は正で，数サイクルにわたって残る．実機の希薄域で見られる負の相関（1 サイクルおきの交代）とは符号が逆で，6 節の結論と整合する．アイドルで $r_2 > r_1$ となるのは，回転数とスロットルの制御ループ（4 節）を通じた 2 サイクル以上の遅れを持つ帰還のためと考えられる（推定）．アイドルの変動係数が部分負荷の約 $7$ 倍なのは，同じ大きさの燃焼の乱れに対して平均 IMEP が $1/6$ しかないことによる．

## 8. 面白そうなテーマ

実行のしやすさと面白さで並べる．

1. **アイドルの安定領域の地図．** $(K_p, K_i)$ 平面で，回転数つきのサイクル写像の乗数を計算し，$\max|\lambda| = 1$ の曲線を描く．慣性モーメント，吸気管容積 $V_{\text{in}}$，$\tau_N$ に対する境界の動きを見る．境界での乗数の偏角から振動の周期を予測し，4 節の表（$0.57\ \text{s}$，$2.2\ \text{s}$）と照合する．行程遅れを $e^{-s\tau}$ とした平均値モデルの特性方程式との比較もできる．
2. **始動の吸引域とストール．** $(\omega, p_{\text{in}}, I_\alpha)$ の初期値の格子から運転状態に落ちる領域を描き，$T_{\text{aux}}$ とともに縮む様子を見る．運転状態が消える点（5 節の $10$〜$12\ \text{N·m}$）がサドルノード分岐かどうかを，不動点の接続（continuation）で確かめる．未決事項 6 の修正（完爆直後の開度の扱い）の設計根拠にもなる．
3. **MBT 制御ゲインの周期倍分岐．** $K_s$ を $0.6$ から $2$ 超へ上げ，$\lambda = 1 - K_s$ が $-1$ を横切るところで点火時期が 1 サイクルおきに振れることを確かめる．予測が単純で，分岐図（$K_s$ に対する $s_k$ の集積点）を描きやすい．サイクル変動 ON では，分岐の手前で雑音が増幅される（$1/(1-\lambda^2)$）こともテストできる．
4. **不完全燃焼を入れて周期倍分岐からカオスへ．** 燃焼効率を残留ガス率と当量比の関数にして（希釈限界で急落させる），Daw ら [2] の写像を 0 次元モデルの上で再現する．当量比を薄くしていったときの IMEP の戻り写像（$\text{IMEP}_k$ 対 $\text{IMEP}_{k+1}$）と分岐図を，性能曲線タブと同じ仕組みで描ける．
5. **吸気ランナの同調を Floquet 理論で見る．** 弁が周期的に開閉するので，ランナとポートは係数が周期的に変わる振動子（Hill 型の方程式）である．ランナ長 $L_r$ と回転数の平面で体積効率の等高線を描き，乗数の対の偏角が $0$ に近づく（共鳴が 1 サイクルの整数分の 1 に合う）線と，体積効率の山・谷が対応するかを調べる．性能曲線で見えた $250\ \text{rpm}$ 刻みの凹凸の説明になりうる．
6. **遅い多様体への縮約．** 2 節の時間スケールの分離を使い，サイクル平均で $(\omega, p_{\text{in}}, T_w)$ の 3 状態に落とした平均値モデルをこのモデルから数値的に作り（平均トルクと体積効率のマップ），元のモデルの過渡応答と比べる．縮約の誤差が大きくなる条件（ランナの共鳴，高残留）を特定する．
7. **区分的に滑らかな系としての解析．** 3.2 節で，高残留の条件だけ差分が摂動の大きさに敏感だった．流れの向きの切替面を軌道がかすめる（grazing）ことによる写像の非滑らかさを，切替時刻の感度（saltation matrix）を入れた変分方程式で正しく扱い，差分との差を評価する．

## 9. 再現手順と限界

**再現．** `dist/engine.html`（第20版）に対して次を実行する（Playwright と numpy が必要）．

```
node tools/dynamics/floquet.js    # 3 節：不動点と Jacobian を tools/dynamics/A.json に出力
python3 tools/dynamics/eig.py     # 3 節：固有値
node tools/dynamics/scans.js      # 4〜7 節：B（ゲイン），C（オーバーラップ），D（雑音），E（補機負荷）
```

**限界．**

- Jacobian は有限差分で，写像は区分的にしか滑らかでない．乗数の精度は，低残留の条件で $\pm 0.002$，高残留の条件で $\pm 0.05$ 程度とみる（$\epsilon$ の 2 通りの差から）．
- 3 節は RK4・刻み $0.25^\circ$ の離散化の上の結果である．既定の DOPRI5 では刻み幅が状態に加わるため同じ手順が使えない．離散化による乗数のずれは評価していない．
- 4 節と 5 節は時間発展の観察で，乗数や不動点の接続は計算していない．分岐の型は推定である．
- 結論はこのモデルについてのものである．実機との対応を述べた箇所（6 節・7 節）は文献 [1][2] の知見との比較で，本モデルは 0 次元・単気筒・完全燃焼を仮定している．
