# 外部 EGR の検討（熱効率）

2026-11-22．利用者の要求「熱効率を良くしたい／EGR を検討」のための調査．製品のコード（`src/core.js`）は変えていない．試算は `tools/egr/survey1.js`（読み込むときに 1〜2 行を差し替える）．成果物には埋め込まない．

## 1. 今のモデルにあるもの，無いもの

* **ある**：内部 EGR（バルブオーバーラップの吹き返しと残留ガス．REQ-06，24），吸気管の既燃ガスの追跡，残留ガス率 $x_r$ による層流燃焼速度の低下（$1 - 2.1x_r$．SPEC-07），化学平衡の熱物性（既燃ガスの比熱と解離．REQ-29），熱効率の損失の内訳（REQ-33），バルブタイミングの最適化（REQ-32，34）．
* **無い**：外部 EGR（排気を吸気マニホールドへ戻す通路と弁）．ノッキング（要件定義書 7.2 節の 10）．希釈による失火と燃焼の不安定．

## 2. 試算のしかた

* 吸気マニホールドへの既燃ガスの流入を足す：$\dot m_{\text{EGR}} = \frac{x_E}{1 - x_E}\max(\dot m_{th}, 0)$．$x_E$ は EGR 率（マニホールドへ入る流れのうちの既燃ガスの質量の割合），$\dot m_{th}$ はスロットルの流量．
* EGR ガスは，マニホールドの温度まで冷やして入れる（冷却 EGR）．排気側からの取り出し（排気管の流量が減ること）と，EGR 弁の前後の圧力差で流量が決まることは，数えていない（率を直接与えた）．
* 回転数固定，熱物性は化学平衡・直噴，サイクル変動なし．点火時期は自動（CA50 を $10^\circ$ ATDC に合わせる）．スロットルの開度を合わせて，正味平均有効圧 BMEP を目標にそろえた．
* ECU の燃料の計量は，EGR を入れても点火の時点の当量比 $1.000$〜$1.001$ を保った（空気の質量だけを数えているため）．

* **問題**：EGR 率を $50\%$ まで上げても熱効率が上がり続ける（$2000\ \text{rpm}$，開度 $8.8^\circ$ で $\eta_i$ $33.5 \to 38.3\%$）．燃焼期間が $37.4^\circ \to 38.7^\circ$ とほとんど伸びないためで，実機と合わない．

## 4. なぜ燃焼期間が伸びないか

燃焼期間は乱流燃焼速度 $S_T = S_L + C_{\text{turb}}u'$（$C_{\text{turb}} = 6$，$u' = 0.5c_m$）で決まる（SPEC-07 の 2）．$2000\ \text{rpm}$ では乱れの項が約 $18\ \text{m/s}$，層流燃焼速度 $S_L$ は $1\ \text{m/s}$ に満たない．希釈が効くのは $S_L$ だけなので，$S_T$ はほとんど変わらない．変わるのは着火遅れだけである（点火時期が $23 \to 29^\circ$）．

文献の準次元のモデルでは，乱流燃焼速度の乱れの項も層流燃焼速度に依存する．Smith ら（SAE Int. J. Engines，2019）は Zimont の形 $u_t = u_l + A\,u'\,Da^{1/4}$ を使っている（$Da$ は Damköhler 数で $u_l^2$ に比例するので，乱れの項は $u_l^{1/2}$ に比例する）．同じ論文は，EGR による層流燃焼速度の低下の式を機関の実測（$1500\ \text{rpm}$，EGR $5$〜$25\%$）で比べ，Metghalchi–Keck の $1 - 2.1f$（今のモデルの式）は高い EGR 率でやや遅い側だが使える，としている．

## 6. まとめと，製品に入れるなら要ること

1. **外部 EGR の効果はこのモデルで表せる**：部分負荷で，EGR 率 $20\%$ のとき正味熱効率が相対で約 $+4\%$（ポンプ損失，熱損失，比熱比）．
2. **今の燃焼のモデルのままでは，EGR を入れるほど良くなる**．乱れの項に希釈を効かせないと，最適な EGR 率が出ない．燃焼のモデルを変えると，EGR $0\%$ の今の結果とテストの判定値（TEST-07，24 など）にも影響する．
3. **表せないもの**：
   * ノッキングが無いので，高負荷で EGR がノックを抑えて点火を進められる効果（実機の高負荷での主な利点）は出ない．
   * 失火と燃焼の不安定が無いので，EGR 率の上限がモデルから決まらない．上限は設定の範囲（たとえば $0$〜$30\%$）で与えることになる．
   * EGR の経路の応答（弁から筒内までの遅れ）と，圧力差で流量が決まることは，試算では数えていない．
4. **決めること**：EGR 率を直接与えるか（簡単．定常の検討向き），EGR 弁の開度と圧力差から流量を解くか（過渡と高負荷の限界が出る）．冷却 EGR だけか，冷やさない EGR も扱うか．最適化タブの探索に EGR 率を加えるか．

## 7. 試していないもの

* 内部 EGR（今ある最適化タブのバルブタイミングの探索）で同じ点がどこまで良くなるか，との比較．
* 冷やさない EGR，リーン燃焼，圧縮比，遅閉じ（Miller）など，EGR 以外の熱効率の手段．
* 回転数が自由な運転，過渡．
