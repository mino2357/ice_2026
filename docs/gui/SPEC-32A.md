### SPEC-32 A：最適化（バルブタイミング）の画面

1. 上のタブ「最適化」の上端に，`[バルブタイミング]` `[VVT マップ]` の 2 つのボタン（高さ $44\ \text{px}$，文字 $12\ \text{px}$）を置き，下の領域を切り替える（既定はバルブタイミング）．`[VVT マップ]` は SPEC-34．
2. バルブタイミングの領域（上から）：目的の切替 `[軸トルク]` `[正味熱効率]`（既定 軸トルク）．運転状態の 1 行（探索に使う $\bar N$，$\alpha$，$\phi$．機関が回っていないときは「運転タブで START してください」）．操作ボタン `[探索]`（探索中は `[中止]`）`[適用]` `[元に戻す]`．進み具合の 1 行（段階の名前「探索の前の点」「標本」「探索 $k$」「確認 $k$」（$k$ は何番目の始点か），評価の回数，経過時間，それまでの最良の値）．結果の表（IVO，IVC，EVO，EVC，吸気と排気の作用角，オーバーラップ，目的の値について，探索の前と結果を並べ，差を添える）．評価の履歴の図（横軸 評価の番号，縦軸 目的の値．標本の点（粗い許容）は灰の点，それ以外の点（細かい許容）は橙の点，それまでの最良を線で）．
3. **表示の切替**：進み具合の行と段階の表示の下に `[結果]` `[弁時期]` `[軌跡]` の 3 つのボタン（既定は結果）を置き，その下の領域を切り替える．結果は，2 の結果の表と評価の履歴の図．弁時期と軌跡は，1 枚の Canvas に 5，6 の図を描く．図は，実行中の探索，無ければ直前の探索（終了または中止）の記録を描く．探索の最中は毎フレーム描き直すので，評価が進むたびに動く．
4. **段階の表示**：進み具合の行の下の帯（高さ $18\ \text{px}$）．評価した点を，段階と始点の番号が同じ続きごとの区間に分け（「探索の前の点」「標本」「探索 $k$」「確認 $k$」），区間の幅を評価の回数に比例させて並べる．評価の回数が全体の $12\,\%$ 以上の区間には，名前と評価の回数を書く．探索の最中は，最後の区間（いまの段階）を強調する．
5. **弁時期の図**（バルブタイミングダイヤグラム）：円の上を上死点，下を下死点とし，クランク角 $\theta$ の位置を，上から時計回りに $\theta \bmod 360^\circ$ の角度に置く．外の輪に排気弁の開いている区間 $[\text{EVO}, \text{EVC}]$，内の輪に吸気弁の区間 $[\text{IVO} + 720^\circ, \text{IVC} + 720^\circ]$ を，弧で描く．
   * 探索の前の弁時期は灰の破線，それまでの最良の点は太い弧（排気は橙，吸気は青），いま評価している点は細い紫の弧（排気は外の輪のさらに外，吸気は内の輪のさらに内）．
   * 最良の点の 4 つの角の値（IVO，IVC，EVO，EVC）を弧の端に書き，円の中に輪の説明と，重なり $\text{EVC} - (\text{IVO} + 720^\circ)$ を書く．
   * 円の半径は，Canvas の幅の半分から $62\ \text{px}$，高さの半分から $24\ \text{px}$ を引いた小さい方（文字が Canvas の中に収まるように）．
6. **探索の軌跡**：左に吸気の平面（横軸 IVO，縦軸 IVC），右に排気の平面（横軸 EVO，縦軸 EVC）を並べる．
   * 評価した点：標本（粗い許容）は灰の輪，それ以外は目的の値で色分けした点（viridis．細かい許容の点の値の下から $30\,\%$ の位置を暗い端，最大を明るい端にする）．
   * 中心の移った経路：1 つ目の始点からの探索は実線，2 つ目は破線．
   * 信頼領域の枠：いまの中心 $\pm \Delta$ の正方形（紫．探索の最中だけ）．
   * 印：○ 探索の前の点，★ それまでの最良の点，紫の輪 いま評価している点（大きさが周期的に変わる．探索の最中だけ）．枠の外の点の印は，枠の縁に寄せる．
   * 軸の範囲：標本の段では，評価した点の全部と評価中の点を含む範囲．信頼領域の探索が始まった後は，その探索の点と中心 $\pm \Delta$ と探索の前の点を含む範囲（遠くの標本は範囲に入れず，枠で切る）．どちらも幅の $6\,\%$（最低 $4^\circ$）の余白を足す．目盛の数字は範囲の両端．
7. `[適用]` は，設定の IVO，IVC，EVO，EVC を結果の値に書き換える（設定タブの操作と同じ経路で，`[元に戻す]` の履歴に 1 回の操作として積む）．運転中の機関にも直ちに反映する．`[元に戻す]` は設定タブの `[元に戻す]` と同じ．
8. 探索は描画のループの中で時間を区切って進める（1 フレームに $12\ \text{ms}$．運転中の機関の計算とは別の複製で行うので，運転タブの機関は回り続ける）．タブを離れても探索は続く．
