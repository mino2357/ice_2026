### TEST-31：全体図（系統図）（REQ-31，SPEC-31）
1. [U]（開く・戻る）上のタブに「全体」が無い．運転タブの機関断面図の右上に `[全体図]`（$44 \times 44\ \text{px}$ 以上，文字が収まる，断面図の領域の中）があり，タップすると全体図に切り替わって上のタブは「運転」が選ばれた表示のまま．全体図は `[◀ 運転]` と Canvas 1 つで，Canvas の下端と画面の下端の差が $8\ \text{px}$ 以下，ページと容器がスクロールしない．`[系統図]` `[状態網]` のボタンは無い．`[◀ 運転]` をタップすると運転タブに戻る．
2. [A]（要素の一覧）既定の設定の系統図に，大気，スロットル，マニホールド，吸気ランナ，機関，インジェクタ（燃焼室），点火プラグ，排気管，大気に開いた出口，はずみ車，動力計，スターター，補機，ECU と，ECU からスロットル・インジェクタ・点火プラグ・動力計への 4 本の信号線がある．ランナを OFF にすると吸気ランナが無く，マニホールドから吸気ポートへの管がある．排気系モデルを OFF にすると排気管と出口が無く，背圧の矢印がある．ポート噴射にするとインジェクタが吸気ポートにある．
3. [A]（寸法と状態の反映）系統図で，スロットルの板と管の軸のなす角 $= 90^\circ - \alpha$（$\alpha = 0, 6.9, 45, 90^\circ$．相対 $10^{-9}$），吸気の管・ランナ・排気管の太さの比 $= D_t : d_r : d_e$（相対 $10^{-9}$），弁の傘の幅の比 $=$ 吸気弁径 $:$ 排気弁径（相対 $10^{-9}$．既定で吸気のほうが大きい），動力計の弧の角度 $= 2\pi\lvert T_{\text{dyno}}\rvert/T_{\max}$（$T_{\text{dyno}} = 0,\ 0.5T_{\max},\ -0.5T_{\max},\ T_{\max}$．相対 $10^{-9}$）と色（吸収は橙，駆動は緑），枠の向きの語（吸収／駆動）とトルクの絶対値，機関の断面のピストン頂面とクランクピンが運転タブの断面図と同じ縮尺の比で同じ位置にある．
4. [U]（数値の一致）S2 の機関を運転中の機関にして描いたとき，系統図の $p_{\text{in}}$，筒内の $p$（MPa，小数 3 桁），$\bar N$，排気管の $T_X$（K，整数）の文字列が，その時点の状態から仕様の書式で作った文字列と一致する．ECU の枠に，スロットル制御（$T_{\text{dyno}} = 3$）と動力計制御（$12.34$，$-4.1\ \text{N·m}$）で「動力計 吸収（駆動）○ N·m」があり，「充水率」と「f」の語が無い．
5. [U]（重なり無し）数値の枠どうしが重ならず（$1\ \text{px}$ 以上離れる），すべて Canvas の中にある．設定は，既定，ランナ OFF，排気系 OFF，ポート噴射，諸元を範囲の端（$B$，$S$，$l$，$V_{\text{in}}$，$L_r$，$d_r$，$L_e$，$d_e$ の最大と最小）にした場合．
6. [U]（描画の時間）30 回描いた平均が $6\ \text{ms}$ 以下．
