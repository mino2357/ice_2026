### SPEC-26 B：性能曲線タブ（回転数に対する特性の計測）の画面

1. 画面の文言では「計測」と言う（「掃引」は使わない）．
2. 上段に `[計測開始]`（実行中は `[中止]`）と `[基準を消す]`，その下に表示の切替 `[出力]` `[η_v]` `[燃費]` `[点火]` `[条件]` `[前提]` `[マップ]`（`[マップ]` は運転点のマップ．SPEC-37 A），残りの高さにグラフまたは表を置く．`[条件]` と `[前提]` の表示中は状態の表示（3 行）を隠す．
3. **条件**：開度のチェック式のボタン 9 つ，刻み（ボタン 4 つ），厳しさ，流量・状態量の判定，サイクル数（1 行に `[−]` 最少の値 `[+]` `[−]` 最多の値 `[+]`），手順．どれかを変えると，計測済みの結果に「設定が変わりました」と表示する．
4. **前提**：計測の仮定を数値で書き出す表．固定する条件（開度の一覧，回転数の保持，点火，サイクル変動，壁温），回転数の点（範囲，刻み，点数，手順），収束の判定（選んだ厳しさの数値，流量・状態量の判定の有無，最少・最多のサイクル数），計測に使う設定（大気圧，当量比，圧縮比，ボア × ストローク，カムの種類，最大リフト，吸気弁径，IVO・IVC・EVO・EVC（位相を含む），吸気ランナ，排気系（ON なら排気管の長さ $L_e$ と内径 $d_e$，OFF なら排気圧損），補機負荷トルク）．
   * 「計測に使う設定」は，計測の実行中は実行中の計測が複製した設定（見出しは「計測中の設定」），それ以外は現在の適用済みの設定（見出しは「現在の設定（次の計測に使う）」）を示す．計測済みの結果があっても，結果を計測した時点の設定は示さない．
   * 表は，設定の変更（設定画面の値の変更，`[適用]`，`[元に戻す]`，`[既定値]`），計測の開始・中止・完了，「前提」の表示への切替，性能曲線タブへの切替のたびに作り直す．
   * 表示中の曲線が現在と異なる設定・条件で計測したものであるとき（B.7 の古さの注記と同じ判定）は「表示中の曲線は変更前の設定で計測（再計測で更新）」，保留中（未適用）の変更があるときは「保留中の変更は [適用] の後に使う」と，見出しに続けて書く．保留中の値は表に出さない（計測に使わないため）．
5. **グラフ**：`[出力]` は $T_b$ と $P_b$，`[η_v]` は $\eta_v$，`[燃費]` は bsfc と $\eta_b$，`[点火]` は MBT 点火時期と $x_r$．横軸は $N$（$0$〜$7000\ \text{rpm}$，目盛 $1000\ \text{rpm}$ ごと．計測の点は刻みの 1 つ目からで，軸は原点から描く）．縦軸は 0 起点の段階的な自動レンジで，負の値があれば負の側にも広げる．$\eta_v$ は $0$〜$1.2$，$\eta_b$ は $0$〜$0.5$ に固定．$P_b \le 0$ の点では bsfc と $\eta_b$ を描かない．
6. **重ね描き**：選んだ開度の曲線を，開度に応じた色（$10^\circ$ を青，$90^\circ$ を赤とする色相の変化）で重ね，凡例に開度を示す．点は印と線でつなぎ，求まるたびに描き足す．印（半径 $3\ \text{px}$）は，隣り合う点の画面上の間隔が $8\ \text{px}$ 以上のときだけ描く．間隔がそれより狭いとき（刻み $25$，$100\ \text{rpm}$ など）は線だけにし，未整定の点の白抜きの印だけを描く（印が重なって線が太く見えるのを防ぐ）．凡例はプロット領域の中に収まる．
7. **状態の表示（3 行）**：計測中は開度と回転数の進捗．完了後は所要時間，最大の開度の曲線の最大トルクと最大出力（とその回転数），往復なら往復差の最大．3 行目に基準または古さの注記．
8. **基準**：新しい計測が完了したとき，それまでの結果を「基準」として灰色の細い線で重ねる．`[基準を消す]` で消す．中止した計測は基準を置き換えない．
9. 実行中はタブを切り替えても計測を続ける．検証タブの全テストの実行中は計測を始められない．
