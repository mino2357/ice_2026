### SPEC-33 C：熱効率の損失の内訳の画面

1. 上のタブ「熱効率」（4 番目）．ボタンは無く，Canvas を 1 つ（画面の残りの高さ）置く．Canvas に横向きの滝の図：上から，理論（$0$ から $\eta_O$ の棒），8 つの損失（前の段の値から次の段の値までの浮いた棒．損失は赤，利得は緑），正味の図示熱効率（$0$ から $\eta_i$ の棒），機械損失（摩擦・補機．$\eta_i$ から $\eta_b$ までの浮いた棒），正味熱効率（$0$ から $\eta_b$ の棒）．各行の左に名前（Canvas の幅が $520\ \text{px}$ 未満では棒の上の行に），棒の右に値（段は %，小数 1 桁．損失は「$-x.xx$ %pt」）．理論の行の名前は「理論（オットー，圧縮比 ε ○）」．下に 3 行で，(1) 膨張比／圧縮比 $\frac{\varepsilon_e}{\varepsilon_c}$（小数 2 桁）と，その値が $1.05$ より大きければ「膨張比のほうが大きい：ミラーサイクルの向き」，$0.95$ より小さければ「膨張比のほうが小さい」，その間は「ほぼ等しい」，(2) 等容度，CA50，$Q_w/Q_f$，(3) 計算した時点の $\bar N$，開度，燃えた燃料の割合 $\xi$．
2. 計算は，タブを表示している間，前の計算から $1\ \text{s}$ 以上たってサイクルが進んでいれば始め，描画のループの中で 1 フレームに $6\ \text{ms}$ ずつ進める．計算中も前の結果を表示する．
3. 熱物性が化学平衡でないときは「熱物性が「化学平衡」のときに表示します」，機関が回っていないときは「運転タブで START してください」，燃料を噴いていないとき（燃料カット，動力計によるモータリング）は「燃料を噴いていません（燃料カット中は計算しません）」と表示し，内訳は計算しない（SPEC-32 A の 2）．
