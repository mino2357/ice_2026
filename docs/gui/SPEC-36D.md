### SPEC-36 D：振動の画面

1. **運転タブの `[音]` と `[振動]`**：操作ボタンの行（SPEC-15 C の 1）を `[START]` `[FUEL CUT]` `[指標1/2]` `[音]` `[振動]` の 5 つ（幅の比 $2 : 2 : 1 : 1 : 1$．幅 $700\ \text{px}$ 以上では `[指標1/2]` を隠して $2 : 2 : 1 : 1$）にする．`[音]` と `[振動]` は独立に ON／OFF を切り替える．文字は変えず，ON のとき選ばれた色（`on`）にする．どちらも既定は OFF で，設定として保存しない（ページを開き直すと OFF）．`navigator.vibrate` が無い環境では `[振動]` を無効にする．
2. ON にするタップは利用者の操作なので，振動の命令の条件（ページが一度でも操作されていること）を満たす．
3. **設定ページ「音と振動」**：設定ページ「音響」の名前を「音と振動」に改める（振動の設定の項目は無い）．このページの説明の文字（$p$-$V$ 図の上の 1 行）を「振動は，端末のサイレントモードや本体の振動の設定で止まります（画面からは分かりません）」とする．
4. 解説タブの §20「振動による体感」に，振動の時刻の式（SPEC-36 B の 1）と，振動が端末の設定で止まることを書く．
