### TEST-23：目標回転数とスロットル開度のスライダ（REQ-23，SPEC-23）

1. [U] 運転タブに帯・つまみ・`[−]`・`[＋]` があり，ボタンとつまみが $44 \times 44\ \text{px}$ 以上，帯が Canvas の下端に収まり，運転タブがスクロールしない．
2. [U] つまみを押して動かすと，目標回転数が「つまみの位置の値」（SPEC-23 の 2 の対応．位置 $0.7$ より左は $50\ \text{rpm}$，右は $500\ \text{rpm}$ に丸めた値）になり，ソルバの入力とラベルが同じ値になる．左端・右端までドラッグすると $500$，$40000\ \text{rpm}$．位置 $0.85$ で $24000\ \text{rpm}$．
3. [U] トラックのつまみ以外の位置のタップと，そこから始めたドラッグでは，目標回転数が変わらない．
4. [U] `[＋]`・`[−]` で $\pm 50\ \text{rpm}$．$40000\ \text{rpm}$ から `[＋]` を 2 回押すと $40100\ \text{rpm}$ で，つまみは右端，ラベルは `40100`．$500\ \text{rpm}$ で `[−]` は無効．
5. [A] 機関断面図の全要素が帯の上端より上にある（既定の諸元と範囲の端点，$\theta = 0, 180^\circ$．帯が 1 本と 2 本の両方）．文字も帯の上端より上にあり，描く高さ $H = 100, 150, 200, 400\ \text{px}$ で，`OVERLOAD` と `VALVE HIT` が出る状態でも両方の警告が描かれる．
6. [U]（スロットルの帯）動力計制御では運転タブに帯が 2 本（上がスロットル開度，下が目標回転数）あり，スロットル制御では 1 本．スロットルの帯のボタンとつまみが $44 \times 44\ \text{px}$ 以上，帯が Canvas の中にあり，運転タブがスクロールしない．
7. [U]（スロットルの帯の操作）つまみのドラッグで開度が「つまみの位置の値」（$1^\circ$ に丸めた値）になり，ラベルと設定の値と運転中の機関の開度が同じ値．左端・右端で $0$，$90^\circ$．トラックのタップでは変わらない．`[＋]`・`[−]` で $\pm 1^\circ$（$12.34^\circ$ から `[＋]` で $13^\circ$），$90^\circ$ で `[＋]`，$0^\circ$ で `[−]` が無効．
