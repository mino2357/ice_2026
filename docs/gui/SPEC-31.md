### SPEC-31：全体図（系統図）（REQ-31）

#### A. 画面と共通の定め
1. **構成**：上から，`[◀ 運転]` のボタン（幅いっぱい，高さ $44\ \text{px}$．タップで運転タブに戻る），その下に Canvas を 1 つ（画面の残りの高さ）．運転タブの `[全体図]`（SPEC-19 の 8）で開く．上のタブには置かず，表示中は上のタブの「運転」を選ばれた表示にする．グラフのタップの読み取り線（SPEC-15 E）は出さない．
2. **描画**：他のタブと同じく $60\ \text{fps}$ に間引き（SPEC-15 F），運転中の機関（`live`）のその時点の状態と設定から毎回描く．
3. **座標**：設計座標 $400 \times 620$ を，一様な縮尺 $k = \min\left(\frac{W}{400}, \frac{H}{620}\right)$ で Canvas の中央に置く（$W$，$H$：Canvas の CSS の寸法）．文字の大きさは $10k\ \text{px}$ を $9$〜$13\ \text{px}$ に丸めた値 $f$．
4. **圧力の色**：$u = \log_{10}(p/10\ \text{kPa})/\log_{10}500$ を $[0, 1]$ に切り，$u = 0$，$0.38$，$1$ の色 $(60, 110, 210)$，$(150, 160, 175)$，$(220, 70, 50)$（RGB）の間を線形に補間する（$10\ \text{kPa}$ が青，大気圧付近が灰，$5\ \text{MPa}$ が赤）．
5. **数値の枠**：角丸の四角に，1 行目は見出し（太字，要素の色．噴射の枠は淡い緑 `#8ce99a`（インジェクタの緑 `#2f9e44` を明るくした色．吸気の枠が吸気の青を明るくした色であるのと同じ））．2 行目以降は値（$f$ の文字，行の高さ $1.25f$）．枠どうしは重ならず，Canvas の中に収まる（TEST-31 項目 7）．
   * **桁の固定**：値の行は「名前，数値，単位」の 3 つの欄に分ける．数値の欄の幅は，その量の最大の桁数のひな形（数字をすべて `8` にした文字列．例：筒内の圧力 `88.888`（MPa），流量 `−888.8`）の幅とし，数値は欄の右端にそろえる．1 つの枠の中では，名前の欄と数値の欄の幅をそれぞれの最大にそろえる．文の中に数値がある行（ECU の行など）は，数値ごとにひな形の幅の欄を取り，右にそろえて書く．枠の幅は欄の幅の和で決めるので，値が変わっても枠の位置と幅，数値の右端は動かない．値がひな形の桁数を超えたときだけ，欄をその値の幅に広げる．負の値の符号は `−`（U+2212）で書く．
   * 四角の中に中央ぞろえで書く数値（マニホールドの圧力）も，ひな形の幅の欄を中央に置き，その右端にそろえる．
6. **場面の記述**：描く要素の一覧，位置，寸法，数値の文字列を，描画とは別の関数（`sysSpec`）で作る．テストはこの記述を調べる．
7. 単位は Pa 系（筒内は MPa，ほかの圧力は kPa），質量流量は g/s，トルクは N·m．

#### B. 系統図
1. **吸気**：左上から，大気（$p_{\text{atm}}$，$T_{\text{in}}$）→ スロットル（バタフライの板．管の軸となす角が $90^\circ - \alpha$．管の太さ $0.32k\,D_t$ [px/mm]）→ マニホールド（四角．中に $V_{\text{in}}$ と $p_{\text{in}}$．色は $p_{\text{in}}$ の圧力の色）→ 吸気ランナ（ON のとき．太さ $0.32k\,d_r$）→ 機関の吸気ポート．ランナが OFF のときは，マニホールドから吸気ポートへ太さ $0.32k\,D_t$ の短い管でつなぎ，ランナの枠は出さない．
2. **機関**：運転タブの機関断面図（SPEC-19）を，文字を描かずにそのまま縮めて置く（ポート，弁（傘の幅は弁径），点火プラグ，ピストン，連桿，クランク，筒内の色と火炎）．枠の大きさは設計座標で幅 $150$，高さ $300$（上端 $y = 140$）．
3. **噴射**：直噴は燃焼室の吸気側の壁に，ポート噴射は吸気ポートの上にインジェクタ（緑）を描く（ポート噴射は，モデルではスロットルを通る予混合気として扱う（SPEC-30）が，図では実機の位置に描く）．
4. **排気**：排気ポート → 排気管（太さ $0.32k\,d_e$．上へ曲げて右へ出す）→ 開放端（管の端に矢印．「出口（大気開放）」の枠に $A_e$）．消音器は無い．排気系モデルが OFF のときは，排気ポートから右へ短い管と矢印を描き，「背圧 $\Delta p_{\text{ex}}$」の値を添える（排気管と出口の枠は描かない）．
5. **回転系**：クランクの中心から右へ軸，はずみ車，動力計（電動式．円．中に 6 本の軸．軸の向きはクランク角 $\theta$．円の内側に，上端から時計回りに角度 $2\pi\lvert T_{\text{dyno}}\rvert/T_{\max}$ の弧を，吸収なら橙，駆動なら緑で描く．$R_d$：円の半径）．枠に「動力計（電動）」，向き（吸収／駆動）とトルクの絶対値，出力 $P_d$（kW），定格（N·m と kW）．クランクの左にスターター（M の円）と補機の円．
6. **ECU**：左下の枠に，回転数の制御（方式と目標），点火（自動／手動と BTDC の値），噴射（方式，$\phi$，$m_{f,\text{cmd}}$），動力計（「動力計 吸収 12.3 N·m（トルクの PI）」の形．スロットル制御では「（負荷トルク 固定）」）．ECU から，スロットル，インジェクタ，点火プラグ，動力計へ破線を引く．
7. **数値の枠**（左右の列に置く．動力計の枠は，運転の枠の上に $4k$ px の間を空けて収まるよう上へ寄せる）：スロットル（$\alpha$，$D_t$，$\dot m_{\text{th}}$），吸気ランナ（$L_r$，$d_r$，$\dot m_r$），吸気弁（$d_{v,\text{in}}$，$L_v$），噴射（方式，$m_{f,\text{cmd}}$，SOI），点火，機関（$B \times S$，$l$，$\varepsilon$），排気弁（$d_{v,\text{ex}}$，$L_v$），筒内（$p$，$T$，$\theta$ と行程），排気管（$L_e$，$d_e$，$p_{pe}$，$T_X$（K，整数）），動力計（$f$，$T_d$，定格トルク），運転（$\bar N$，$T_b$，$P_b$，IMEP）．流量は瞬時値，$T_b$，$P_b$，IMEP は前のサイクルの値．
