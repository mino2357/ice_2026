### TEST-17：グラフの軸・目盛・自動レンジ（REQ-17，SPEC-17）

1. [A] 目盛：$F \in \{1, 2, 5, \dots, 5000\}$ と $600$，$120$，$3000$，$720$ で，間隔が $\Lambda$ の元で区間の数が 4〜8．諸元連動の上限が $555 \to 600$，$9 \to 10$．
2. [A] 段階型：(a) $F_0 = 5000$ で $M = 4500 \to 6500$ にすると直ちに $10000$，(b) $M = 1500$ を $2.9\ \text{s}$ 与えても変わらず $3.0\ \text{s}$ で $2000$，(c) $M$ が $F$ の $\pm 5\%$ で振れる入力 $60\ \text{s}$ で変更 1 回以下，(d) $F_{\min}$ を下回らず，上限が無い（$F_0 = 20$，$F_{\min} = 1$ の軸に $M = 3 \times 10^7$ で $F = 5 \times 10^7$，$M = 0$ を $4\ \text{s}$ で $F = 1$），(e) リセットで $F_0$，(f) $M = 1200$ 一定を $20\ \text{s}$ 与えると変更はちょうど 1 回，(g) $M = 6500$ で $10000$ に切り替わった $0.5\ \text{s}$ 後に $M = 12000$ を与えると，待たずに $20000$ になる（拡大は待たない）．
3. [A] 帯域型：データ $[795, 805]$ に対し，範囲がデータを含み，刻み $\ge s_{\min}$，区間の数 4〜8．データが範囲を出たら直ちに計算し直す．
4. [U] 線図の 8 画面（①は線形と両対数）の全グラフについて，S3 のデータで計算したレイアウト（軸名・目盛の数値・凡例の矩形）を，現在の Canvas の寸法と，同じ幅で高さ $300\ \text{px}$ と $240\ \text{px}$ の Canvas（文字を大きくした端末などで線図の領域が低くなった場合）で検査する：縦軸名と横軸名があり単位 `[...]` を含む，目盛の数値が各軸 3 個以上，複数系列のグラフに凡例がある，全矩形が Canvas 内にあり互いに重ならない．
5. [U] $p$-$V$ 図に既知の長方形のサイクル（$V \in [100, 500]\ \text{cm}^3$，$p \in [1000, 4000]\ \text{kPa}$）を与えると，4 頂点の座標変換が目盛の位置と $\pm 1\ \text{px}$ で一致し，描いた 4 辺の中点に曲線の画素があり，長方形の中心には無い．
6. [S] S2 の終端で，$p$ 軸の $F$ が $M$ の $1$〜$3.2$ 倍にあり，直近 $5\ \text{s}$ で範囲の変更が 0 回．
7. [U]（クランク角の軸）線図③とカム線図の横軸が $[360, 1080]$（目盛 $360, 540, 720, 900, 1080$），線図②の 3 グラフが $[180, 540]$（目盛 $180, 270, 360, 450, 540$），線図④⑤が $[0, 720]$（目盛 $0, 180, 360, 540, 720$）．各系列の横座標が単調増加で，並べ替えた系列の $\theta = 720^\circ$ の値が元の配列の $\theta = 0$ の値と一致する．
8. [A]（強調）範囲の切替から $0.5\ \text{s}$ 後のレイアウトでは目盛の数値が強調の対象で，$1.5\ \text{s}$ 後は対象でない．
9. [U]（グラフのタップ，SPEC-15 E）線図②のグラフの横 $25\%$ の位置をタップすると，その位置（$\pm 1\%$）に読み取り線が出る．もう一度タップすると消える．
10. [S]（$p$-$V$ 線図の印）S2 の機関で，線図タブの $p$-$V$ 線図の仕様に，線形の表示では `IVO`，`IVC`，`EVO`，`EVC` の 4 つ，両対数の表示ではそれに `IGN`，`CA50`，`SOI`，`EOI`，`p_max` を加えた 9 つの印がある．印の位置が，曲線のデータのその角度の点（$V$，$p$）に一致する．記号がすべて ASCII の文字である．小さい $p$-$V$ 図の仕様では印が 4 つで，記号が無い．ポート噴射にすると `SOI`，`EOI` が無い．
11. [A][S]（印の記号の配置．SPEC-17 A の 5）記号の位置を決める関数に，(a) $6\ \text{px}$ 以内に集まった 5 つの印，(b) プロット領域の四隅の 4 つの印を与えると，記号が互いにも，印にも，領域の枠にも重ならない．記号の無い印には位置を返さない．領域が記号より狭くて置けないときは，最初の候補を領域の中に収めた位置を返す．S2 の機関で IVO・IVC・EVO・EVC を設定範囲の端にした 4 通り（$(-40, 190, 430, 690)$，$(40, 290, 530, 760)$，$(40, 190, 530, 690)$，$(-40, 290, 430, 760)$ [°]，各 2 サイクル）について，バルブタイミングの画面の $p$-$V$ 線図（$344 \times 300$ と $900 \times 500\ \text{px}$）で，記号が互いにも，印にも，枠にも重ならない．重なりは，配置の関数と同じ寸法の規則（記号の高さ $\pm 7\ \text{px}$，印の周り $5 \times 11\ \text{px}$）で，結果に対して数える．
12. [S]（範囲がデータを含む．B）次の 2 つの機関で，20 ステップごと（サイクルの途中）に軸を更新して線図①〜⑦の全グラフの仕様を作り，すべてのグラフのすべての系列の有限な値が範囲 $[a, b]$ の中にあることを確かめる（外に出た点の数 $0$．0 起点の軸では，$-0.002F$ までの負の値は中とみなす．B の 3 の負の側の規則で下限を動かさない大きさ）．(a) 全開・目標 $3000\ \text{rpm}$ の定常から，スロットル開度を $90^\circ \to 5^\circ \to 90^\circ$ と $0.3\ \text{s}$ ずつ変える（過渡）．(b) $B = S = 150\ \text{mm}$，$l = 300\ \text{mm}$，全開，目標 $12000\ \text{rpm}$，定格トルク $500\ \text{N·m}$，定格出力 $2000\ \text{kW}$ の機関を始動から $2\ \text{s}$（それまでの上限 $\dot m_{\text{th}} \le 100\ \text{g/s}$，$\bar N \le 10000\ \text{rpm}$，ピストン速度 $\le 50\ \text{m/s}$ を超える条件）．この条件で，(b) の $\bar N$ の軸の $F$ が $10000$ を超えること．
13. [A][S]（負の値．B の 3）0 起点の段階型の軸（$F = 10$，目盛の間隔 $d = 2$）に，$M = 6.3$，$m = -0.49$ を与えると範囲が $[-2, 10]$．$m = -0.01$（$\lvert m\rvert < 0.002F$）では $[0, 10]$ のまま．$[-2, 10]$ から $m = 0$ を $2.9\ \text{s}$ 与えても変わらず，$3.0\ \text{s}$ で $[0, 10]$ に戻る．$[-2, 10]$ の目盛が $-2, 0, 2, \ldots, 10$．既定のアイドル（動力計制御，開度 $15^\circ$，$800\ \text{rpm}$，始動から $3\ \text{s}$）の機関で，線図④のスロットルの質量流量の系列の最小が負で，その軸の下限が最小以下である（スロットル制御のアイドル S2 では開度が小さく，最小は正である）．
14. [A]（有限でない値．B の評価）データに $+\infty$，$-\infty$，NaN が混じっても，範囲の評価（データの最小・最大）はそれらを除いた有限の値になる．段階型と帯域型の軸に $M = +\infty$ や $m = -\infty$ を与えても，呼び出しが戻り，範囲が変わらない（直す前のコードでは戻らず，テストが止まる）．
