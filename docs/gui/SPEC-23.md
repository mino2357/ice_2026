### SPEC-23：目標回転数とスロットル開度のスライダ（REQ-23）

1. **配置**：機関断面図の下端に高さ $48\ \text{px}$ の帯を重ね，左から `[−]`，スライダ（現在値のラベル付き），`[＋]` を置く．機関断面図は帯の上の領域に収まるよう縮尺を決める．
2. **範囲と刻み**：スライダは $500$〜$40000\ \text{rpm}$．位置 $u \in [0, 1]$ と値の対応は 2 つの線形の区間をつなぐ：$u \le 0.7$ で $N = 500 + \frac{u}{0.7}\cdot 7500$（$50\ \text{rpm}$ に丸める），$u > 0.7$ で $N = 8000 + \frac{u - 0.7}{0.3}\cdot 32000$（$500\ \text{rpm}$ に丸める）．ふだん使う $8000\ \text{rpm}$ 以下を細かく，モータリングで使う高い回転数まで 1 本で届くようにするためである．ボタンは $\pm 50\ \text{rpm}$．目標回転数には上限が無いので，ボタンではスライダの範囲を超えて上げられ，そのときつまみは右端にとどまり，ラベルは実際の値を表示する．下限は $500\ \text{rpm}$．
3. **誤操作の防止**：値を変えるのは，つまみ（当たり判定 $44 \times 44\ \text{px}$ 以上）から始めたドラッグだけとする．トラックのタップと，つまみ以外から始めたドラッグでは値が変わらない．ドラッグ中は指の横位置に合わせて値を直ちに反映する．
4. 設定画面の目標回転数と同じ値で，即時項目として扱う．どちらの制御方式でも目標回転数として働く．
5. 独自実装（`div` と Pointer Events）とし，`input[type="range"]` は使わない．
6. **スロットル開度の帯**（動力計制御のときだけ）：目標回転数の帯の上に同じ形の帯（高さ $48\ \text{px}$）を重ね，左から `[−]`，ラベル「スロットル ○○.○°」，スライダ，`[＋]` を置く．範囲は $0$〜$90^\circ$（位置と値は線形），つまみのドラッグで値を $1^\circ$ に丸め，`[−]`・`[＋]` は $\pm 1^\circ$（$1^\circ$ の格子に乗っていない値からは，格子の隣の値へ）．$0^\circ$ で `[−]`，$90^\circ$ で `[＋]` を無効にする．操作の規則は 3 と同じ．設定のスロットル開度 $\alpha_{\text{manual}}$（即時項目）と同じ値を指す．機関断面図は 2 本の帯の上の領域に収まるよう縮尺を決める．スロットル制御のときは帯を出さない（開度は ECU が決めるため）．
