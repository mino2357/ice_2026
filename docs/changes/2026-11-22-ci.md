## 要件の差分

なし（検証の段階の定義は変えていない．段階 2 を実行する場所に CI を加えた）．

## 決めたこと

* **GitHub Actions**（`.github/workflows/ci.yml`）．どのブランチへの push でも走る．同じブランチの古い実行は取り消す．
  * 点検とビルド：`npm run check`，索引が追跡中のものと同じか，`npm run build`，成果物の保存（`engine-html`）．
  * 段階 2：計算のビット比較と，7 通りの `node tests/headless.js`．機能の検査の FAIL は失敗，性能の記録だけの上限超え（終了コード 2）は警告を出して成功．
  * リリース：`v` で始まるタグで，GitHub のリリースに `engine.html` を付ける．
* **書体**を開発用の計算機と同じにする（Inter と Noto Sans CJK JP．`tools/ci/fonts.conf`）．文字の幅を測る検査があるため．
* **結果の読み方**：このセッションからは Actions の API に届かないが，コミットのチェックの結果と注記（annotation）は読める．失敗したステップの出力の末尾と，7 通りの結果の行を，注記に出すようにした．
* **claude.ai のアーティファクトへの公開は CI からはできない**ので，今までどおりこのセッションの中で行う．

## 検証の結果

* 1 回目：点検が失敗．`CLAUDE.md` を直した後に索引を作り直していなかった（`docs/INDEX.md` が追跡中のものと違う）．CI が見つけた．`npm run check` で作り直して直した．
* 2 回目（commit `776bf76`）：点検とビルドは成功．**ビルドした `dist/engine.html` は追跡中のものと同じ**（警告なし．ビルドは CI でも再現する）．段階 2 は，手元と同じ FAIL（横長の 2 通りの TEST-32「弁時期の図」）を検出して失敗．7 通りの所要 $13.3$ 分（手元は $20.7$ 分）．性能の記録の上限超えは 0 件．
* 3 回目（commit `33c5950`．弁時期の図を直した後）：成功．機能の検査は 7 通りすべて PASS．性能の記録の上限超え 2 件（警告）．7 通りの所要 $21.4$ 分（計算機の速さが実行ごとに違う）．
