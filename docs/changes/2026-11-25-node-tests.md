## 要件の差分

## 作ったもの

* `tools/dev/node_tests.js`：計算だけのテスト（TEST-1，2，4〜7，9〜13，24，28，29．`NODE_IDS`）を Node.js で実行する．`src/core.js`，`audio.js`，`plot.js`，`tests.js` を連結して 1 つの関数の中で読み込み，`runAll` と同じく例外を FAIL とし，テストの後に `endAll` で共有の値を戻す．出力は `run.js` と同じ形．
  * 初めは `vm` の文脈で読み込んだが，ブラウザの 5〜10 倍遅かった（TEST-12：$438\ \text{s}$，ブラウザ $34\ \text{s}$）．`vm` の文脈では最上位の関数の参照が遅い経路を通るためと見て，`node_core.js` と同じく関数の中に包むと速くなった（TEST-12：$22.7\ \text{s}$）．
* `tools/dev/shard.js`：`NODE_IDS` を Node.js の組（`--nn`），残りをブラウザの組（`--n`）に分けて同時に実行できるようにした（試しただけ．下の判断で戻した）．

## 確かめたこと

* **合否**：14 のテストを，ブラウザ（`run.js --only …`）と Node.js（`node_tests.js`）で，省かずに実行した．どちらも 230 件中 FAIL 0 件．
* **値**：性能の記録を除く 228 件のうち，189 件は名前・実測・基準が文字として一致し，39 件は実測が浮動小数点の桁で違った（例：TEST-13 項目 20 の互換の相対差がブラウザ $1.2 \times 10^{-5}$，Node.js $0$．TEST-29 の第一法則の残差の符号）．
* **原因**：Node.js 22（V8 12.4）と Chromium 153 で，`Math.exp`，`pow`，`log`，`sin`，`cos`，`atan2`，`cbrt`，`tanh` など超越関数の結果が違う（20 万点ずつの値のハッシュを比べた．`Math.sqrt` と `Math.hypot` は同じ）．長い時間の積分ではこの違いが広がる．
* **画面のテストを入れたとき**：TEST-3，14 を Node.js で実行すると例外（`U is not defined`，`Base is not defined`）で FAIL になる．

## 所要（開発用の計算機．8 論理 CPU．段階 1 と同じ `--quick`）

| 組の分け方 | 全項目の所要 |
| :--- | ---: |
| ブラウザ 4 組（今の段階 1） | $206\ \text{s}$ |
| ブラウザ 3 組，Node.js 4 組 | $206\ \text{s}$ |
| ブラウザ 3 組，Node.js 2 組 | $194\ \text{s}$ |
| ブラウザ 2 組，Node.js 2 組 | $207\ \text{s}$ |

* Node.js は，同じテストをブラウザより少ない計算で終える（14 のテストを 1 本で順に：Node.js $233\ \text{s}$．ブラウザの組での所要の合計は約 $450\ \text{s}$）．
* それでも全体が縮まないのは，計算機の CPU を使い切っているため．7 組のときは，どのテストも 1 組だけのときの約 2 倍かかった（TEST-21：$53 \to 102\ \text{s}$）．Chromium は 1 組で複数のプロセスを使う．また，組ごとにシナリオ（S2，S4 など）を計算し直す．

## 決めたこと

* 利用者の判断：**段階 1 には入れない**．`node_tests.js` は道具として残す（`tools/dev/README.md`）．
  * 理由：最善の分け方でも $206 \to 194\ \text{s}$（約 6%）しか縮まず，値がブラウザとビット単位で一致しない実行の道筋を段階 1 に増やすほどの得がない．
  * `shard.js`，`verify.js`，`inputs.js`，`times.json`，仕様書 9 節に入れた変更は戻した．
* 使い道：ビルドもブラウザも要らないので，`src/core.js` を変えている途中に計算のテストを手早く回す（例：`node tools/dev/node_tests.js --only 13 --quick`）．合否の判定は，これまでどおりブラウザの `run.js`，段階 1，段階 2 で行う．
* 朝の判断の 12 の残り：(c) 重い計算を Web Worker へ（要件の差分が要る）．
