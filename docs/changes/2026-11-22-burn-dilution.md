# 2026-11-22 燃焼のモデル：乱流燃焼速度に希釈を効かせる（取り下げ）

## 指示

利用者：「要求／外部 EGR は入れないものの，この箇所を直すこと」（外部 EGR の調査で挙げた「燃焼のモデルを直すか：乱れの項に希釈を効かせる変更」を指して）．

## 要件の差分（取り下げ．要件定義書からは戻した）

* REQ-07：要求に「希釈が増えると乱流燃焼速度も下がり，燃焼期間が伸びる」を加え，受入基準 8（$x_r = 0.05 \to 0.30$ で燃焼期間が $1.5$〜$1.65$ 倍．$x_r = 0.05$ では第26版の式と同じ）と 9（化学平衡のモデルだけ．$\gamma$ のモデルは第25版のまま）を加える．
* REQ-13 の 15：「第26版と同じ結果」を「基準の版（モデルの式を最後に変えた時点のコード）と同じ結果」に改める（モデルを変えるので，第26版の値とは合わなくなる）．

## 影響の見積もり（試しに 1 行直して全項目を実行．コードは元に戻した）

乱れの項を $\left(S_L / S_L\rvert_{x_r = 0.05}\right)^{1/2}$ 倍にした版で，全項目（$360 \times 640$）600 件中 FAIL 4 件．

| 検査 | 実測 | 基準 | 見立て |
| :--- | :--- | :--- | :--- |
| TEST-12「S2：アイドル $800 \pm 25\ \text{rpm}$」 | 最大偏差 $29.5\ \text{rpm}$ | $\le 25$ | アイドルは残留ガスが多く（$x_r = 21\%$），燃焼期間が $35.6^\circ \to 45.5^\circ$ に伸びる．残留ガスの揺れが燃焼の揺れになり，回転の振れが少し増える |

アイドル（既定の $800\ \text{rpm}$，Node.js，最後の 6 s）：点火 $17.6 \to 22.3^\circ$ BTDC，燃焼期間 $35.6 \to 45.5^\circ$，回転数の幅 $769$〜$837 \to 764$〜$844\ \text{rpm}$，IMEP の標準偏差 $12.6 \to 15.2\ \text{kPa}$，燃料の流量は同じ（$141.8\ \text{g/h}$）．全開の結果は，残留ガスが $3$〜$6\%$ で基準の $5\%$ に近いので，ほとんど変わらない（全開のテストはすべて PASS）．

## 決めたこと

利用者に式（今の $S_T = S_L + C_{\text{turb}}u'$ を $S_T = S_L + C_{\text{turb}}u'\left(g(x_r)/g(0.05)\right)^{1/2}$ にする案．$g(x_r) = \max(0.15, 1 - 2.1x_r)$）と影響を示したところ，「判断，実装しない／要求も取り下げる」．要件の差分（REQ-07 の受入基準 8，9 と REQ-13 の 15 の言い方）を元に戻した．燃焼のモデルは変えていない．

調査の結果は `docs/report_egr.md`（希釈）と `docs/report_burn.md`（回転数）に残してある．
