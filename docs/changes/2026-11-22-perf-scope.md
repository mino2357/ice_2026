# 性能の記録の上限を，主対象の環境の基準にする（2026-11-22）

## 指示

4 つの環境（Galaxy S26+，iPad Air，Pixel 7，PC）の結果（`docs/report_devices.md`）を受けて，利用者：「A」（上限は主対象の端末の基準とし，ほかの環境では「上限超え（判定しない）」と表示して FAIL に数えない）．

## 要件の差分（取り下げ）

REQ-20 の受入基準 6 と 5.1 節の 3 を，「上限を超えた値を FAIL にするのは，主対象の端末の検証タブでの実行と段階 2 だけ」とする差分を書いて利用者に見せた．利用者：「基本変えない」．意味を確かめると「取り下げて今のまま」．差分は元に戻した（要件，仕様，コードは変えていない）．

## 決めたこと

* 性能の記録の上限と判定の方法は変えない．主対象でない環境（Pixel 7，PC，iPad Air）の検証タブでは，上限を超えた性能の記録を今までどおり FAIL と表示する．その FAIL は，機能の不具合ではなく，主対象の環境の基準に対する計算機の速さの差を表す（`docs/report_devices.md`）．

## 検証の結果

* 変更なし（要件の 2 つの断片が承認済みの時点と同じであることを `npm run delta` で確かめた）．
