## 指示

外部のレビュー（ソースの点検の 3.4）の「`chk()` の相対誤差が基準値 0 の近くで跳ぶ」「長い時間の収支の検査が無い」について，利用者が「(a) chk を直す，(b) 長時間の収支」と判断した（`docs/changes/2026-11-24-review-gemini-6.md` の「朝の判断」の 10）．途中で利用者が「基本的にすべて承認する．止まらず進めて」と指示したので，(b) の要件の差分は見せたうえで承認の返事を待たずに承認済みにした（利用者はその前に差分を見て，承認の質問に「基本的にすべて承認する」と答えた）．

## 要件の差分（承認済み．6be40dc）

* (a)：無い（検査の道具と仕様）．
* (b)：REQ-29 に受入基準 12 を足した：「長い時間の収支：サイクル変動ありで始動から $30\ \text{s}$，途中で開度と目標回転数を 3 回変える運転（直噴とポート噴射，動力計制御とスロットル制御）の通算で，筒内の第一法則の残差（6 と同じ式）が供給した燃料の発熱量の $10^{-4}$ 以下，筒内の質量の収支の残差が吸気弁を通った質量の $10^{-9}$ 以下（項目 16）．」6 節の対応表の REQ-29 の行に「長い時間の収支」を足した．

## 決めたこと

* (a) 数値の検査 `chk` の誤差を $\frac{\lvert\text{実測} - \text{基準}\rvert}{\max(\lvert\text{基準}\rvert, s)}$ にし，量の大きさの尺度 $s$ を渡せるようにした（SPEC-20 の 7）．渡さないときは今までと同じ（基準が $0$ のときは分母 $1$）．基準が差で $0$ に近くなりうる 3 項目に尺度を渡した：BMEP $=$ IMEP $-$ FMEP $-$ AMEP（尺度 IMEP），$P_b$（尺度 $P_i$），PMEP $\cdot V_d = W_{i,\text{net}} - W_{i,\text{gross}}$（尺度 $W_{i,\text{net}}$）．TEST-14 の 1・2 に書いた．全 85 か所の `chk` の基準の式を読んで選んだ．今の検査で誤って FAIL していたものは無かった（予防）．
* (b) TEST-29 項目 16：化学平衡，サイクル変動あり，3 通り（直噴・動力計制御，ポート噴射・動力計制御，直噴・スロットル制御）で，始動から $1\ \text{s}$ の状態を基準にその後 $30\ \text{s}$（$7.5\ \text{s}$ ごとに開度と目標回転数を変える）の通算の，筒内の第一法則の残差と質量の収支の残差．供給した燃料は，直噴は噴いた質量（$y_{44}$），ポート噴射は吸気弁を通った燃料蒸気（$y_{46}$）．
* 収支は筒内の検査体積で見る（吸気系と排気系を含む全体の収支は含めていない）．
