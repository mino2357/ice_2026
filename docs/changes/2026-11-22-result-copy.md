# 2026-11-22 検証の結果をテキストでコピーする

## 指示

利用者：Galaxy S26+ の検証タブの結果（PASS 36/36，163.2 s）の画面の写真を示し，「Pixel 7，M1 iPad Air でもメトリックを貼る予定／この結果を画像にして貼るのは面倒なので／要求／ここに環境などの情報とともに結果をテキストでコピー出来るようにして」．

## 要件の差分（承認済み．利用者：「実装」）

REQ-20 の受入基準 7（`npm run delta`）：検証タブで，結果を環境の情報とともにテキストとしてコピーできる．含めるもの：ビルドの ID，環境（ユーザーエージェント，画面と表示領域の大きさ，画素の比，論理コア数，日時），要約，テストごとの合否と所要時間，FAIL と上限超えの検査，性能の記録の全件．クリップボードに書けないときは選択できる形で表示する．

## 決めたこと

* `[結果をコピー]` を `[全テスト実行]` の右に置いた（幅 2：1）．結果が無いときと実行中は無効．
* テキストの中身と並びは仕様書 SPEC-20 B の 11．ビルドの ID は，成果物の内容の SHA-1 の先頭 8 桁（ビルドのときに入れる）．
* コピーは，クリップボードの API → `execCommand('copy')` → 詳細カードの中の選択できる枠，の順に試す．アーティファクトの枠の中でどれになるかは，実機で試すまで分からない．
* 機種の名前は，ブラウザが `navigator.userAgentData` で教えたときだけ入る．
* テストごとの所要時間を記録するようにした（`RUN.dur`）．
