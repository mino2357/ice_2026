# 2026-11-24 既燃ガスの物性の表の当量比の範囲を $0$ まで広げる

## 指示

外部のレビュー（Gemini）の CRIT-02 について，利用者が「表を広げる（下端を 0 近くまで．表の外に出た回数が 0 の検査を足し，今の版で FAIL を確かめてから）」と判断した（`docs/changes/2026-11-24-review-gemini-6.md` の「朝の判断」の 3）．

## 要件の差分（承認済み．a106191）

* REQ-29 の要求に「既燃ガスの物性の表は，運転中に現れる当量比をすべて範囲に含むこと（範囲の外を端の値に丸めて使わない）」を足した．
* 受入基準 11 を足した：ポート噴射と直噴のそれぞれで，当量比の設定の下限と上限，始動の直後（吸気ポートに燃料がまだ無い間）を含む運転で，表の範囲の外に出た回数が $0$．広げた範囲（薄い側）でも 5（補間の精度）と 9（解の収束）を満たす（TEST-29 項目 15）．
* 6 節の対応表の REQ-29 の行に「表の当量比の範囲」を足した（要件の差分と一緒に利用者に見せて承認された）．

## 決めたこと

* 表の当量比の座標 $\phi_r$ の下端を $0.50$ から $0$ にした（刻み $0.0125$ のまま，81 点 → 121 点）．上端 $1.50$ は，測った運転で超えたことが無いので変えない．
* 下端の $0$ は燃料の無い既燃ガス（空気の平衡組成）．C と H の元素の量が $0$ になるが，それを含む化学種は下限 $10^{-40}$ に張り付き，連立方程式は解ける（下の実測）．
* 範囲の外に出て端に丸めた回数 `GAS.stat.of` を数える（`burned`）．
* $\phi_r$ の方向の偏微分は，範囲の端の上では内側の区間の傾きを使う（以前は端の上で $0$．$\phi_r = 0$，すなわち $\zeta = 0$ ちょうどで傾きが $0$ になるのを避ける）．範囲の外では今までどおり $0$．
* 仕様：SPEC-29 A の 6．解説タブ（§18 の格子）．新しい記号は無い（用語の定義集は変えない）．
* 燃焼のモデルに薄い側の可燃の限界が無いこと（$\phi \approx 0.01$ の混合気も燃える）は，朝の判断の 11 で 7.2 節に記録する．

## 検証の結果

* **先に測ったこと**（Node.js．`node_core.js` で表の下端だけを $0$ にして実行）：$\phi_r = 0$〜$0.5$ の 41 節点で，平衡の解はすべて収束し，解けない連立方程式も $0$．薄い側の節点の中間（$T$ と $\ln p$ の区間の中点）で，補間の誤差は $e_b$ が最大 $1.07\ \text{kJ/kg}$（$\phi_r = 0.00625$，$2425\ \text{K}$，$22\ \text{kPa}$），$R_b$ が相対 $5.2 \times 10^{-5}$．41 節点を作る時間は Node.js で約 $0.76\ \text{s}$．
* **テストを先に**：TEST-29 の項目 5 に $\phi_r = 0.00625$，$0.25625$ を，項目 11 に $\phi_r = 0$，$0.25$ を足し，項目 15 を足した．範囲を広げる前（回数を数える仕組みは入れた状態）の成果物で，項目 5 が FAIL（$e_b$ の差 $1468.55\ \text{kJ/kg}$，$R_b$ 相対 $7.3 \times 10^{-2}$），項目 15 が FAIL（ポート噴射 $\phi = 0.6$：49374 回，$\phi = 1.4$：20659 回．直噴は $0$ 回）することを確かめた．項目 11（平衡を直接解く）は前から PASS．
* 広げた後，TEST-29 は 30 件中 FAIL 0 件（項目 5：$3.59\ \text{kJ/kg}$，$1.9 \times 10^{-4}$．項目 15：4 通りとも $0$ 回）．
