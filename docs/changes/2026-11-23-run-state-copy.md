## 決めたこと（仕様 SPEC-15 K，テスト TEST-15 項目 20）

* **ボタンの位置**：`[コピー]` は機関断面図の右上，`[全体図]` のすぐ下．操作ボタンの行（5 個）に足すと，$360\ \text{px}$ の幅で 1 単位が $44\ \text{px}$ を割る．はじめ `[全体図]` の左に並べたが，$360$，$412\ \text{px}$ の幅で機関の絵の排気側（排気弁とポート）を隠したので，縦に並べた（画面を撮って確かめた）．スライダの帯と重ならないことを検査に入れた（$360 \times 640$ の動力計制御では，ボタンの下端とスライダの帯の上端の間は数 px）．
* **状態**：状態ベクトルの 22 成分を，仕様書 2.2 節の表の並びで `String(v)` で書く（読み戻すと同じ倍精度の数）．配列 `y` の長さは 59 で，22 成分の位置は `EIX`（`src/core.js`）．はじめ `y` の先頭 22 個を書いていて，検査で見つけた．
* **状態の語**：機関断面図と同じ RUN／MOTOR／CRANK／STOP に日本語の説明を付けた．
* **設定**：全項目を設定画面の書式で書き，既定値と違う項目（書式の文字で比べる）に `*` と既定値を付ける．制御が操作している項目も設定の値を書く（操作している今の値は【制御】にある）．
* **変更の記録**：基準サイクルを取るたびに空にする一覧を新しく持つ（今の画面は直前の 1 件しか持たない）．同じ項目を続けて変えたら 1 件にまとめ，元に戻ったら消す（つまみのドラッグで毎フレームの値が並ばないように）．最新の 50 件まで．
* **表示**：成功は「完了」（「コピーしました」はボタンの幅に入らない）．書けないときの枠は断面図の領域に重ね，ボタンを隠さない．
* 貼ったテキストから設定を戻す機能は入れていない（要件に無い）．
* `tools/dev/unused.js` は `...STN` の前の「.」で名前を数え落とすので，展開を使わない書き方にした（道具は変えていない）．
