## 決めたこと

利用者の指示（「A」）で実装した．

1. **既定の解法を BS3(2) にした**（設定「ソルバ」の 3 つ目の選択肢，既定）．最後の段の使い回し（FSAL），刻みの PI 制御，刻みの上限 $5^\circ$ と $2\ \text{ms}$（仕様書 SPEC-13 の 8）．DOPRI5 と RK4 は設定で選べる．
2. **相対許容誤差は $4 \times 10^{-5}$**．調査で勧めた $3 \times 10^{-4}$ は，定常の平均では基準を満たすが，同じ状態から進めた 1 サイクルでは低負荷で当量比が $1.1\%$ ずれることが，実装のテストを書くときに分かった（レポートの 8.1 節）．1 サイクルの差で選び直した．右辺の評価の回数は DOPRI5 の $0.24$ 倍（調査の見積もりは $0.17$〜$0.20$ 倍）．
3. **要件の差分**（承認待ち）：受入基準 11 に「同じ状態から進めた 1 サイクルの差」と「回転数が自由な運転」を加え，12 の値を「$1/2$ 以下（目標）」から「$0.3$ 倍以下」に確定し，16（線図の記録に抜けが無い）を加えた．
4. **テストのシナリオは DOPRI5 のまま**（`mkPT()` に `sol: 1`）．600 件近い判定値は DOPRI5 で求めたもので，モデルの式の検査である．既定の解法の精度は，TEST-13 項目 14〜21 で DOPRI5 の参照解と比べて確かめる（仕様書 SPEC-20 C）．画面を操作する検査（[U]）は，運転中の機関（既定の BS3）で動く．
5. **線図の升**：BS3 は刻みが $0.5^\circ$ より大きいので，ステップの間を線形に補間して升を埋める．
6. **最後の段の使い回しと制御の入力**：使い回す右辺は，ECU と動力計の更新の前の入力での値である（入力の変化は次のステップの 2 段目から効く．仕様書 SPEC-13 の 8）．
7. **互換**：DOPRI5 を選ぶと，解法を加える前のコード（commit `93f480b`）と状態の全成分がビット単位で同じ（`tools/dev/bitcheck.js` に比較を加えた）．アプリの中の検査は相対 $10^{-6}$（JavaScript の処理系で丸めが違うため）．

## 検証の結果

1. **テストを先に**：TEST-13 に項目 14〜22 を加えた（実装の前のコードには `sol = 2` も評価の回数の計数も無いので，どれも成り立たない）．既定の解法の検査（TEST-13 項目 13）を「既定は BS3(2)」に改めた．
2. **段階 1（`npm run verify`）**：`src/core.js` を変えたので，ビット比較と全項目（$360 \times 640$）が選ばれた．
   * 1 回目：600 件中 FAIL 1 件（新しい互換の検査．判定値を相対 $10^{-6}$ にしていたが，基準値を取った Node.js と Chromium の差が $3.5 \times 10^{-6}$ あった）．既存の TEST-29 項目 8 と同じ相対 $10^{-4}$ にし，理由をテスト項目に書いた．ビット単位の一致は `tools/dev/bitcheck.js` で確かめる（Node.js，Chromium とも一致）．
   * 2 回目：同じ 1 件で FAIL．修正の書き換えが当たっていないのを確かめずに実行した（整形で行の終わりが変わっていた）．無駄な実行だった．
   * 3 回目（commit `6ebea7e` の成果物）：PASS 36/36，600 件中 FAIL 0 件．ビット比較は一致．所要 $394\ \text{s}$（テストは $365.8\ \text{s}$）．
3. **性能の記録**（段階 1 では判定しない）：総所要時間 $365.8\ \text{s}$（上限 $360\ \text{s}$）．TEST-13 に加えた検査で約 $8\ \text{s}$ 延びた．段階 2 では上限を超える見込みで，上限か検査の量を利用者と決める必要がある．1 回目に最長フレーム間隔 $346.5\ \text{ms}$（TEST-16．上限 $250\ \text{ms}$）が出たが，2 回目は $159\ \text{ms}$，3 回目は $143\ \text{ms}$ で，再現していない（原因は調べていない）．
4. **実測**（3 回目．詳しくは `docs/report_solver.md` の 8 節）：1 サイクルの差 $0.023\%$ 以内，右辺の評価の回数は DOPRI5 の $0.243$ 倍，全開 $3000\ \text{rpm}$ の 1 サイクルの計算時間 $3.4\ \text{ms}$．50 の運転点では，1 サイクルの差の最大 $0.039\%$，回数の比 $0.199$．
5. **公開**：段階 1 を満たしたので先行版に公開した．正式版は公開していない（段階 2 を実行していない）．
