# 2026-11-25 MathJax の検証用の写しをリポジトリから消す

## 指示

利用者：「数式フォント，レポジトリにある意味あるの？」．数式フォント（Latin Modern Math のサブセット）は 2026-11-16（4d4d2c2）に消してあり，README の「ライセンス」の節だけが古いまま残っていた，と答えた．あわせて，検証用の MathJax 3.2.2（`vendor/mathjax-3.2.2/es5/tex-svg.js`，2.1 MB）の扱いを説明したところ，「テスト用も削除」．

## 要件の差分

なし（要件定義書は検証の MathJax の置き場所を決めていない．仕様書 9 節を直した）．

## 決めたこと

* `vendor/mathjax-3.2.2/`（`tex-svg.js`，`LICENSE`，`README.md`）を消した．
* 検証（`run.js`，`tests/headless.js`）は，新しい道具 `tools/dev/mathjax.js` で同じ版を用意する．初回に cdnjs から取り寄せ，成果物の SRI（`src/doc.js` の `MJX.sri`．sha512）と一致したものだけを `~/.cache/ice_2026/mathjax-3.2.2/es5/` に置く．次からは照合して使う．環境変数 `MATHJAX` で場所を変えられる（そのときも照合し，一致しなければ止める）．
  * 成果物が要求する SRI と照合するので，検証で使う MathJax が実機の読み込むものと同じであることが毎回保たれる（前は `vendor/` のファイルと cdnjs のファイルの一致を 1 回だけ確かめていた）．
  * 代わりに，初回の検証にはネットワークが要る（CI の GitHub Actions も初回に取り寄せる）．
  * 組に分けて同時に実行したとき，同時に取り寄せても互いに壊さないよう，一時ファイルの名前にプロセスの番号を入れる．
* `README.md` の「ライセンス」の節：消したフォントの説明を，MathJax の実際の扱い（実行時に cdnjs から読む．リポジトリと成果物には含めない．検証は取り寄せて照合）に書き換えた．
* 仕様書 9 節，`tools/dev/README.md`，検証の入力（`inputs.js`．`mathjax.js` を足し，変わったら TEST-16 を実行する）を直した．`docs/verification.md`（過去の検証の記録）は当時のままにした．

## 検証の結果

* `node tools/dev/mathjax.js`：キャッシュが無い状態で取り寄せて SRI と一致（2 108 580 バイト），2 回目はキャッシュを使う（0.05 s），中身の違うファイルを `MATHJAX` で指すと「SRI と一致しない」で止まる（終了コード 1）．
* 段階 1（`npm run verify`．TEST-16）：32 件中 FAIL 0 件（数式の組版と SRI の検査を含む）．
* `tests/headless.js` は構文だけ確かめた（段階 2 と CI は実行していない）．
