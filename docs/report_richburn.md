# 直噴の気化潜熱とリッチでの出力増：検討の記録

第26版（REQ-29，REQ-30）の仕様を決めるまでの考察，試算，選ばなかった案をまとめる．成果物には埋め込まない．仕様そのものは仕様書の SPEC-29，SPEC-30，経緯は要件定義書の 7.4 節にある．

## 1. 発端（2026-11-16）

利用者の問い：「直噴を想定した場合，今のモデルではガソリンの気化潜熱分はどう考えているのか」．続けて「入れる．リッチに噴いたときの出力増を表現したい．噴射は 1 回でよい」．

## 2. 第25版のモデルでの扱い

1. **吸気は気化済みの予混合気**（SPEC-05 の 2）：スロットルを通る時点で空気と燃料蒸気が当量比 $\phi$ で混ざっており，マニホールドは等温（$298.15\ \text{K}$）．気化に要る熱は，マニホールドより上流の外界から暗に供給されていることになり，筒内のエネルギーの式に潜熱の項は無い．
2. **発熱量**：$Q_{\text{in}} = m_f H_u \eta_c \epsilon(\phi)$，$H_u = 44.0\ \text{MJ/kg}$．液体の燃料の値と読めば，潜熱（$h_{fg}/H_u \approx 0.8\%$）を燃焼のときにまとめて差し引いたのと同じ収支になる．仕様書は液体か蒸気かを定めていなかった．
3. **気体定数**：混合気も既燃ガスも $R = 287.0\ \text{J/(kg·K)}$．$U = pV/(\gamma - 1)$ が $R$ によらないので圧力の応答は $\gamma$ で決まる，という理由による（SPEC-02 の 2）．その代わり，質量と温度の絶対値がずれる．

## 3. 第25版のモデルはリッチで出力が下がる

全開，点火は自動最適化（MBT），回転数固定の計測（`Sweep`）：

| $\phi$ | 0.8 | 0.9 | 1.0 | 1.05 | 1.1 | 1.15 | 1.2 | 1.3 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| $T_b$ [N·m]，$2000\ \text{rpm}$ | 28.67 | 32.16 | 35.45 | 34.80 | 34.18 | 33.55 | 32.92 | 31.69 |
| $T_b$ [N·m]，$4000\ \text{rpm}$ | 27.60 | 31.46 | 35.04 | 34.34 | 33.65 | 32.96 | 32.29 | 30.94 |
| $T_b$ [N·m]，$6000\ \text{rpm}$ | 12.02 | 15.07 | 17.97 | 17.41 | 16.84 | 16.29 | 15.74 | 14.66 |

$\phi = 1.0$ が最大で，$\phi$ を $0.1$ 増やすごとに約 $4\%$ 下がる．

### 理由

**空気あたりの発熱が減る．** $\phi > 1$ では酸素が尽き，余った燃料は CO と H$_2$ になる．燃料の炭素 1 個あたりの酸素の不足は $b' + d' = \left(2 + \frac{y}{2}\right)\left(1 - \frac{1}{\phi}\right)$（$y = 1.87$），不足 $1\ \text{mol}$ につき約 $265\ \text{kJ}$（CO の $283\ \text{kJ/mol}$ と H$_2$ の $242\ \text{kJ/mol}$ の平均の概算）が出ない．燃料の発熱量を炭素 1 個あたり約 $610\ \text{kJ}$ として

$$\phi\,\epsilon(\phi) \approx \phi - \frac{2.935 \times 265}{610}\,(\phi - 1) = 1 - 0.275\,(\phi - 1)$$

完全燃焼の理想化では，$\phi$ が $0.1$ 増えるごとに空気あたりの発熱が約 $2.8\%$ 減る．

**リッチが出力を増やす機構が無い．**

1. **解離**：高温の既燃ガスでは CO$_2$ ⇌ CO + ½O$_2$ などの平衡で，$\phi = 1$ でも CO と O$_2$ が残り，発熱の一部が上死点付近で出ない．少しリッチにすると O$_2$ が使い切られ，この損が減る．
2. **既燃ガスの組成**：リッチの生成物は 2 原子分子（CO，H$_2$）が増え，比熱比が上がる．第25版の $\gamma_b(T)$ は $\phi$ によらない 1 本の直線．
3. **吸気の冷却**：直噴の潜熱で，噴く量に比例して冷える．

**気体定数だけを組成で変えても燃焼圧は増えない．** $c_v = R/(\gamma - 1)$ の形では，$R_b$ を上げると $c_v$ も同じ比で上がり，定容での圧力上昇 $\Delta p = (\gamma_b - 1)\,Q/V$ は変わらない．効くのは，組成で $\gamma_b$ そのものが変わる分である．

## 4. 直噴の冷却の大きさ（手計算）

$\phi = 1$ で混合気 $1\ \text{kg}$ あたりの燃料は $f = \frac{\phi}{\text{AF}_{st} + \phi} = 0.064$．筒内のガスの熱だけで断熱的に気化すると，$h_{fg} \approx 350\ \text{kJ/kg}$，$c_p \approx 1.1\ \text{kJ/(kg·K)}$ として

$$\Delta T_{\max} = \frac{f\,h_{fg}}{c_p} \approx 20\ \text{K}$$

吸気弁が閉じる前に気化すれば，密度が $\Delta T/T \approx 6\%$ 増える．加えて，ポート噴射で燃料蒸気が押しのけていた空気（燃料のモル分率 $\approx 1.8\%$）が入る．合わせて体積効率が $7$〜$8\%$ 増える見積もりで，ポート噴射から直噴に替えて約 $9\%$ 増えたという実測（SAE 2002-01-0839）と合う．壁やピストンに付いた燃料は壁から熱をもらうので，実際の冷却は上限より小さい．

## 5. 試算（燃料空気サイクル）

`tools/richburn/faircycle.py`．定容燃焼の Otto サイクル，圧縮比 $10$，$p_1 = 100\ \text{kPa}$，$T_1 = 330\ \text{K}$，残留ガス・熱損失なし，燃焼効率 $1$．熱力学のデータは NASA の 7 係数多項式（NASA TM-4513．Cantera の `nasa_gas.yaml` から）．燃料は擬似種 CH$_{1.87}$（モル質量 $110\ \text{g/mol}$，比熱は質量あたりでイソオクタンと同じ，液体の低位発熱量 $44.0\ \text{MJ/kg}$，気化潜熱 $350\ \text{kJ/kg}$）．

| 記号 | モデル |
| :--- | :--- |
| M0 | 第25版相当：$R = 287$ 一定，$\gamma_u(T)$，$\gamma_b(T)$ の直線，発熱 $q = f H_u \epsilon(\phi)$ |
| M1 | 化学種の熱力学，解離なし（リッチは水性ガス反応 $K = 3.5$ 固定） |
| M2 | 6 種（CO$_2$，CO，H$_2$O，H$_2$，O$_2$，N$_2$）の化学平衡 |
| M3 | 10 種（M2 ＋ OH，O，H，NO）の化学平衡 |
| PFI／DI | 予混合（燃料蒸気が空気を押しのける．$T_1$ 固定）／直噴（空気を吸い，液体燃料が定圧・断熱で気化．冷却の上限） |

### 結果

| モデル | IMEP（$\phi = 1$）[kPa] | 最大になる $\phi$ | $\phi = 1$ 比 |
| :--- | ---: | ---: | ---: |
| M0／PFI | 1449 | 1.00 | $\phi = 1.1$ で $-2.8\%$ |
| M1／PFI | 1661 | 1.00 | $\phi = 1.1$ で $-1.3\%$ |
| M1／DI | 1799 | 1.00 | $\phi = 1.1$ で $-0.6\%$ |
| M2／PFI | 1616 | 1.05 | $+0.9\%$ |
| M2／DI | 1754 | 1.10 | $+1.4\%$ |
| M3／PFI | 1601 | 1.10 | $+1.1\%$ |
| M3／DI | 1739 | 1.15 | $+1.7\%$ |

M3／DI の $\phi$ ごとの値（$\phi = 1$ 比）：$1.05$ で $+1.3\%$，$1.10$ で $+1.7\%$，$1.15$ で $+1.7\%$，$1.20$ で $+1.6\%$，$1.30$ で $+1.0\%$，$1.40$ で $+0.3\%$．

### 読み取れること

1. **解離が決め手**：解離を入れない M0，M1 では最大は $\phi = 1$ のまま．M3 では，燃焼直後（約 $2940\ \text{K}$）の既燃ガスに，$\phi = 1$ でも CO が $2.8\%$，O$_2$ が $0.9\%$ 残る．$\phi = 1.1$ では O$_2$ が $0.4\%$ に減る．
2. **直噴の冷却**：$\phi = 1$ で $24.5\ \text{K}$（上限），空気量 $+8.0\%$．リッチでは噴く量が増えるぶん冷却も増え，最大の位置が $1.10$ から $1.15$ に移る．
3. **増え幅は小さく，山は平ら**：$\phi = 1.05$〜$1.25$ で $+1.3$〜$1.7\%$．
4. **6 種と 10 種**：最大の位置が $1.10$ と $1.15$，増え幅が $1.4\%$ と $1.7\%$．断熱火炎温度は 10 種が文献値に合う．
5. **凍結温度**：この理想サイクルでは膨張の終わりが約 $1800$〜$1900\ \text{K}$ で，$1700\ \text{K}$ に届かず，結果に効かなかった．熱損失のあるシミュレータでは効く可能性がある．
6. **基準が動く**：$\phi = 1$，ポート噴射の IMEP は M0 の $1449\ \text{kPa}$ に対して M3 で $1601\ \text{kPa}$（$+10.5\%$）．内訳は，空気量 $+4.5\%$（混合気の気体定数は約 $274\ \text{J/(kg·K)}$ で，$287$ より小さい）と，熱効率 $+4.3\%$（$0.441 \to 0.460$．$\gamma_b(T)$ の直線は 10 種の平衡より既燃ガスの比熱を大きく見ている）．

## 6. 利用者の感覚との照合：なぜ実機はもっと濃く噴くのか

利用者：「当量比 $1.5$ とかで噴けば気化潜熱で筒内温度が下がるから良いと思っていたが，これを見ると $1.1$ くらいが極大なのか．副次的に，本来はノックが避けられて MBT を取りやすいとかあるのだろう」．

この理解は合っている．

* **熱力学だけの最適**は $\phi \approx 1.1$ 付近．冷却は噴く量に比例して効く（空気量が $\phi$ $0.1$ あたり約 $+0.6\%$）が，酸素が尽きた後の余分な燃料は空気あたりの発熱を $\phi$ $0.1$ あたり約 $2.8\%$ 減らす．解離の損が減る効果は，O$_2$ がほぼ無くなる $\phi \approx 1.15$ で頭打ちになる．
* **実機でもっと濃く噴く理由**は，主にノックと排気温である．高負荷ではノックのために点火を MBT より遅らせている．濃くすると，潜熱で圧縮端の温度が下がり，未燃ガスの比熱比も下がるので，エンドガスの温度が下がる．その分だけ点火を進められ（過給機関なら過給圧も上げられ），MBT に近づいた分のトルクが出る．また，排気温が下がる（試算で膨張の終わりは $\phi = 1$ の $1873\ \text{K}$ から $\phi = 1.1$ の $1780\ \text{K}$）ので，タービンや触媒の保護に使う．
* **このモデルではノックを扱わない**（利用者の方針）．点火は常に MBT が取れるので，「濃くすると MBT が取れる」利得は現れず，リッチでの出力増は試算の $+1$〜$2\%$ 程度にとどまる見込みである．
* 後でノックを入れるなら，エンドガスの温度と圧力の履歴から自着火の遅れを積算する形（Livengood–Wu 積分）が定番で，化学種の熱力学と直噴の冷却の上に載せられる．

## 7. 採った案と，採らなかった案

| 論点 | 採った案 | 採らなかった案と理由 |
| :--- | :--- | :--- |
| リッチの出力増の表し方 | 化学種の熱力学と化学平衡（解離） | 潜熱だけ（M1 相当）：最大が $\phi = 1$ のまま．経験式で出力に係数を掛ける：係数を結果に合わせることになる（REQ-28 の方針に反する） |
| 平衡の化学種 | 10 種 | 6 種：表にして補間するので実行時の計算量は同じ．断熱火炎温度の検算は 10 種が合う |
| 平衡の計算の時点 | 起動時に表を作り，$(\phi_b, T, \ln p)$ で補間 | 毎ステップで平衡を解く：右辺が重くなる |
| 既燃ガスの当量比 | 筒内は状態 $m_{bf}$（既燃ガスのうち燃料に由来する質量）で連続に追う．筒外は直近の排気弁の開く時点の値 | サイクルごとに 1 つの値に切り替える：切り替えの瞬間に内部エネルギーが跳び，第一法則の検査が崩れる |
| 従来の熱物性 | 設定で残す（`化学種`／`γ(T)`／`γ一定`） | 置き換える：第25版の結果と比べられなくなる |
| 噴射率 | クランク角で一定（開始角と，開始時の回転数から決めた噴射の角度幅） | 時間で一定：終了が角度のイベントにならず，積分のステップを終了にちょうど合わせられない |
| 噴射量の決め方 | 前のサイクルで閉じ込めた空気量から | 今のサイクルの空気量：噴射を始める時点では分からない |
| 壁への付着，液滴の加熱，成層 | 扱わない（冷却は上限寄り） | 壁から熱をもらう割合を設定にする：根拠のある既定値が無い |

## 8. 分かっている限界と，実装してから確かめること

1. **単一ゾーン**：既燃ガスも筒内の平均温度で評価する．実際の既燃部は平均より高温で，解離はもっと進む．平均温度での平衡は解離を小さく見積もるので，リッチでの出力増は燃料空気サイクルの試算（既燃ガスだけの温度で評価）より小さくなる可能性がある．REQ-29 の受入基準（直噴・全開で $T_b(\phi = 1.1) > T_b(\phi = 1.0)$）を満たすかは，実装して測るまで分からない．満たさなければ，係数は合わせず，結果と理由を報告する．
2. **基準の変化**：既定の機関のトルク・効率・$p_{\max}$ が動く（試算で IMEP $+10\%$ 程度）．数値で判定しているテストの基準は，実装の後に実測して引き直す．
3. **凍結温度 $1700\ \text{K}$** は仮定．表の $T < T_{fr}$ の物性は「同じ圧力で $T_{fr}$ のときの平衡組成」を使う状態量の近似で，経路（どの圧力で凍結したか）は追わない．
4. **NO** は平衡値で，実際（生成が遅い）より多い．エネルギーへの影響は小さい．
5. **燃料**は擬似種．実際のガソリンは多成分で，気化潜熱も $300$〜$400\ \text{kJ/kg}$ と幅がある．
6. **量論空燃比**が $14.7$ から $14.50$ に変わる（空気を O$_2$ + 3.76 N$_2$ とし，燃料を CH$_{1.87}$ とした結果）．
7. **ノック**は扱わない（6 節）．
