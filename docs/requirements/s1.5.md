### 1.5 文書の体系
| 文書 | 定めること |
| :--- | :--- |
| **要件定義書**（この文書） | 何ができることを求めるか（要求）と，その合否を測る受入基準．制約，納品条件，改訂の記録 |
| **仕様書**（`docs/specification/`） | 要件を満たすための具体的な定め：状態変数，支配方程式と導出，定数と既定値，数値解法，制御則，音，テスト項目の手順と判定値（画面は画面の文書） |
| **画面の文書**（`docs/gui/`） | 画面（GUI）の要件・仕様・テスト項目．画面だけの章（REQ-15〜19，22，23，31）の全文と，計算の章の画面の節（SPEC-26 B，SPEC-32 A，SPEC-33 C，SPEC-34 A） |
| **用語の定義集**（`docs/glossary/`） | 記号（単位と定義式）と用語の定義 |

1. 要件 REQ-nn，仕様 SPEC-nn，テスト TEST-nn は，同じ番号どうしが対応する（6 節）．画面の文書に置いた章も番号は共通である．
2. 要求は「〜できること」の形で書く．**受入基準**は数式か数値で書き，仕様書のテスト項目で判定する．自動で判定できないものは 5 節の実機目視チェックリストに載せる．どちらにも無い事項は要件ではない．
3. モデルの式の導出，定数，アルゴリズム，画面の寸法，テストの手順は，この文書に書かない（仕様書に書く）．受入基準に現れる記号は用語の定義集で定義する．
4. 受入基準の「（TEST-nn 項目 k）」は，その基準を判定するテスト項目を示す．判定値の根拠（実測値，文献）は仕様書のテスト項目に書く．
5. 仕様の変更は，要件定義書 → 仕様書 → テスト → 実装の順に行う．
6. **表記**：句読点は「，」「．」．圧力は Pa 系（$\text{Pa}$，$\text{kPa}$，$\text{MPa}$）で表し，$\text{bar}$ は使わない．トルクは $\text{N·m}$ と書く（`Nm`，`N m`，`kgf·m` は使わない）．SI 接頭辞は，量ごとに値の桁に合うものを決めて使う（k：$\text{kW}$，$\text{kPa}$，$\text{kN}$，$\text{kg}$．m：$\text{mm}$，$\text{ms}$，$\text{mg}$．接頭辞の k は小文字，M は大文字）．同じ量の表示の途中で接頭辞を替えない．角度の数値は $^\circ$（クランク角は $^\circ\text{CA}$）．定着した日本語訳の無い術語は英語のまま書く．
