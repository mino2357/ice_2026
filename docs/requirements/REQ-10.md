### REQ-10：回転運動，摩擦，スターター

**要求**：クランク軸とフライホイールの回転の運動方程式を解き，スターターによる始動から完爆，自力運転，エンストまでの角速度の変化を再現すること．検証と性能曲線の計測のために，回転数を固定するモードを持つこと．

**受入基準**：

1. $\text{FMEP}(p_{\max} = 5000\ \text{kPa},\ 3000\ \text{rpm}) = 178.02\ \text{kPa}$（相対誤差 $10^{-12}$．TEST-10 項目 1）．
2. 燃料 OFF のクランキングで，平均角速度がスターターと摩擦のつり合い $\omega_{\text{eq}}$ の $\pm 15\%$ 以内で，完爆と判定しない（項目 2）．
3. コールドリセットから START で，$3\ \text{s}$ 以内に完爆と判定し，その後はスターターのトルクが $0$（項目 3）．
4. 定常サイクルで $W_f = \text{FMEP}\cdot V_d$（相対誤差 $10^{-9}$．項目 4）．
5. $p = p_{\text{atm}}$ で $T_{\text{ind}} = 0$．回転数固定のモードで $\dfrac{d\omega}{dt} = 0$．逆転しない（項目 5）．
