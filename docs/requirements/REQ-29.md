### REQ-29：化学種の熱物性と化学平衡（第26版）

**要求**：筒内の作動流体を，空気・燃料蒸気・既燃ガスの 3 成分で表し，各成分の内部エネルギーを，生成エンタルピーを含む絶対値で与えること．既燃ガスは，当量比・温度・圧力で決まる 10 種の化学平衡組成とし，解離と，当量比による比熱・気体定数の変化を扱うこと．燃焼の発熱は，外から加える項ではなく，未燃ガスが既燃ガスに変わるときの内部エネルギーの差として現れること．これにより，リッチ（$\phi > 1$）での出力の増加を，係数の調整なしに表すこと．第25版の熱物性（$\gamma(T)$，$\gamma$ 一定）も設定で選べること．既燃ガスの物性の表は，運転中に現れる当量比をすべて範囲に含むこと（範囲の外を端の値に丸めて使わない）．

**受入基準**：

1. 空気の気体定数 $R_a = 288.19\ \text{J/(kg·K)}$，燃料蒸気の気体定数 $R_f = 75.586\ \text{J/(kg·K)}$，量論空燃比 $\text{AF}_{st} = 14.503$，燃料蒸気の低位発熱量（$298.15\ \text{K}$）$H_u + h_{fg} = 44.35\ \text{MJ/kg}$（いずれも相対誤差 $10^{-4}$．TEST-29 項目 1）．
2. CO$_2$ ⇌ CO + ½O$_2$ の平衡定数が，$2000$，$2500$，$3000\ \text{K}$ で $\log_{10}K_p = -2.879$，$-1.433$，$-0.479$（$\pm 0.005$．項目 2）．
3. 化学平衡の解が元素の保存を満たす（相対誤差 $10^{-9}$）．燃料と空気（$298.15\ \text{K}$，$101.325\ \text{kPa}$）の定圧断熱火炎温度が，$\phi = 1.0$ で $2313.7\ \text{K}$，$\phi = 1.1$ で $2325.2\ \text{K}$（$\pm 2\ \text{K}$．燃焼効率 $1$ として．項目 3）．
4. 定容・断熱の燃焼の終わりの状態が，試算（`tools/richburn`）の値に一致する：$\phi = 1.0$ で $T = 2952\ \text{K}$，$p = 9.565\ \text{MPa}$，$\phi = 1.1$ で $T = 2983\ \text{K}$，$p = 9.817\ \text{MPa}$（$\pm 5\ \text{K}$，$\pm 0.3\%$．条件は項目 4）．
5. 既燃ガスの物性の表の補間が，平衡を直接解いた値に対して，内部エネルギーで $5\ \text{kJ/kg}$ 以下，気体定数で相対 $10^{-3}$ 以下（項目 5）．
6. 弁を閉じ，熱損失を無くした系で，全内部エネルギーと図示仕事の和が保存する（仕事に対して，既定の許容誤差で $10^{-4}$ 以下，許容誤差を絞って $10^{-6}$ 以下）．周期定常の運転で，第一法則の残差が，1 サイクルに供給した燃料の発熱量の $10^{-4}$ 以下（項目 6，7）．
7. 熱物性に $\gamma(T)$ を選ぶと，第25版と同じ結果になる（同じシナリオの IMEP の相対差 $10^{-4}$ 以下．同じ実行環境ではビット単位で一致することを開発時に確かめる．項目 8）．
8. 直噴（REQ-30），全開，点火時期は自動最適化，$2000$ と $4000\ \text{rpm}$ で，軸トルクが $T_b(\phi = 1.1) > T_b(\phi = 1.0) > T_b(\phi = 0.9)$．$\phi \in \{0.9, 1.0, 1.1, 1.2, 1.3\}$ のうち軸トルクが最大になるのは $1.1$ か $1.2$（項目 9）．
9. 既燃ガスの物性の表に入れる化学平衡の解は，すべて収束した解である．表を作るときに収束しなかった解と，解けなかった連立方程式（ピボットが $0$）の数を数え，全テストの実行の終わりにどちらも $0$ である（項目 11，TEST-20 項目 10）．
10. 運転中に熱物性のモデルを切り替えたサイクルは，集計が途中からになるので，性能の指標の平均（REQ-14）に入れない（項目 12）．
11. 表の当量比の範囲：ポート噴射と直噴のそれぞれで，当量比の設定の下限と上限，始動の直後（吸気ポートに燃料がまだ無い間）を含む運転で，既燃ガスの物性を求めた当量比が表の範囲の外に出た回数が $0$．広げた範囲（薄い側）でも 5（補間の精度）と 9（解の収束）を満たす（項目 15）．
12. 長い時間の収支：サイクル変動ありで始動から $30\ \text{s}$，途中で開度と目標回転数を 3 回変える運転（直噴とポート噴射，動力計制御とスロットル制御）の通算で，筒内の第一法則の残差（6 と同じ式）が供給した燃料の発熱量の $10^{-4}$ 以下，筒内の質量の収支の残差が吸気弁を通った質量の $10^{-9}$ 以下（項目 16）．
