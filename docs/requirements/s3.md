## 3. 状態と記号

状態ベクトルは次の 23 成分である（単位と式は用語の定義集 2.2，仕様書 2 節）．後ろの 7 成分は，熱物性が「化学平衡」（REQ-29）のときだけ使う．

$$\mathbf{y} = \left(\theta,\ \omega,\ p,\ m,\ m_u,\ T_w,\ p_{\text{in}},\ m_{b,\text{in}},\ \dot m_r,\ p_p,\ m_{b,p},\ \dot m_e,\ p_{pe},\ p_{te},\ E_{\text{in}},\ E_p,\ m_f,\ m_{bf},\ m_l,\ m_{f,\text{in}},\ m_{f,p},\ T_X,\ m_{a,p}\right)$$

$\theta$：クランク角，$\omega$：角速度，$p$：筒内圧，$m$，$m_u$：筒内ガスの全質量と未燃ガスの質量，$T_w$：壁温，$p_{\text{in}}$：吸気マニホールド圧，$m_{b,\text{in}}$，$m_{b,p}$：マニホールドとポートの既燃ガスの質量，$\dot m_r$，$p_p$：吸気ランナの流量と吸気ポート圧，$\dot m_e$，$p_{pe}$，$p_{te}$：排気管の流量，排気ポート圧（排気管の弁側の半分の圧力），排気管の出口側の圧力（排気管は大気に開いているので使わない．時間微分は $0$．仕様書 SPEC-27 の 8 の内部の値で出口側に容積を置いたときだけ使う），$E_{\text{in}}$，$E_p$：マニホールドとポートの余剰エンタルピー，$m_f$，$m_{bf}$：筒内の未燃の燃料蒸気と，既燃ガスのうち燃料に由来する質量，$m_l$：筒内の液体の燃料，$m_{f,\text{in}}$，$m_{f,p}$：マニホールドとポートの燃料蒸気．$T_X$：排気ポートのガスの温度（排気温度），$m_{a,p}$：吸気ポートの空気の質量（REQ-25 の 6）．熱物性が「化学平衡」のとき，壁温 $T_w$ は設定の一定値で，時間変化しない（REQ-08）．

受入基準で使う増分 $\Delta$ は，指定した区間（サイクル）での補助積分（用語の定義集 2.3）または状態の増分を表す．
