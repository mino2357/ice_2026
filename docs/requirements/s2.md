## 2. 前提と制約

| # | 制約 | 確かめ方 |
| :--- | :--- | :--- |
| C-1 | **配信形態**：単一の HTML ファイル（JavaScript，Canvas 2D，CSS）．ネットワークなしで全機能が動く．例外は数式の組版だけで，ネットワークがあれば実行時に MathJax を読み込んで組み，無ければ数式を TeX のソースのまま表示する（どちらでも内容は読める） | 開発時検証は成果物のファイルだけを開いて全テストを実行する．MathJax の読み込みは手元の同じ版に振り向け，1 通りは読み込みを遮断する（TEST-15 項目 10，TEST-16 項目 19） |
| C-2 | **操作**：スマートフォンのタッチ操作だけで全機能を使える | REQ-15，REQ-18，REQ-23 |
| C-3 | **単位**：計算の内部は SI．画面の圧力は Pa 系で，量ごとに桁に合う接頭辞を付ける（筒内圧は $\text{MPa}$，吸気・排気系と大気の圧力と平均有効圧は $\text{kPa}$）．$\text{bar}$ を表示しない | TEST-15 項目 3，TEST-18 項目 1 |
| C-4 | **保存則**：質量，既燃ガス，エネルギーの収支が，数値積分の誤差の範囲で閉じる | REQ-05，REQ-06，REQ-09，REQ-13 |
| C-5 | **決定性**：同じ設定と同じ操作から，同じ結果が得られる（乱数は種を固定した擬似乱数だけ） | REQ-20 |
| C-6 | **検証できること**：全要件に対応するテストを持ち，自動化できる項目はアプリの「検証」タブから実行できる | REQ-20 |
| C-7 | **モデルを合わせ込まない**：実機の値に結果を合わせるための係数の調整はしない．物性値や式の誤りは直し，実機とのずれは理由とともに記録する | REQ-24，REQ-28，7.2 節 |
| C-8 | **第三者の著作物を埋め込まない**：フォントやライブラリなど第三者の著作物を成果物に含めない．数式の組版に使う MathJax（Apache License 2.0）は実行時に CDN から読み込み，その名前・版・ライセンス・読み込み元を解説タブに示す | REQ-16 受入基準 7（TEST-16 項目 18） |
