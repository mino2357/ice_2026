### 7.1 版の一覧
第24版までは，要件・仕様・テスト・改訂記録を 1 つの文書に書いていた．その全文は `docs/history/requirements_v24.md` にある．

| 版 | 主な内容 |
| :--- | :--- |
| 第5版 | 摩擦を Chen–Flynn 型に．検証の基盤（アプリ内テスト）を定めた |
| 第6〜8版 | DOPRI5 を既定に，点火時期の自動最適化，カム線図，サイクル変動，燃焼速度の調整係数，リッチ側の不完全燃焼 |
| 第9〜10版 | 目標回転数スライダ，線図の横軸の範囲 |
| 第11版 | 吸気管の既燃ガスの追跡（内部 EGR），着火遅れの校正 |
| 第12版 | 吸気ランナ（慣性過給），性能曲線タブ，弁諸元の見直し |
| 第13〜15版 | 画面の言葉，解説タブの目次と方程式のまとめ，文字幅の余裕，指標の日本語名 |
| 第16版 | 理想スロットル（漏れ面積の廃止），補機の負荷，10 サイクル平均 |
| 第17〜19版 | 性能曲線の計測条件（点数，収束の判定，手順）を選べるようにした |
| 第20版 | 排気系（脈動と背圧），アイドルの妥当性の判定 |
| 第21版 | 計算の高速化（結果は不変） |
| 第22版 | タブレットと PC への対応（画面の大きさに応じた表示） |
| 第23版 | 冷間始動への対応（補機負荷の feedforward と開度の下限） |
| 第24版 | 演出の音（4 気筒風） |
| 第25版 | 熱物性・エネルギーの式・吸気側の熱・燃焼速度の定数・数値積分の見直し．文書を要件定義書・仕様書・用語の定義集に分け，解説タブから読めるようにした（第25版の経緯） |
| 第26版 | 化学種の熱物性と化学平衡（解離），直噴と気化潜熱．リッチでの出力増を表す．性能曲線の回転数の点を刻みの 1 つ目からにし，$p$-$V$ 線図の印，バルブタイミングの画面を加えた．全体の点検．排気弁径の設定，全体図のタブ（REQ-31）．4 弁，全体図の数値の桁の固定，排気管の大気開放（第26版の経緯） |
