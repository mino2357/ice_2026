### REQ-12：ECU（スロットル開度の PI 制御と点火時期の自動最適化）

**要求**：完爆後，スロットル開度を操作して回転数を目標に合わせること（スロットル制御）．補機の負荷が大きくても冷間始動できること．点火時期を，図示仕事が最大になる時期（MBT）へ自動で合わせられること．

**受入基準**：

1. アイドル（目標 $800\ \text{rpm}$）で，最後の $3\ \text{s}$ の $|\bar N - 800| \le 25\ \text{rpm}$．目標 $1200\ \text{rpm}$，大気圧 $80\ \text{kPa}$ でも $\pm 25\ \text{rpm}$（TEST-12 項目 1〜3）．
2. 開度が上限に張り付いている間，積分の状態 $I_\alpha$ が増え続けない（項目 4）．
3. 点火時期の自動最適化で CA50 が上死点後 $10 \pm 0.5^\circ$ になり，そのときの IMEP が，点火時期を $\pm 4^\circ$，$\pm 8^\circ$ 振ったときの最大の $99\%$ 以上（項目 6，7）．
4. 開度の下限が $\alpha_{\min} = \min\left(\alpha_{\max},\ \max\left(0,\ \alpha_{\text{base}} + k_T T_{\text{aux}} - \delta_\alpha\right)\right)$ である（$T_{\text{aux}} = 0, 2, 20\ \text{N·m}$ で $2^\circ$，$2.52^\circ$，$7.2^\circ$．項目 9）．
5. 補機の負荷 $T_{\text{aux}} = 0, 6, 10\ \text{N·m}$ の冷間始動で，$3\ \text{s}$ 以内に完爆して止まらず，完爆後の $\bar N \ge 450\ \text{rpm}$，吸気管圧 $\ge 6\ \text{kPa}$（項目 10）．
6. 下限が制御を妨げない：目標 $600\ \text{rpm}$ で機関が止まらず，$\bar N$ が $600 \pm 100\ \text{rpm}$ の中にあり，開度が下限に張り付かない（項目 11．この回転数では回転が振れ続ける．7.2 の 2）．

**仕様**：仕様書 SPEC-12　**検証**：TEST-12
