### 7.3 経緯の記録の場所

要件定義書には，今の要件だけを書く．変更の経緯（利用者の指示，選ばなかった案，途中の FAIL と原因）は次の場所に書き，成果物には埋め込まない．

| 文書 | 内容 |
| :--- | :--- |
| `docs/history/requirements_v24.md` | 第24版までの文書の全文 |
| `docs/history/changes_v25.md` | 第25版の経緯（ほかの文書の「第25版の経緯の n」は，この文書の項目 n） |
| `docs/history/changes_v26.md` | 第26版の経緯（2026-11-21 まで．「第26版の経緯の n」は，この文書の項目 n） |
| `docs/changes/` | 2026-11-21 より後の変更の記録（変更 1 件を 1 ファイル） |
