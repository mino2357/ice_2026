### REQ-08：壁面熱伝達と壁温

**要求**：筒内ガスからシリンダ壁への熱流量を Woschni の式で求めること．熱物性が「化学平衡」（既定）のときは，壁温を設定の一定値とし（既定 $360\ \text{K}$），利用者がほかの設定と同じように変えられること．設定の範囲は，計算の上で扱える $300$〜$3500\ \text{K}$ とする．熱物性が $\gamma(T)$，$\gamma$ 一定のときは，第25版と同じく壁温の変化を連立して解く．

**受入基準**：

1. $C_w = 0$ で $\dot Q_{\text{wall}} = 0$（TEST-08 項目 1）．
2. 燃焼による増圧（$p > p_{\text{mot}}$）で熱伝達率 $h_c$ が増える（項目 2）．
3. 熱物性 $\gamma(T)$ で，$\dot Q_{\text{wall}} = 0$，$T_w = 300\ \text{K}$ のとき $\dfrac{dT_w}{dt} = \dfrac{G_{\text{cool}}\,(T_{\text{cool}} - T_w)}{C_{w,\text{th}}} = 0.6\ \text{K/s}$（相対誤差 $10^{-12}$．項目 3）．
4. 化学平衡のモデルで，壁温が設定値に等しく，運転しても変わらない（$\dfrac{dT_w}{dt} = 0$）．設定を変えると次のステップから新しい値になり，壁温を上げると壁への熱が減る（項目 4）．
5. 設定ページ「冷却」で壁温を変えられ，熱物性が「化学平衡」でないときは使わない項目として示す．パネルに壁温，壁が受ける熱，排気温度を示す（項目 5）．
