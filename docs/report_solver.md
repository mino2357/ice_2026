# 積分の解法の比較（REQ-13 の受入基準 11〜13 のための調査）

2026-11-21．製品のコード（`src/core.js`）は変えていない．試算は `tools/solver/`（`lib.js` が読み込むときに差し替える．`survey1.js`〜`survey4.js`）で，Node.js で行った．成果物には埋め込まない．

## 1. 測り方

* **条件**（4 つ．熱物性は化学平衡，直噴．回転数固定，壁温固定，サイクル変動なし）：低負荷（$800\ \text{rpm}$，開度 $6^\circ$），部分負荷（$1500\ \text{rpm}$，$15^\circ$），全開 $3000\ \text{rpm}$，全開 $7000\ \text{rpm}$．
* **点火時期**：今の既定（自動）で落ち着いた値（$17.0$，$22.0$，$25.9$，$28.9^\circ$ BTDC）に固定した．自動の最適化が解法ごとに別の値に落ち着くと，解法の誤差と区別できないため．
* **指標**：IMEP，$p_{\max}$，体積効率 $\eta_v$，軸トルク $T_b$．60 サイクル回し，最後の 10 サイクルの平均を取る．
* **参照解**：DOPRI5，相対許容 $10^{-8}$，刻みの上限 $0.125^\circ$（約 $40\,400$ 評価／サイクル）．相対許容 $10^{-7}$・上限 $0.25^\circ$ の解との差は最大 $0.009\%$，100 サイクルまで回した解との差は $10^{-4}\%$ 以下．参照解の不確かさは約 $0.01\%$．
* **誤差**：4 条件 × 4 指標の，参照解との相対差の最大．受入基準 11 は $0.1\%$ 以内．
* **計算量**：1 サイクルあたりの右辺の評価の回数（最後の 10 サイクルの平均）の，4 条件の合計．
* **今の既定**（DOPRI5，相対許容 $10^{-5}$，刻みの上限 $0.5^\circ$）：$43\,912$ 回（どの条件も 1 サイクル約 1440 ステップで，$10\,000$ 回あまり），誤差 $0.021\%$．1 ステップは右辺 7 回で，ほぼ全ステップが上限 $0.5^\circ$ に張り付いている．

**アイドルの条件について**：要件の「アイドル」として，はじめ $800\ \text{rpm}$・開度 $3^\circ$（IMEP $22\ \text{kPa}$）と $4^\circ$（$110\ \text{kPa}$）を試したが，回転数固定ではサイクルごとの差が $10^{-4}$ ほど残り，$0.1\%$ の比較ができなかった．開度 $6^\circ$（IMEP $362\ \text{kPa}$，サイクルごとの差 $3 \times 10^{-6}$）を低負荷の条件にした．実際のアイドル（回転数が自由，点火時期は自動）での確認は，実装のときのテストで行う（未実施）．

## 2. 分かったこと

1. **今の計算量は刻みの上限で決まっている**．上限をゆるめると DOPRI5 のままでも回数は減るが，$16\,000$ 回あたりで止まる（低負荷と部分負荷が減らない）．しかも誤差が許容誤差に対して単調に減らず，上限なしでは $0.1\%$ を超える組み合わせが多い．
2. **低回転は，速い成分で刻みが決まる**．ヤコビアンの固有値の絶対値の最大は約 $10^5\ \text{1/s}$（排気弁が開いている $630$〜$665^\circ$．`tools/dev/stiff.js`）．1 サイクルの時間が長い低回転ほど，1 サイクルのステップ数が増える．
3. **次数の低い公式の方が合う**．右辺は弁の開閉や流れの向きの切り替わりで滑らかでなく，5 次の高い次数が生きない．3 次の Bogacki–Shampine 3(2)（BS3）は，1 ステップの右辺が 4 回（最後の段を次のステップに使い回せば 3 回）で済み，誤差も許容誤差に対して素直に減る．
4. **安定の範囲を広げた公式（RKC）は効かない**．段の数を 3 → 8 に増やしても回数は増えるだけだった．低回転の刻みは，安定よりも誤差（滑らかでない所）で決まっている割合が大きい．
5. **誤差の見積もりで最大になる成分**（BS3，上限なし）：筒内圧 $p$，吸気ポート圧 $p_p$，吸気ランナの流量 $\dot m_r$，排気管の流量 $\dot m_e$，吸気ポートの余剰エンタルピー $E_p$ に分かれていて，1 つの成分の許容をゆるめれば済む形ではない．ステップは，低負荷では吸気行程の前半（$90$〜$180^\circ$）と排気行程（$540$〜$720^\circ$）に集まる．不受理は $10$〜$20\%$．
6. **イベントの合わせ直しは，回転数固定では 0 回**（角速度が一定なので 1 回で合う）．密出力でイベントの位置を決める工夫の効果は，この条件では測れなかった．

## 5. 試していないもの

| 手法 | 試さなかった理由 |
| :--- | :--- |
| Tsit5，Verner 6(5)，DOP853 | 5 次の DOPRI5 で高い次数が生きないことが分かった（2 の 3）．同じ類か，より高い次数 |
| Rosenbrock 法などの陰的な公式 | 1 ステップにヤコビアン（数値微分で右辺 22 回以上）が要る．BS3 は 1 ステップ 3 回で，低負荷でも 1 サイクル約 1600 ステップ．陰的な公式が勝つには 1 サイクル 200 ステップ以下で $0.1\%$ を満たす必要があり，滑らかでない右辺では見込みが薄い（見積もりで，実行していない） |
| 多段階法（Adams 系） | 1 サイクルに 7〜8 回あるイベントのたびに立ち上げ直しが要り，安定の範囲も 1 評価あたりで Runge–Kutta と同じ程度（見積もり） |
| 密出力によるイベントの位置決め | 回転数固定の条件では合わせ直しが 0 回で，効果を測れない．回転数が自由な運転で数える（未実施） |
| クランク角を独立変数にする定式化 | 回転数固定では時間と同じ．モデルの式が変わる |

## 6. 実装のときに要ること（未決を含む）

1. **線図の標本**：線図の記録は $0.5^\circ$ ごとの升に 1 ステップ 1 点を入れている．刻みが $0.5^\circ$ を超えると升が抜ける．ステップの間を補間して升を埋める必要がある（3 次 Hermite．右辺の評価は増えない）．
2. **$p_{\max}$**：今は 3 点の放物線で求めている．刻みが大きいと誤差が増える（DOPRI5 の上限 $4^\circ$ で $0.15\%$）．BS3 では刻みが燃焼の所で細かくなるので $0.1\%$ に収まっているが，補間に替えるかを確かめる．
3. **音と振動**：エンジン音の合成はステップごとの排気流量を使う．刻みが変わると入力の標本の間隔が変わる（確かめる）．
4. **回転数が自由な運転，点火時期の自動，$\gamma$ のモデル，RK4**：この調査の条件に入っていない．実装のときのテスト（TEST-13 の新しい項目）で確かめる．
5. **数値の変化**：既定を変えると，テストの判定値のうち DOPRI5 の値に合わせたものを取り直す（どれが変わるかは実装のときに数える）．受入基準 15 のとおり，設定で DOPRI5 と上限 $0.5^\circ$ を選べば今と同じ値になるようにする．
6. **実時間**：回数の比と実時間の比は同じとは限らない（1 ステップあたりの決まった手間がある）．実装の後に計る（性能の記録）．
