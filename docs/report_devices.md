## 6. 分かったこと

1. **機能は環境によらない**：機能の検査 581 件は 4 つの環境で全部 PASS．ブラウザのエンジン（Chromium と WebKit），画面の大きさ，計算の速さが違っても，計算の結果と画面の検査の合否は同じだった．
2. **上限は主対象の環境の値に合っている**：S は 21 件すべて上限以下で，総所要時間は上限の $38\,\%$．フレームを待たない計算（TEST-13，TEST-24）は，P と W が S の約 3 倍かかり，上限（S の値の約 3〜3.5 倍）の前後になる．
3. **I の上限超えは文書の表示**：最長フレーム間隔 $263\ \text{ms}$ は TEST-16（解説）の実行中．相互参照の移動も $112\ \text{ms}$（S は $3\ \text{ms}$）．計算の所要は S の $1.0$〜$1.4$ 倍（TEST-13 だけ $2.0$ 倍）．
4. **W の遅さ**：CPU は 2017 年のノート PC 用（4 コア 8 スレッド，TDP $15\ \text{W}$）．実行の前半は P とほぼ同じ速さで，TEST-26〜32 のあいだだけ P の約 2 倍かかった（5 節）．負荷が続いたときの電力と熱の制限か，ほかの処理の負荷による可能性がある（**推定**．温度も周波数も測っていない）．
5. **画面の更新の周期の影響は小さい**：I（$60\ \text{Hz}$）の計算の所要は S（$120\ \text{Hz}$）の $1.04$〜$1.36$ 倍で，2 倍の差は無い（更新の周期は端末の仕様の値で，測っていない）．
6. **結果のコピー**：4 つの環境でテキストを取り出せた．機種の名前は S と P で入り，I と W では入らない．P と W のテキストは，行の途中の改行と半角の空白に変わって届いた（S と I は元のまま）．コピーの経路か，貼るまでの経路かは未確認．
