### TEST-36：振動による体感（REQ-36，SPEC-36）

1. [A]（パターン．A の 2，C の 2）送る時刻 $0$ から $5,\ 20,\ 40\ \text{ms}$ に始まる 3 つのパルスで $[0, 5, 3, 12, 3, 17, 3]$．$0\ \text{ms}$ に始まるパルスで先頭が $3$．間隔 $4\ \text{ms}$（休止 $1\ \text{ms}$）の 5 つのパルスは 1 つの振動 $[0, 5, 19]$ につながる．100 個のパルスでも要素が $98$ 個以下．全要素が整数で，先頭のほかは $1$ 以上．
2. [S]（燃焼の回数と時刻．B の 1）S4 の定常から，再生速度 $0.1\times$，$0.5\times$，$1\times$ で，模擬の時計（フレーム $16.7\ \text{ms}$，1 フレームの積分は時計の経過 × 再生速度）で実時間 $4\ \text{s}$ を進める．送ったパターンから再構成した振動の開始の数が，その間に記録された燃焼の数と一致し（終わりのフレームの分は除く），各振動の開始が，その燃焼を含むフレームの終わりから次のフレームの終わりまでの間にある（B の 1 の式の時刻と $1\ \text{ms}$ 以内）．各振動の長さが $3\ \text{ms}$（つながったものを除く）．
3. [A]（つながる振動）1 フレーム $16.7\ \text{ms}$ にシミュレーションの $4\ \text{ms}$ ごとの燃焼が 4 つ入る入力で，パターンが 1 つの振動（休止なし）になる．$8\ \text{ms}$ ごとの燃焼では休止がある．
4. [S]（燃焼しないときは振動しない．A の 3）S4 から `[FUEL CUT]`（動力計による駆動）にすると，$0.2\ \text{s}$ 後から $1\ \text{s}$ の間にパターンを送らない．CRANK（燃料 OFF のクランキング）の $1\ \text{s}$ でパターンを送らない．
5. [U]（画面と止める命令．SPEC-36 D，C の 3）`navigator.vibrate` を記録用の関数に差し替えて：運転タブに `[振動]`（$44 \times 44\ \text{px}$ 以上，文字が収まる）があり既定は OFF．ON にして再生速度 $1\times$ で START すると $4\ \text{s}$ 以内にパターンを送る（完爆は $3\ \text{s}$ 以内．REQ-10．燃焼が起きてから送る）．OFF にすると直ちに `vibrate(0)` を送り，その後は送らない．ON のまま全テストの実行の状態（`U.busy`）にすると `vibrate(0)` を送り，その間は送らない．ページの非表示（`visibilitychange`）で `vibrate(0)` を送る．`navigator.vibrate` が無い環境を模すと `[振動]` が無効になる．設定ページ「音と振動」の説明の文字に「サイレント」を含む．検査の後，差し替えと設定を元に戻す．
6. [A]（計算時間）2 の $1\times$ の $4\ \text{s}$ で，`Hap` の 1 フレームの処理の平均が $0.05\ \text{ms}$ 以下，99 パーセンタイルが $0.2\ \text{ms}$ 以下（最大は記録．全テストの実行の中では，ほかのテストの後始末（ガベージコレクション）で 1 回だけ長くなることがあるため）．
7. [S]（計算に影響しない．B の 2）S2 の状態から $3\ \text{s}$ を，振動 OFF と ON で，同じフレームの列で進めると，状態ベクトルが完全に一致する．
8. [S]（長いフレーム．REQ-36 の 7，B の 1）S3 の機関を，経過 $0.3\ \text{s}$ のフレームとして再生速度 $1\times$ で進めると，進む時間は $0.05\ \text{s}$（$\pm 2\ \text{ms}$）で，その間に燃焼が 1 回以上ある．振動の判断に渡す長さが $50\ \text{ms}$ で，振動はすべて，そのフレームの時刻から $50\ \text{ms}$ 以内に始まる．振動が OFF のときは空の入力になる．
