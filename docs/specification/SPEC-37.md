### SPEC-37：運転点のマップ（回転数 × 軸トルク）（REQ-37）

#### A. 画面
画面の文書（`docs/gui/`）の 3 節「SPEC-37 A」にある．

#### B. 計算
1. **点の計算**：性能曲線の計測（SPEC-26）と同じ機関と手順「上り」を使う．スロットル開度 $\alpha$ を 1 つに固定し，回転数の点を低い方から続けて計測する（前の点の終わりの状態から次の点を始める）．収束の判定も SPEC-26 と同じで，画面の `[条件]` の厳しさ・流量と状態量の判定・サイクル数を使う．各点は，軸トルク $T_b$，正味熱効率 $\eta_b$，燃料の質量流量 $\dot m_f$，排気温度 $\bar T_X$，スロットルの流量の 1 サイクルの平均 $\bar{\dot m}_{\text{th}}$，筒内の最大圧力 $p_{\max}$，点火時期 $\theta_{\text{ig}}$ を持つ．
2. **回転数の点**：$N_i = 250\,i\ \text{rpm}$（$i = 1, \ldots, 28$）．性能曲線の既定の刻みと同じ．
3. **はじめの開度**：$\alpha \in \{90, 45, 28, 18, 12, 8, 5.5, 3.8, 2.6, 1.8\}^\circ$ を大きい順に計測する．2 つ目からの開度では，直前の開度で $T_b > 0$ だった回転数だけを計測する（エンストした回転数と，$T_b \le 0$ になった回転数は，それより小さい開度を計測しない）．
4. **開度を下げる**：$1.8^\circ$ でも $T_b > 0$ の回転数が残るときは，$\alpha \leftarrow 0.7\alpha$ として，その回転数だけを計測することを，残りが無くなるか $0.7\alpha < 0.3^\circ$ になるまで繰り返す．
5. **列**：回転数 $N_i$ ごとに，エンストしていない点を開度の大きい順に並べ，全開（$90^\circ$）の点から順に，軸トルクが直前に採った点より $\varepsilon T_{\max}$（$\varepsilon = 0.002$，$T_{\max}$ は全開の軸トルクの全回転数での最大）以上小さい点だけを採る（開度を閉じても軸トルクが下がらない点を除く）．採った点を「節点」と呼ぶ．
   * $T_b \le 0$ の点 $z$ が現れたら，その手前の節点 $a$ との 1 次の補間で $T_b = 0$ の節点を置いて，列を終える．補間する量 $f \in \{\dot m_f, \bar T_X, \bar{\dot m}_{\text{th}}, p_{\max}, \theta_{\text{ig}}\}$ の値は $f_0 = f_a + (f_z - f_a)\,u_0$，$u_0 = \dfrac{T_a}{T_a - T_z}$（$T_a$，$T_z$ は点 $a$，$z$ の軸トルク）．
   * 列 $i$ の下端 $T_i^{\text{lo}}$ は最も小さい節点の軸トルク（$T_b = 0$ の節点があれば $0$），上端 $T_i^{\text{hi}}$ は全開の軸トルク．
   * 全開の点がエンストか $T_b \le 0$ の回転数と，節点が 2 つに満たない回転数は，列を持たない．
6. **細かくする**：$\Delta T_{\lim} = 0.1\,T_{\max}$ とし，各列で次のどちらかに当たる隣り合う 2 点（上側 $a$，下側 $b$）について，開度の順で $b$ のすぐ上にある点 $a'$（節点でない点を含む）との間に，開度 $\alpha = \sqrt{\alpha_{a'}\alpha_b}$（有効数字 6 桁）の点を加える．
   * 隣り合う節点 $a$，$b$ で $T_a - T_b > \Delta T_{\lim}$．
   * 最後の正の節点 $a$ と $T_b \le 0$ の点 $z$（$b = z$）で，$T_a > \Delta T_{\lim}$ または $T_a - T_z > 2\Delta T_{\lim}$．
   
   $\alpha_{a'} - \alpha_b \le 0.05^\circ$ のときは加えない．加える点を開度ごとにまとめ，開度の大きい順に，回転数の低い方から続けて計測する．これを，加える点が無くなるまで，最大 8 回繰り返す．
7. **補間**：点 $(N, T)$（$N_i \le N \le N_{i+1}$）で，$u = \dfrac{N - N_i}{N_{i+1} - N_i}$ とし，描く領域の下端と上端を $T^{\text{lo}}(N) = (1-u)\,T_i^{\text{lo}} + u\,T_{i+1}^{\text{lo}}$，$T^{\text{hi}}(N) = (1-u)\,T_i^{\text{hi}} + u\,T_{i+1}^{\text{hi}}$ とする．**描く領域**は，両側の列があり，$T^{\text{lo}}(N) \le T \le T^{\text{hi}}(N)$ を満たす点の集まりである（$N$ がちょうど $N_i$ のときは列 $i$ だけを使う）．領域の中の点の値は，相対的な負荷 $s = \dfrac{T - T^{\text{lo}}(N)}{T^{\text{hi}}(N) - T^{\text{lo}}(N)}$ をそろえて，

   $$f(N, T) = (1-u)\,f_i\!\left(T_i^{\text{lo}} + s\,(T_i^{\text{hi}} - T_i^{\text{lo}})\right) + u\,f_{i+1}\!\left(T_{i+1}^{\text{lo}} + s\,(T_{i+1}^{\text{hi}} - T_{i+1}^{\text{lo}})\right)$$

   とする．$f_i(\cdot)$ は，列 $i$ の節点の間を軸トルクについて 1 次で補間した値．
   * **1 次関数の場を再現する**：$f = c_0 + c_1 N + c_2 T$（$c_0$，$c_1$，$c_2$ は定数）のとき，$f_i(T_i^{\text{lo}} + s\,\Delta_i) = c_0 + c_1 N_i + c_2\,(T_i^{\text{lo}} + s\,\Delta_i)$（$\Delta_i = T_i^{\text{hi}} - T_i^{\text{lo}}$）なので，上の式は $c_0 + c_1\left[(1-u)N_i + uN_{i+1}\right] + c_2\left[T^{\text{lo}}(N) + s\,(T^{\text{hi}}(N) - T^{\text{lo}}(N))\right] = c_0 + c_1 N + c_2 T$ になる．
   * **相対的な負荷でそろえる理由**：回転数ごとに全開の軸トルクが違うので，同じ $T$ でそろえると，全開の曲線の近くで片方の列に値が無い．相対的な負荷でそろえると，領域の上の縁が全開の軸トルクの曲線（列の間は直線）になる．
8. **燃費**：補間するのは燃料の質量流量 $\dot m_f$ で，正味熱効率と正味の燃料消費率は，補間した $\dot m_f$ から

   $$\eta_b(N, T) = \frac{T\,\omega}{\dot m_f(N, T)\,H_u},\qquad \omega = \frac{2\pi N}{60},\qquad b_e = \frac{3.6 \times 10^9}{\eta_b H_u}\ \text{g/(kW·h)}$$

   で求める（$N$ は rpm，$H_u$ は燃料の低位発熱量 [J/kg]）．$T = 0$ では $\eta_b = 0$ で，$b_e$ は定義しない．
   * **理由**：同じ回転数では，$\dot m_f$ は $T_b$ に対してほぼ 1 次である（$T_b = 0$ でも摩擦とポンプ損失の分の燃料が要る）．$\eta_b$ は $T_b \to 0$ で $0$ へ急に下がるので，$\eta_b$ をそのまま 1 次で補間するより，$\dot m_f$ を補間した方が誤差が小さい．格子の点では，この式の値は計測の $\eta_b$ と同じになる（$P_b = T_b\omega$．REQ-26 の受入基準 2）．
9. **量の表**（`OPQ`）：

   | 量 | 記号 | 単位 | 等高線を引く範囲 |
   | :--- | :--- | :--- | :--- |
   | 燃費 | $\eta_b$ | % | $[\max(v_{\min}, 0.75\,v_{\max}),\ v_{\max}]$ |
   | 排気温 | $\bar T_X$ | K | $[v_{\min}, v_{\max}]$ |
   | 空気量 | $\bar{\dot m}_{\text{th}}$ | g/s | $[v_{\min}, v_{\max}]$ |
   | 最大圧 | $p_{\max}$ | MPa | $[v_{\min}, v_{\max}]$ |
   | 点火 | $\theta_{\text{ig}}$ | °BTDC | $[v_{\min}, v_{\max}]$ |

   $v_{\min}$，$v_{\max}$ は，描く領域の中の値の最小と最大．燃費だけ範囲の下を切るのは，$\eta_b$ が $T_b = 0$ で $0$ になり，全部の範囲に等高線を割り当てると，熱効率の高い部分の形が見えなくなるため．
10. **熱効率が最大の点**：全部の列の節点のうち，8 の式の $\eta_b$ が最大の節点．
11. 計算は描画のループの中で時間を区切って進める（1 フレームに $12\ \text{ms}$）．運転中の機関の設定の複製を使い，運転中の機関の状態は変えない．`[中止]` で止めたときは，それまでに計測した点で列を作る．

#### C. 仮定と限界
* **上の縁は全開の曲線**：吸気の脈動のため，開度を少し閉じた方が全開より軸トルクが大きい回転数がある．その部分（全開の軸トルクより上）は描かない．
* **回転数の方向は $250\ \text{rpm}$ ごとの 1 次の補間**：吸気と排気の脈動による，それより細かい山や谷は表せない．
* **排気温度**は排気ポートのガスの温度の質量平均で，排気管の先の温度や触媒の温度ではない．熱物性が $\gamma$ のモデルのときと排気系が OFF のときは一定値（$800\ \text{K}$）になる．
* **空気量**はスロットルを通る流量で，吸気ポートから吹き返した燃料の蒸気がスロットルを逆に通るときは，その分を含む．
* **点火時期**は自動最適化（CA50 を目標に合わせる）の値で，ノックの限界は考えない．
