### SPEC-34：VVT マップ（REQ-34）

#### A. 画面
画面の文書（`docs/gui/`）の 3 節「SPEC-34 A」にある．

#### B. 計算
1. **評価**：SPEC-32 B と同じ評価器で，変える項目を $\phi_{\text{in}}$，$\phi_{\text{ex}}$ にする（弁時期 IVO〜EVC は設定のまま）．軸トルク $T_b$ と正味熱効率 $\eta_b$ を同時に得る．正味の燃料消費率は $b_e = \frac{3.6 \times 10^9}{\eta_b H_u}\ \text{g/kWh}$（$H_u$ は J/kg）．
2. **格子と順序**：$\phi \in \{-40, -30, \ldots, 40\}^2$ の 81 点．段階 1（$\{-40, 0, 40\}^2$ の 9 点），段階 2（$\{-40, -20, 0, 20, 40\}^2$ の残り 16 点），段階 3（残り 56 点）の順に，各段階の中は行ごとに向きを変えて（蛇行）並べる．格子の点は粗い許容（SPEC-32 B の 3 のモンテカルロの段と同じ）で，直前の点の終わりの状態から始める（最初の点は基準の状態から）．
3. **最適点**：格子の $T_b$ 最大の点と $b_e$ 最小（$\eta_b$ 最大．$\eta_b$ が定義された点の中で．無ければ ◆ を作らない）の点から，それぞれ，有限差分の勾配と $1^\circ$ の仕上げを，2 変数 $\mathbf x = (\phi_{\text{in}}, \phi_{\text{ex}})$ で，範囲 $[-40, 40]^2$ の中で行う（細かい許容．標本の段は無い）．
   * **勾配**：差分の幅 $h = 4^\circ$ から始めて，中心差分 $g_k = \dfrac{J(\mathbf x + h\mathbf e_k) - J(\mathbf x - h\mathbf e_k)}{2h}$ で勾配を求め，向き $\mathbf d = \mathbf g/\lVert\mathbf g\rVert_\infty$ に沿って，歩幅 $t$（初め $8^\circ$．$16, 8, 4, 2, 1^\circ$ の順に，前の成功の 2 倍から試す）の点 $\text{round}(\mathbf x + t\mathbf d)$ を評価し，$J$ が増えた最初の点へ移る．どの歩幅でも増えなければ $h$ を半分にする（$4 \to 2$）．$h = 2^\circ$ でも増えなければ終える．20 回まで移る．
   * **$1^\circ$ の仕上げ**：2 成分のそれぞれを $\pm 1^\circ$ ずらした 4 点を評価し，最も増えた点へ移ることを，増えなくなるまで繰り返す．
   * バルブタイミングの 4 項目の探索（SPEC-32 C）は 2 次式のモデルを使う方法に替えたが，ここは 2 変数で，格子の最良の点から始めるので，勾配の方法のままにしている．
4. 計算は描画のループの中で時間を区切って進める（1 フレームに $12\ \text{ms}$）．運転中の機関がなければ計算しない．

#### C. 仮定と限界
* 燃料消費率は同じ開度で比べるので，部分負荷では軸トルクとほぼ同じ形になる（REQ-34 の経緯）．同じ軸トルクでの比較（開度を合わせる）はしない．
* $10^\circ$ の格子の補間なので，マップの細部（$10^\circ$ より細かい山や谷）は表せない．★ ◆ の値は詰めた点で計算した値で，マップの色とは少し違うことがある．
