### TEST-25：吸気ランナの慣性（慣性過給）（REQ-25，SPEC-25）

1. [A]（共鳴）吸気弁が閉じた角度で回転を止め，$\zeta = 0$，$\dot m_{\text{th}} = 0$ として $\dot m_r(0) = 10^{-4}\ \text{kg/s}$ から積分すると，$\dot m_r$ の振動の周期が $2\pi/\omega_H$ と相対誤差 $1\%$ 以内．
2. [A]（摩擦）$p_{\text{in}} - p_p = \frac{\zeta\dot m_r^2}{2\rho_r A_r^2}$ のとき $\frac{d\dot m_r}{dt} = 0$（$p_{\text{in}} - p_p$ を基準に相対誤差 $10^{-9}$．$\rho_r$ の気体定数は，化学平衡のモデルでは空気の $R_a$）．
3. [S]（OFF）ランナ OFF で $\dot m_r$，$p_p$，$m_{b,p}$，$E_p$ の時間微分が $0$ で，吸気弁の流量が上流圧 $p_{\text{in}}$ で計算される（S2 の定常から 1 サイクルの全ステップ）．
4. [S]（質量の収支）S3 の定常の直近 5 サイクルで，$M_{\text{th}}$，$M_r$，$M_{\text{in}}$ の増分が相互に相対誤差 $1\%$ 以内．全時刻で $0 \le Y_{b,p} \le 1$．
5. [S]（慣性過給）全開・回転数固定の計測（SPEC-26）で，既定のランナ（$L_r = 450\ \text{mm}$）の $\Delta\eta_v(N) = \eta_{v,\text{ON}}(N) - \eta_{v,\text{OFF}}(N)$ の最大が $0.02$ 以上．その最大を与える回転数が，$L_r = 900\ \text{mm}$ では $450\ \text{mm}$ より低い．（実測：$4000 \to 2500\ \text{rpm}$，最大 $0.107$，$0.147$）
6. [U] 設定ページ「吸気ランナ」に 3 項目があり，全項目の操作で値が変わり，画面がスクロールしない．
7. [A]（運転中に ON．$\gamma(T)$）熱物性 $\gamma(T)$ で，ランナ OFF で運転中の状態から ON にすると，$\dot m_r = 0$，$p_p = p_{\text{in}}$（厳密），$m_{b,p} = Y_{b,\text{in}}m_p$，$E_p = \varepsilon_{\text{in}}m_p$（相対誤差 $10^{-12}$）になる．
8. [A]（運転中に ON．化学平衡．REQ-25 の 5）化学平衡のモデル（ポート噴射で余剰が正，直噴で余剰が負の 2 通り）で，ランナ OFF で運転中の状態のマニホールドに既燃ガス，燃料蒸気，余剰エンタルピーを与え，ポートの燃料蒸気にマニホールドと合わない値を残してから ON にする．$\dot m_r = 0$，$p_p = p_{\text{in}}$（厳密）で，ポートの既燃ガスの質量分率，燃料蒸気の質量分率，単位質量あたりの余剰エンタルピーが，マニホールドの値と一致する（相対 $10^{-12}$．質量は右辺と同じく成分ごとの気体定数で求める）．余剰が負のとき，ポートの余剰も負である．
9. [A]（原子の保存：右辺．REQ-25 の 6）化学平衡のモデル，ランナ ON の定常の S4 の条件（ポート噴射と直噴）の 1 サイクルの全ステップの状態と，その各状態の吸気側の成分の質量を乱数（種を固定）で $\pm 10\%$ 変えた状態で，右辺が返すマニホールドとポートの空気，既燃ガス，燃料蒸気の質量の時間微分が，同じ右辺の流量（スロットル，ランナ，吸気弁）と上流側の質量分率から求めた出入りの和と相対 $10^{-12}$ で同じ（$\lvert \dot m_{\text{th}}\rvert + \lvert \dot m_r\rvert + \lvert \dot m_{\text{in}}\rvert$ に対して）．状態でない成分（マニホールドの空気．化学平衡の今のモデルではポートの空気も）の時間微分は，圧力とほかの成分の時間微分から求める．（右辺がどの状態でもこの形なら，Runge–Kutta 法は状態の線形の量を保つので，積分した変化も出入りの積分と丸めの誤差の範囲で合う．ステップの点の外の状態でも調べるのは，ステップの途中の段の状態を含めるため．空気に由来する質量と燃料に由来する質量は，空気，燃料蒸気，既燃ガス（組成 $\zeta^*$）の質量の 1 次式なので，成分ごとに合えば原子の数が保存する．）今のモデルでは，ポートの空気の時間微分が圧力の式の剛性 $\gamma_p$ の分だけ合わず FAIL する見込み（実装の前に実行して確かめる）．
10. [S]（原子の保存：1 サイクル．REQ-25 の 6）同じ定常の 1 サイクルで，マニホールドとポートの全質量の変化（状態から求める）が，補助積分の $\Delta M_{\text{th}} - \Delta M_{\text{in}}$ と，$\Delta M_{\text{in}}$ の相対 $10^{-6}$ 以内で合い，ポートだけの全質量の変化が $\Delta M_r - \Delta M_{\text{in}}$ と同じ許容で合う（今のモデルでは，ポートの全質量を圧力から求めるので，サイクルの始めと終わりの圧力の差の分だけずれる見込み）．吸気側の既燃ガスの組成 $\zeta^*$ はサイクルごとに替わるので，原子の数の保存は，$\zeta^*$ が変わらない周期定常で判定する（過渡では，既燃ガスの組成の読み替えの分だけずれる．排気ポートと同じ仮定．SPEC-27 の 9）．
