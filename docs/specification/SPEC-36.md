### SPEC-36：振動による体感（REQ-36）

#### A. 振動の単位
1. **表すもの**：燃焼のガス圧によるクランク軸のトルクの脈動（機関を持つ手に，その反力として伝わる）．単気筒では燃焼は 1 サイクルに 1 回で，その周波数（**点火の周波数**）は $f_c = \frac{\bar N}{120}\ [\text{Hz}]$ である．振動子（ブラウザの `navigator.vibrate`）は ON と OFF の時間しか指定できないので，1 回の燃焼を 1 回の短い振動（**パルス**）で表す．
2. **パルス幅**：$w = 3\ \text{ms}$（一定）．$3\ \text{ms}$ は，振動の試験台で $150\ \text{Hz}$（周期 $6.7\ \text{ms}$）でも一発ずつ分かった長さである（第26版の経緯の 34）．
3. **燃焼**：点火の時点（SPEC-13 の 4 のイベント $\theta = 2\pi - s$）で，燃焼の熱 $Q_{\text{in}} > 0$ が決まった（SPEC-07．燃料が ON で燃料があるとき）ものを 1 回の燃焼とし，その時点のシミュレーションの時刻 $t_e$ を記録する．燃料カット，モータリング，クランキング（燃料が OFF）と停止では燃焼が無いので，振動しない．

#### B. 振動の時刻
1. 描画のフレーム $k$ の積分で，シミュレーションの時刻が $t_{k-1}$ から $t_k$ まで進み，実経過時間が $\Delta\tau_k$ のとき，その間の燃焼の時刻 $t_e$ を，次のフレームの実時刻 $\tau_k$（フレーム $k$ の終わり）から
   $$\tau_e = \tau_k + \frac{t_e - t_{k-1}}{t_k - t_{k-1}}\,\Delta\tau_k$$
   に始まるパルスにする（1 フレームの遅れで，フレームの中の間隔を保つ）．$\Delta\tau_k$ は，実経過時間を，1 フレームで進める時間の上限 $0.05\ \text{s}$ で切った値とする（積分が進める時間と同じ．フレームの間隔が長かったとき，$0.05\ \text{s}$ 分の燃焼を長い間隔に引き伸ばさない．REQ-36 の 7）．再生速度 $0.1\times$ ではシミュレーションの 1 サイクルが実時間で $10$ 倍に延び，$1\times$ では実時間の点火の周波数になる．最速では 1 フレームに多くの燃焼が入り，振動はつながる（C の 2）．
2. 振動は機関の計算に関わらない（読むのは燃焼の時刻の記録とシミュレーションの時刻だけ）．

#### C. 振動の命令
1. **送る時刻**：燃焼のあったフレームの次のフレームで，まだ終わっていないパルス（前に送ったものを含む）を並べて送る．燃焼の無いフレームでは送らない．
2. **パターン**：振動と休止の時間を交互に並べた配列（先頭は振動）にする．境界の時刻を ms に丸め，差を要素とする．送る時刻が休止の中なら先頭を $0$ にして最初の休止を続ける．休止が $2\ \text{ms}$ 未満になるところは前後の振動をつなぐ．要素は $98$ 個まで（Chrome の上限 $99$ の内側）．
3. **止める**：振動を OFF にしたとき，全テストの実行を始めたとき，ページが非表示になったときは，直ちに `navigator.vibrate(0)` を送る．全テストの実行中とページが非表示の間は命令を送らない．

#### D. 画面
画面の文書の SPEC-36 D（運転タブの `[振動]` と，設定「音と振動」）．

#### E. 実装
1. 燃焼の時刻は `EngineCore` の `igT`（配列．状態ベクトルには入れない）に積み，画面の側がフレームごとに取り出す．パターン（`hapPattern`）と，フレームごとの判断（`Hap`．時刻を引数で受け取る）を，描画とブラウザの API から分けた関数にする．`navigator.vibrate` を呼ぶのは画面の側の 1 か所だけにする．
2. 振動子の立ち上がりと止まるまでの時間は端末で違い，ページからは測れない．ここでの時刻はすべて命令の上の時刻である．Chrome はパターンをページの計算と同じスレッドのタイマーで 1 区間ずつ再生するので，計算の負荷でタイマーが遅れることがある（要件定義書 7.2 節の 22）．
