# tools/review

`docs/review_requirements.md`（第24版の要件定義書に対する，機関の数値計算の観点からのレビュー）で数値を確かめるのに使った試作スクリプトの記録．

* **第24版のコア向け**に書いてある（`load.js` が `src/core.js` を読み込む）．第25版でコアの状態ベクトルと右辺の形が変わったので，現在の `src/` に対してはそのままでは動かない．再実行するときは `git checkout 166282d -- src/core.js src/audio.js` で第24版のコアに戻してから実行する．
* レビューの全項目は第25版で反映した（要件定義書 7.3 節）．第25版の同じ検査は，アプリ内テスト（TEST-02，05，09，13）に入っている．

| ファイル | 内容 |
| :--- | :--- |
| `load.js` | コアを Node.js に読み込む |
| `expA.js`，`expA2.js` | 比熱比のモデルの差し替えによるトルクの変化（A1） |
| `expB.js`，`expC.js` | 吹き返しの熱の収支（A2），第一法則の残差（A3） |
| `expF.js`，`expH.js`，`expI.js`，`eig.py` | 刻みと精度，イベントの量子化，集計の次数，ヤコビアンの固有値（B1〜B4） |
