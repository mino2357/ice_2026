# tools/richburn — リッチでの出力増の試算（燃料空気サイクル）

直噴の気化潜熱と，リッチ（$\phi > 1$）での出力増をモデルに入れる検討のための試算．成果物には含めない．

- `faircycle.py`：定容燃焼の Otto サイクル（圧縮比 10，$p_1 = 100\ \text{kPa}$，$T_1 = 330\ \text{K}$，残留ガス・熱損失なし，燃焼効率 1）で，図示平均有効圧を $\phi$ に対して計算する．`python3 faircycle.py`（numpy，scipy が必要）．
- `thermo.json`：NASA 7 係数多項式．Cantera の `data/nasa_gas.yaml`（commit 25c1ab1c，BSD 3-Clause）から抜き出した．原典は McBride, Gordon, Reno, NASA TM-4513 (1993)．
- `faircycle_result.json`：実行結果．

## モデル
| 記号 | 内容 |
| :--- | :--- |
| M0 | 今のシミュレータ相当：$R = 287$ 一定，$\gamma_u(T)$，$\gamma_b(T)$ の直線，発熱 $q = f H_u \epsilon(\phi)$ |
| M1 | 化学種の熱力学，解離なし（リッチは水性ガス反応 $K = 3.5$ 固定） |
| M2 | 6 種（CO2，CO，H2O，H2，O2，N2）の化学平衡 |
| M3 | 10 種（M2 ＋ OH，O，H，NO）の化学平衡 |
| PFI／DI | 予混合（燃料蒸気が空気を押しのける，$T_1$ 固定）／直噴（空気を吸い，液体燃料が定圧・断熱で気化．冷却の上限） |

燃料は擬似種 CH$_{1.87}$（モル質量 110 g/mol，比熱は質量あたりでイソオクタンと同じ，液体の低位発熱量 44.0 MJ/kg，気化潜熱 350 kJ/kg）．

## 結果（2026-11-16）
検算：イソオクタン／空気の定圧断熱火炎温度（$\phi = 1$，298.15 K）は 10 種で 2271 K，6 種で 2295 K，解離なしで 2403 K（文献値は約 2275 K）．CO2 ⇌ CO + ½O2 の $\log_{10} K_p$ は 2500 K で $-1.433$．

| モデル | IMEP（$\phi = 1$）[kPa] | 最大になる $\phi$ | $\phi = 1$ 比の増加 |
| :--- | ---: | ---: | ---: |
| M0／PFI | 1449 | 1.00 | 0（$\phi = 1.1$ で $-2.8\%$） |
| M1／PFI | 1661 | 1.00 | 0（$\phi = 1.1$ で $-1.3\%$） |
| M1／DI | 1799 | 1.00 | 0（$\phi = 1.1$ で $-0.6\%$） |
| M2／PFI | 1616 | 1.05 | $+0.9\%$ |
| M2／DI | 1754 | 1.10 | $+1.4\%$ |
| M3／PFI | 1601 | 1.10 | $+1.1\%$ |
| M3／DI | 1739 | 1.15 | $+1.7\%$ |

- 解離を入れない限り（M0，M1），最大は $\phi = 1$ のまま．解離を入れると（M2，M3）最大がリッチ側へ移る．
- 直噴の冷却（上限）は $\phi = 1$ で $24.5\ \text{K}$，空気量 $+8.0\%$．
- このサイクルでは膨張の終わりが約 1800〜1900 K で，凍結温度 1700 K には届かない（凍結の有無で結果は同じ）．
